# 운영자 주문처리 매뉴얼

## 1. 문서 목적

이 문서는 주문팡팡 운영자가 주문수집부터 주문확인, 소싱라이프 구매 진행, 국내송장 확보, 마켓 송장전송까지 처리하는 기준 절차를 정의한다.

## 2. 하루 운영 흐름

운영자는 다음 순서로 주문을 처리한다.

1. `내정보 > 마켓연동`에서 마켓 계정 인증상태와 수집 실패 여부를 확인한다.
2. `주문수집 > 전체` 또는 상태별 메뉴에서 처리해야 할 주문 건수를 확인한다.
3. 신규주문에서 주문확인을 처리한다.
4. 상품준비에서 소싱라이프 상품 매칭, 구매, 결제를 진행한다.
5. 발송대기에서 국내송장을 확인하거나 입력한다.
6. 국내송장이 준비된 주문을 마켓으로 송장전송한다.
7. 배송중, 배송완료, 취소/반품/교환 주문을 확인한다.

## 3. 마켓연동 확인

위치: `내정보 > 마켓연동`

운영자는 주문수집 전 다음 항목을 확인한다.

| 항목 | 확인 기준 |
|---|---|
| 마켓 | 네이버 스마트스토어, 쿠팡 우선 활성 |
| 확장 예정 마켓 | 11번가, 지마켓, 옥션 |
| 연동 계정 | 스토어 또는 판매자 계정별 등록 상태 |
| 인증상태 | 정상, 인증만료, 오류, 미연동 |
| 마지막 수집시각 | 계정별 마지막 수집 여부 |
| 수집 실패 여부 | 실패 계정이 있는지 확인 |
| 마켓수수료율 | 마켓 또는 연동 계정 단위 수수료율 확인 |

주문팡팡은 마켓별 여러 개의 스토어 또는 판매자 계정을 등록할 수 있다.
주문수집은 활성화된 모든 연동 계정을 대상으로 실행한다.
마켓별 필터와 계정별 필터는 주문 목록을 보는 조건이며, 주문수집 대상을 줄이는 기능이 아니다.

## 4. 주문수집 확인

주문수집을 실행하면 활성화된 모든 연동 계정의 마켓 결제완료 주문을 수집한다.

수집된 주문은 기본적으로 `신규주문`에 표시된다.
계정 하나의 인증이 실패해도 다른 계정의 주문수집은 계속 진행한다.
실패한 계정은 마켓연동 화면에서 확인하고 재인증 또는 설정 확인을 진행한다.

## 5. 신규주문 처리

대상 상태: `NEW`

신규주문은 마켓에서 결제완료된 주문이 주문팡팡에 수집되었지만 아직 주문확인 전인 상태다.

| 버튼 | 사용 기준 |
|---|---|
| `주문확인` | 주문을 확인하고 상품준비로 이동 |
| `선택 주문확인 n건` | 선택한 신규주문을 일괄 주문확인 |
| `전체 주문확인` | 현재 필터 결과에 노출된 신규주문을 일괄 주문확인 |
| `소싱하기` | 소싱 후보 확인과 매칭 저장을 진행하면서 주문확인을 함께 처리 |
| `주문취소` | 신규주문을 취소 처리하고 취소/반품/교환으로 이동 |

신규주문에서 주문번호를 클릭하면 주문상세 모달이 열린다.
신규주문 모달 하단에는 `주문확인`, `소싱하기` 버튼만 표시한다.

## 6. 상품준비 처리

대상 상태: `PREPARING`

상품준비는 주문확인이 완료되었고, 소싱라이프에서 상품 매칭, 구매, 결제를 진행해야 하는 상태다.

운영자는 주문별 `소싱하기` 버튼으로 다음 작업을 진행한다.

1. 주문 상품 정보를 확인한다.
2. 이미지 매칭 후보를 확인한다.
3. 적합한 상품과 옵션을 선택한다.
4. 예상원가와 예상마진을 확인한다.
5. 소싱라이프 결제 화면으로 이동한다.
6. 소싱라이프 결제 완료 결과를 주문팡팡에 반영한다.

상품준비 단계의 주문상세 모달 하단에는 `소싱하기` 버튼만 표시한다.
소싱라이프 결제 화면으로 이동하는 과정은 `소싱하기` 흐름 안에서 처리한다.

소싱 후보가 없거나 적합하지 않으면 `후보 없음, 소싱라이프에서 찾기` 버튼을 사용한다.
이 버튼은 소싱라이프로 이동해 직접 검색 또는 이미지 검색으로 상품을 찾는 흐름이다.

소싱라이프 결제가 완료되면 주문은 `발송대기`로 이동한다.

## 7. 발송대기 처리

대상 상태: `READY_TO_SHIP`

발송대기는 소싱라이프 결제가 완료되었고, 국내송장 확보 또는 마켓 송장전송을 기다리는 상태다.

발송대기 주문은 두 가지로 나뉜다.

| 구분 | 의미 |
|---|---|
| 송장 수집대기 | 국내송장이 아직 없는 발송대기 주문 |
| 송장전송 대기 | 국내송장이 있고 마켓 송장전송 전인 발송대기 주문 |

## 8. 국내송장 확보

국내송장은 세 가지 방법으로 입력된다.

| 방법 | 설명 |
|---|---|
| 자동수집 | 자동수집 ON 상태에서 소싱라이프에 발급된 국내송장을 자동으로 가져온다 |
| 송장 수동수집 | 운영자가 버튼을 눌러 소싱라이프에 발급된 국내송장을 조회한다 |
| 수동 입력 | 운영자가 국내 택배사와 송장번호를 직접 입력한다 |

국내송장은 어떤 방법으로 입력되어도 즉시 자동저장된다.
운영자가 별도로 저장 버튼을 누르는 단계는 없다.

국내송장 컬럼은 발송대기 상태에서만 편집 가능하다.
신규주문, 상품준비, 배송중, 배송완료에서는 표시값만 확인한다.

## 9. 마켓 송장전송

국내송장이 입력된 뒤에는 자동 송장전송 설정에 따라 처리 방식이 달라진다.

| 설정 | 처리 기준 |
|---|---|
| 자동 송장전송 ON | 국내송장 자동저장 직후 마켓으로 송장전송 |
| 자동 송장전송 OFF | 운영자가 `송장전송` 버튼을 눌러 마켓으로 전송 |

송장전송이 성공하면 주문은 `배송중`으로 이동한다.
송장전송이 실패하면 주문은 `발송대기`에 남고 실패 사유가 표시된다.

발송대기 모달 하단에는 `송장전송` 버튼을 표시한다.

## 10. 배송중과 배송완료 확인

배송중은 마켓에 국내송장을 전송 완료한 주문이다.
배송완료는 마켓 배송완료 또는 구매확정 주문이다.

배송중과 배송완료는 기본적으로 조회용 상태다.
주문상세 모달 하단에는 다음 단계 버튼을 표시하지 않는다.

## 11. 취소/반품/교환 확인

대상 상태: `CLAIM`

취소, 반품, 교환 주문은 취소/반품/교환 메뉴에 표시한다.
신규주문에서 `주문취소`를 실행한 주문도 이 메뉴로 이동한다.

운영자는 주문별 `클레임확인` 버튼으로 사유와 후속 처리 필요 여부를 확인한다.

## 12. 주문 검색과 조회

운영자는 다음 조건으로 주문을 조회할 수 있다.

| 조건 | 기준 |
|---|---|
| 주문 검색 | 마켓 주문번호, 상품주문번호, 상품명, 구매자명, 수령인명, 연락처, 개인통관부호 |
| 기간 | 시작일, 종료일, 오늘, 7일, 15일, 1개월 |
| 마켓 | 전체, 네이버 스마트스토어, 쿠팡, 11번가, 지마켓, 옥션 |
| 계정 | 전체 계정 또는 등록된 스토어/판매자 계정 |
| 상태 | 전체 또는 상태별 탭 기준 |

필터는 주문 목록을 보는 조건이다.
필터를 바꿔도 주문수집 대상 계정은 바뀌지 않는다.

## 13. 주문상세 확인

마켓 주문번호를 클릭하면 주문상세 모달을 연다.

주문상세 모달에서는 다음 정보를 확인한다.

- 마켓, 연동 계정, 주문상태
- 마켓 주문번호, 상품주문번호
- 주문일시, 마켓 결제완료일시
- 상품이미지, 상품명, 옵션명, 수량, 상품단가, 결제금액
- 구매자명, 구매자 아이디, 구매자 연락처
- 수령인명, 수령인 연락처, 우편번호, 배송지 주소, 배송메시지
- 개인통관부호와 일치/불일치/확인필요 상태
- 소싱상태, 소싱상품명, 소싱옵션명, 예상원가, 실제결제금액, 실제마진, 소싱라이프 주문번호
- 국내송장
- 클레임 사유, 실패 사유

## 14. 실패 사유 확인

실패 사유는 정상 처리되지 않은 주문에만 표시한다.

| 실패 유형 | 운영 처리 |
|---|---|
| 주문수집 실패 | 마켓연동 화면에서 계정 인증상태 확인 |
| 주문확인 실패 | 실패 사유 확인 후 다시 주문확인 |
| 소싱라이프 연동 실패 | 필수정보, 상품 후보, 소싱라이프 연결 상태 확인 |
| 결제 상태 반영 실패 | 소싱라이프 결제 완료 여부 확인 |
| 송장전송 실패 | 국내송장 값과 마켓 전송 가능 상태 확인 후 재전송 |
| 클레임 처리 실패 | 클레임 사유와 마켓 상태 확인 |

초기버전에서는 처리이력 화면을 제공하지 않는다.
운영자는 주문상태, 소싱상태, 실패 사유를 기준으로 현재 처리 상태를 판단한다.

## 15. 운영 주의사항

- 사용자 화면 용어는 `주문확인`을 사용한다.
- 신규주문에서 다음 단계로 넘기는 기본 액션은 `주문확인`이다.
- 상품준비에서 소싱라이프 구매와 결제 화면 이동은 `소싱하기`로 처리한다.
- 국내송장은 입력되면 자동저장된다.
- 국내송장 자동수집과 자동 송장전송은 서로 다른 기능이다.
- 자동 송장전송은 국내송장이 어떤 방식으로 입력되었는지와 관계없이 동작한다.
- 마켓 송장전송이 성공해야 주문이 배송중으로 이동한다.
- 특정 판매처만 주문수집하거나 특정 계정만 주문수집하는 운영 기능은 초기 범위에 포함하지 않는다.
