# 실서비스 주문·소싱·클레임 유저플로우

## 1. 주문수집부터 발송

~~~mermaid
flowchart TD
    A["마켓 결제완료·변경 이벤트"] --> B["계정별 증분 수집"]
    B --> C{"중복 이벤트인가?"}
    C -->|"예"| D["기존 주문 최신상태 대사"]
    C -->|"아니오"| E["주문·상품주문 저장"]
    D --> F{"주문확인 가능한가?"}
    E --> F
    F -->|"아니오: 클레임/이미 처리"| G["현재 상태에 맞는 작업함"]
    F -->|"예"| H["주문확인 명령"]
    H --> I{"마켓 성공?"}
    I -->|"아니오"| J["실패 작업함·재시도"]
    I -->|"예"| K["상품준비"]
    K --> L{"승인된 SKU 매핑?"}
    L -->|"예"| M["매핑 재사용"]
    L -->|"아니오"| N["후보 검색·SKU 선택·매핑 승인"]
    M --> O["가격·재고·통관 재검증"]
    N --> O
    O --> P{"구매 가능?"}
    P -->|"아니오"| Q["재매칭·정보수정"]
    P -->|"예"| R["소싱라이프 구매대행 신청"]
    R --> S["사용자 결제 확인"]
    S --> T{"결제·구매 결과"}
    T -->|"실패/일부 성공"| U["복구 작업"]
    T -->|"성공"| V["중국배송·통관 이벤트"]

    W --> X{"자동 발송 조건 충족?"}
    X -->|"아니오"| Y["발송대기"]

    Y --> Z
    Z --> AA{"마켓 성공?"}
    AA -->|"아니오"| AB["송장 보존·발송 실패"]
    AA -->|"예"| AC["배송중"]
    AC --> AD["실제 국내 배송완료"]
    AD --> AE["배송완료·구매확정 동기화"]
~~~

## 2. 직접전달

~~~mermaid
flowchart TD
    A["상품준비 또는 발송대기"] --> B{"마켓 직접전달 capability"}
    B -->|"UNSUPPORTED"| C["버튼 숨김·대체 안내"]
    B -->|"MANUAL_FALLBACK"| D["판매자센터 처리 안내"]
    D --> E["단건 재동기화"]
    B -->|"API"| F["마켓별 필수값 확인"]
    F --> G["직접전달 명령"]
    G --> H{"마켓 성공?"}
    H -->|"아니오"| I["실패 작업함"]
    H -->|"예"| J["마켓 배송중·직접전달"]
    J --> K{"구매 완료 + 실제 국내송장?"}
    K -->|"아니오"| L["내부 상품준비 유지"]
    K -->|"예"| M["내부 배송중"]
    L --> N["소싱 구매·물류 계속"]
    N --> K
    M --> O["실제 국내송장으로 추적"]
    O --> P["실제 배송완료"]
~~~

직접전달은 마켓 제출 방식이다. 실제 배송 추적용 국내송장과 직접전달용 마켓 값을 분리한다.

## 6. 동기화·명령

~~~mermaid
sequenceDiagram
    participant U as 사용자
    participant W as Web/BFF
    participant D as PostgreSQL
    participant K as Worker
    participant M as 마켓

    U->>W: 주문확인·송장·클레임 요청
    W->>D: 멱등 outbound command 생성
    W-->>U: command ID·접수 상태
    K->>D: lease 획득
    K->>M: 최신 상태 조회
    M-->>K: 현재 상태
    K->>M: 허용된 외부 명령
    alt 명확한 성공
        M-->>K: 성공 응답
        K->>D: attempt·원장 상태·감사 저장
        W-->>U: 최종 성공
    else 명확한 실패
        M-->>K: 오류코드
        K->>D: 실패·다음 조치
        W-->>U: 실패와 재시도 가능 여부
    else timeout
        K->>D: UNKNOWN
        K->>M: 단건 상태 대사
        K->>D: 성공 또는 재시도 판정
        W-->>U: 확인 중 → 확정 결과
    end
~~~
