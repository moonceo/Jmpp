주문처리 유저플로우

소싱라이프·외부 구매, 자동 배송중 처리, 직접전달의 최신 주문 흐름입니다.

기본 흐름

flowchart TD
  A["신규주문"] -->|"주문확인"| B["상품준비"]
  B --> C{"구매 방식"}
  C -->|"소싱라이프 결제완료"| C1["선택 배송대행지 사이트 열기"]
  C1 --> C2["주문서 자동입력"]
  C2 --> C3["접수대기/접수신청"]
  C3 -->|"국내송장 즉시 발급"| D["구매 완료 + 국내송장"]
  C -->|"외부 구매"| D
  D --> E{"자동 배송중 처리"}
  E -->|"OFF"| F["발송대기"]
  E -->|"ON + 성공"| G["배송중"]
  E -->|"ON + 실패"| F
  F -->|"배송중 처리"| G
  G --> H["배송완료"]

직접전달 선처리

flowchart TD
  A["상품준비"] -->|"배송중 처리 > 직접전달"| B["마켓 배송중 · 내부 상품준비"]
  B --> C{"구매 완료 + 송장"}
  C -->|"소싱라이프"| D["내부 발송대기"]
  C -->|"외부 구매"| D
  C -->|"송장 없음"| E["완료 차단"]
  D --> F["배송중 처리 재실행"]
  F --> G["내부 배송중"]
  G --> H["실제 국내배송 완료"]

상태 기준

상태기준
PREPARING구매 완료 전. 직접전달만 먼저 처리한 주문도 포함
READY_TO_SHIP구매·송장 완료 후 배송중 처리 전
SHIPPING구매·송장 확보 후 배송중 처리가 완료
DELIVERED실제 국내송장 배송완료

필수 규칙

소싱라이프 연결 배송대지는 접수 즉시 국내송장을 발급하며 접수대기와 접수신청은 같은 단계입니다. 외부 구매도 국내송장이 있어야 완료할 수 있습니다.
