주문수집

flowchart TD
    A["주문수집 화면"] --> B["주문수집 버튼"]
    B --> C["활성화된 전체 마켓 계정/스토어 기준 수집"]
    C --> D["mock 주문 목록 갱신"]
    D --> E["신규주문 탭 표시"]

마켓/스토어 필터는 조회 조건이며 주문수집 실행 대상은 바꾸지 않는다.

마켓/스토어 필터

선택 상태표시 기준
아무것도 선택 안 함전체 주문 표시
마켓만 선택선택한 마켓의 전체 스토어 주문 표시
스토어만 선택해당 스토어 주문 표시
마켓 + 스토어 선택선택한 마켓 안에서 선택한 스토어 주문만 표시

선택한 마켓과 관계없는 스토어는 숨기지 않고 비활성화한다.

단계별 상태 필터

flowchart TD
    A["주문 단계 탭 선택"] --> B["상태 드롭다운 열기"]
    B --> C["현재 주문 건수와 무관한 단계별 고정 상태 목록"]
    C --> D{"배송완료 단계?"}
    D -->|"예"| E["전체 / 배송완료 / 구매확정"]
    D -->|"아니오"| F["해당 단계의 소싱 진행 상태"]
    E --> G["선택 상태와 일치하는 주문 조회"]
    F --> G

구매확정 주문은 배송완료 상태값과 구매확정 상태값을 함께 가지며, 두 필터에서 모두 조회된다. 내부 주문 단계는 배송완료를 유지한다.
