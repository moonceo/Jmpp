# 마켓연동 및 주문수집 유저플로우

## 1. 마켓연동 흐름

```mermaid
flowchart TD
    A["주문관리 > 마켓연동"] --> B["마켓 추가"]
    B --> C["마켓 드롭다운 선택"]
    C --> D["스토어명 입력"]
    D --> E["마켓별 인증 정보 입력"]
    E --> F["테스트"]
    F --> G["추가"]
    A --> H["관리"]
    H --> I["마켓 추가와 동일한 수정 모달"]
    A --> J["삭제"]
    J --> K["삭제 확인 모달"]
```

## 2. 마켓 추가 드롭다운

- 스마트스토어
- 쿠팡
- 11번가
- G마켓
- 옥션

## 3. 목록 컬럼

| 컬럼 | 설명 |
|---|---|
| 마켓 | 스마트스토어, 쿠팡, 11번가, G마켓, 옥션 |
| 스토어명 | 사용자가 구분하기 위해 입력한 이름 |
| 연동상태 | 정상, 오류 등 현재 상태 |
| 활성 | 주문수집 대상 포함 여부 |
| 관리 | 수정, 삭제 |

현재 MVP 화면에서는 플랫폼 수수료율, 마지막 수집, 결과, 판매자 계정명 컬럼을 표시하지 않는다.

## 4. 주문수집 흐름

```mermaid
flowchart TD
    A["주문수집 화면"] --> B["주문수집 버튼"]
    B --> C["활성화된 전체 연동 계정 기준 수집"]
    C --> D["mock 주문 목록 갱신"]
    D --> E["신규주문 탭 표시"]
```

마켓/스토어 필터는 주문 목록 조회 조건이다.
필터를 변경해도 주문수집 실행 대상은 바뀌지 않는다.

## 5. 마켓/스토어 필터 흐름

| 선택 상태 | 표시 기준 |
|---|---|
| 아무것도 선택 안 함 | 전체 주문 표시 |
| 마켓만 선택 | 선택한 마켓의 전체 스토어 주문 표시 |
| 스토어만 선택 | 해당 스토어 주문 표시 |
| 마켓 + 스토어 선택 | 선택한 마켓 안에서 선택한 스토어 주문만 표시 |

선택한 마켓과 관계없는 스토어는 숨기지 않고 비활성화한다.

## 6. 검색/기간 필터 흐름

```mermaid
flowchart TD
    A["주문수집 화면"] --> B["기간 선택"]
    B --> C{"직접 입력?"}
    C -->|"아니오"| D["오늘/3일/7일/30일 기준 조회"]
    C -->|"예"| E["직접 기간 선택 모달"]
    E --> F["시작일/종료일 선택"]
    A --> G["검색어 입력"]
    G --> H["상품명, 주문번호, 주문자, 수령인 기준 필터"]
    A --> I["마켓/스토어 필터"]
    D --> J["주문 목록 갱신"]
    F --> J
    H --> J
    I --> J
```

기간, 검색어, 마켓/스토어 필터는 모두 현재 화면의 주문 목록을 좁히는 조회 조건이다.
`주문수집` 버튼은 우측에 고정되며, 필터 조건 입력과 별도로 활성 계정 기준 수집을 실행한다.

## 7. 마켓연동 검증/활성 흐름

```mermaid
flowchart TD
    A["마켓 추가/관리 모달"] --> B["필수값 입력"]
    B --> C["테스트"]
    C --> D{"필수 인증값 있음?"}
    D -->|"없음"| E["누락 안내 토스트"]
    D -->|"있음"| F["테스트 성공 토스트"]
    F --> G["추가 또는 저장"]
    G --> H["목록 반영"]
    H --> I["활성 스위치 변경"]
    I --> J["주문수집 대상 포함 여부 변경"]
```

마켓 추가의 `추가` 버튼은 현재 선택한 마켓의 필수 인증 정보가 채워져야 사용할 수 있다.
`관리`는 마켓 추가와 동일한 모달을 사용하되 마켓 종류는 변경하지 않는다.
`활성` 스위치는 계정을 삭제하지 않고 주문수집 대상 포함 여부만 바꾼다.
