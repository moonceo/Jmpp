# 주문현황 기능요구서

> 기능별 중요도와 상세 문서: [주문현황 기능목록](./하위문서/02_주문현황/00_기능목록.md)

## 전체 흐름

```text
주문현황 진입
→ 검색 또는 이슈만 보기 설정
→ 주문 흐름 그룹과 상태별 건수 확인
→ 상태 선택
→ 해당 주문과 처리 필요 사유 확인
→ 이슈 제외·2시간 미루기 또는 주문 작업함 이동
```

## 공통 화면 구성

1. 검색과 이슈 필터
2. 이슈 기준 설정
3. 주문 흐름 상태표
4. 선택 상태의 주문 목록
5. 주문별 처리 기능

외부 배대지 단계는 커머스라이프가 직접 처리하지 않고 연동 수신값으로만 표시한다.

## 검색과 이슈 필터

| 항목 | 요청 내용 |
|---|---|
| 검색 | 주문번호, 상품명, 수령자, 연락처, 스토어명 검색 |
| 이슈만 보기 | 현재 처리 필요로 판정된 주문만 집계·표시 |
| 새로고침 | 데모 갱신시각 변경 |
| 이슈 기준 설정 | 처리 필요 판정에 사용할 조건 ON/OFF |

검색과 이슈 필터는 상태별 건수와 아래 주문 목록에 동시에 적용한다.

## 주문 흐름 그룹

| 그룹 | 포함 상태 |
|---|---|
| 접수~결제 | 신규 주문, 통관부호 수집중, 소싱 발주 대기 |
| 소싱·중국 | 현지 발송 대기, 현지 배송중, 도착·입고 전 |
| 배대지 | 입고 대기, 부분입고, 검수대기, 오류입고, 견적 완료, 재포장 중, 배송비 결제 완료, 출고 준비, 출고 완료 |
| 통관~확정 | 국내 입항, 국내 배송중, 배송 완료, 구매 확정 대기, 구매 확정 |
| 소싱 환불 | 환불 요청부터 환불 완료·거절·결과 확인까지 |
| 마켓 클레임 | 반품, 교환, 취소, 완료 |

각 상태에는 전체 건수와 처리 필요 건수를 함께 표시한다. 상태를 선택하면 아래 목록이 해당 상태 주문으로 변경된다.

## 이슈 판정 항목

| 항목 | 판정 결과 |
|---|---|
| 통관부호 미수집·형식 오류 | 신규·상품준비 주문을 통관부호 확인 필요로 표시 |
| 처리보류·연동 실패 | 실패 사유가 있거나 처리보류된 주문 표시 |
| 미완료 마켓 클레임 | 완료되지 않은 취소·반품·교환 표시 |
| 소싱환불 후속 확인 | 미접수, 중국 반품 필요, 거절, 결과 대사 필요 표시 |
| 예상 역마진 | 예상 비용이 정산예정금보다 큰 주문 표시 |

`기본값 복원`은 모든 이슈 판정 항목을 다시 활성화한다. `적용`은 모달을 닫고 현재 화면에 설정을 반영한다.

## 주문 목록 항목

| 항목 | 표시 내용 |
|---|---|
| 주문·상품 | 상품명, 마켓 주문번호 |
| 판매처 | 마켓, 스토어명 |
| 수령자 | 이름, 연락처 |
| 처리 필요 | 이슈명과 상세 사유 또는 정상 진행 |
| 결제금액 | 주문 결제금액 |
| 작업 | 이슈 아님, 2시간 미루기, 처리하기 |

## 주문별 기능

| 기능 | 표시 조건 | 처리 결과 |
|---|---|---|
| 이슈 아님 | 현재 이슈가 있는 주문 | 현재 브라우저의 이슈 목록에서 제외 |
| 2시간 미루기 | 현재 이슈가 있는 주문 | 현재 목록에서 숨기고 2시간 후 확인 대상으로 설정 |
| 처리하기 | 모든 주문 | 주문 상태에 맞는 주문수집 또는 클레임 화면으로 이동 |

## 상태별 이동

- 신규 주문과 통관부호 수집중은 신규주문으로 이동한다.
- 소싱 발주 대기는 상품준비로 이동한다.
- 국내 배송중은 배송중으로 이동한다.
- 배송완료·구매확정은 배송완료로 이동한다.
- 마켓 클레임은 취소·반품·교환으로 이동한다.
- 소싱환불은 주문수집 전체로 이동한다.
- 나머지 물류 상태는 발송대기로 이동한다.

## 빈 상태

선택 상태에 주문이 없으면 검색어 또는 이슈 필터를 변경하거나 다른 상태를 선택하도록 안내한다.

## 현재 프로토타입 제한

- 모든 주문과 이슈는 고정 데모 데이터다.
- 새로고침은 데이터 자체를 다시 가져오지 않고 갱신시각만 변경한다.
- 이슈 제외, 미루기와 이슈 기준은 새로고침·재진입 후 유지되지 않을 수 있다.
- 2시간 미루기는 시간이 지나도 자동으로 다시 나타나지 않으며 화면 갱신이 필요하다.
- 외부 배대지 상세 상태는 실제 연동값이 없어 대부분 0건이다.

## 완료 확인 기준

- 검색과 이슈만 보기가 상태 건수와 주문 목록에 함께 적용된다.
- 상태별 주문과 처리 필요 사유를 확인할 수 있다.
- 주문의 다음 작업 화면으로 이동할 수 있다.
- 실제 기능 전환 시 새로고침, 이슈 제외, 미루기와 기준 설정의 저장 범위를 명확히 확정해야 한다.
