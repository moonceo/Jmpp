# 스토어별 기본 배송중 처리 방식 설정

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓 추가·설정 모달
- 노출 조건: 모든 계정에 표시한다.
- 실행 흐름: 마켓별 지원 방식 중 기본값 선택 → 스토어 계정 저장 → 주문수집의 개별·일괄·자동 배송중 처리에서 기본값 적용
- 마켓별 선택 범위:
  - 스마트스토어: 직접전달, 해외기타배송, 송장입력
  - 11번가: 직접전달, 송장입력
  - 쿠팡·G마켓·옥션: 송장입력 고정
- 상태 변화: 선택값을 연동 계정 단위로 저장한다. 같은 마켓에 여러 스토어가 있어도 각 스토어가 서로 다른 기본값을 가질 수 있다.
- 처리 결과: 계정 목록에서 현재 기본값을 확인하고, 주문 처리 화면은 주문이 연결된 스토어의 값을 최초 선택값으로 표시한다.
- 예외·제한: 주문에서 사용자가 다른 지원 방식을 선택하면 주문 선택값을 우선한다. 해외기타배송은 해외 운송장번호가, 송장입력은 국내배송 시작과 택배사·국내송장번호가 충족되어야 실행할 수 있으며 기본값 설정이 이 조건을 생략하지 않는다.
