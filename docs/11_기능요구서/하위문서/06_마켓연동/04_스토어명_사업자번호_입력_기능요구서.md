# 스토어명·사업자번호 입력

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓 추가·설정 모달의 공통 입력 영역
- 노출 조건: 모든 마켓에서 표시한다.
- 실행 흐름: 스토어명·사업자번호 입력 → 필수값 검사 → 저장 대상에 포함
- 상태 변화: 저장 후 계정 목록의 스토어명을 갱신한다.
- 처리 결과: 사용자가 여러 계정을 스토어명으로 구분한다.
- 예외·제한: 공백 값은 저장할 수 없다. 사업자번호는 하이픈을 제외한 숫자 10자리만 저장한다.
