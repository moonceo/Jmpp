# 연결 테스트

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓 추가·설정 모달의 `테스트`
- 노출 조건: 마켓과 모든 필수값을 입력하면 활성화한다.
- 실행 흐름: 테스트 선택 → 확인 중 표시 → 더미 성공·실패 결과 표시
- 상태 변화: 성공이면 저장 가능 상태, 실패이면 입력 수정 상태로 변경한다.
- 처리 결과: 사용자는 저장 전 입력 완료 여부와 시연 결과를 확인한다.
- 예외·제한: 실제 마켓 인증 요청은 실행하지 않으며 버튼과 결과 문구에 데모임을 명시한다.
