# 연결 다시 확인

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 계정 설정 모달
- 노출 조건: 확인 대기·연동 오류·재인증 필요 상태에서 제공한다.
- 실행 흐름: 인증정보 입력 또는 유지 → 다시 확인 선택 → 더미 확인 결과 생성
- 상태 변화: 성공이면 연동 완료, 실패이면 연동 오류 상태로 변경한다.
- 처리 결과: 목록의 연동상태를 즉시 갱신한다.
- 예외·제한: 실제 인증이나 주문 접근 권한을 확인하지 않는다.
