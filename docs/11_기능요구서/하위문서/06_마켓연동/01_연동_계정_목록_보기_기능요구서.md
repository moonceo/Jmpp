# 연동 계정 목록 보기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓연동 화면의 계정 목록
- 노출 조건: 화면 진입 시 항상 표시한다.
- 실행 흐름: 더미 연동 계정 불러오기 → 마켓·스토어명·기본 배송중 처리 방식·연동상태·활성 여부·관리 기능 표시
- 상태 변화: 추가·수정·활성 변경·삭제 후 목록과 활성/전체 계정 수를 갱신한다.
- 처리 결과: 사용자가 등록한 모든 더미 스토어를 확인한다.
- 예외·제한: 계정이 없으면 빈 테이블과 마켓 추가 안내를 표시한다.
