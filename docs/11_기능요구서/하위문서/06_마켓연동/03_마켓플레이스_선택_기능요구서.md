# 마켓플레이스 선택

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓 추가 모달의 첫 입력 항목
- 노출 조건: 신규 계정 추가 시 표시한다.
- 실행 흐름: 스마트스토어·쿠팡·11번가·G마켓·옥션 선택 → 해당 마켓 인증 입력 항목 표시
- 상태 변화: 마켓을 바꾸면 이전 마켓 전용 인증 입력값을 초기화하고 기본 배송중 처리 선택지를 해당 마켓 범위로 다시 설정한다. 스마트스토어는 직접전달·해외기타배송·송장입력, 11번가는 직접전달·송장입력, 나머지 마켓은 송장입력만 제공한다.
- 처리 결과: 선택 마켓에 필요한 필드만 표시한다.
- 예외·제한: 계정 수정에서는 마켓 종류를 변경할 수 없다.
