# 계정별 주문수집

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 계정 목록의 `주문수집`
- 노출 조건: 연동 완료이며 활성 상태인 계정에만 활성화한다.
- 실행 흐름: 주문수집 선택 → 수집 중 표시 → 더미 신규·갱신 결과 생성 → 완료 안내
- 상태 변화: 버튼 처리 상태와 마지막 수집 결과를 갱신한다.
- 처리 결과: 주문수집 화면의 더미 주문과 건수에 결과를 반영한다.
- 예외·제한: 실제 마켓 주문을 불러오지 않으며 실패 시 기존 주문을 유지한다.
