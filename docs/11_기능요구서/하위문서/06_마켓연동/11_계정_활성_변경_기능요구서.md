# 계정 활성 변경

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 계정 목록의 활성 스위치
- 노출 조건: 모든 더미 계정에 표시한다.
- 실행 흐름: 활성 ON/OFF → 변경 확인 → 더미 계정 상태 저장
- 상태 변화: ON은 주문수집 대상, OFF는 일시정지 상태로 변경하고 활성 계정 수를 갱신한다.
- 처리 결과: 주문수집 실행 시 활성 계정만 대상으로 시연한다.
- 예외·제한: 연동 완료가 아닌 계정은 활성화할 수 없다.
