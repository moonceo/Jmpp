# 마켓 추가 열기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 화면 상단의 `마켓 추가`
- 노출 조건: 항상 표시하며 계정 수 제한을 두지 않는다.
- 실행 흐름: 마켓 추가 선택 → 추가 모달 열기 → 마켓 선택 → 공통·마켓별 항목 입력
- 상태 변화: 모달을 닫기 전에는 계정 목록을 변경하지 않는다.
- 처리 결과: 5개 대상 마켓 중 하나의 더미 계정을 준비한다.
- 예외·제한: 취소 또는 닫기 시 입력값을 저장하지 않는다.
