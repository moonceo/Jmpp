# 계정 설정

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 각 계정 행의 `설정`
- 노출 조건: 모든 더미 계정에 표시한다.
- 실행 흐름: 설정 선택 → 현재 스토어명·사업자번호·발송방식 표시 → 값 수정 → 저장
- 상태 변화: 마켓 종류는 유지하고 수정 가능한 값만 계정 목록과 주문수집 필터에 반영한다.
- 처리 결과: 수정 완료 안내와 변경된 목록을 표시한다.
- 예외·제한: 비밀키 원문은 다시 표시하지 않으며 변경하지 않을 때 재입력을 강제하지 않는다.
