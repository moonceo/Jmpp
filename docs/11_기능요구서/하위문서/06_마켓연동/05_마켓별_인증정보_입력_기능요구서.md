# 마켓별 인증정보 입력

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓 추가·설정 모달
- 노출 조건: 선택 마켓에 따라 해당 인증 필드만 표시한다.
- 실행 흐름: 필수 인증정보 입력 → 누락 여부 확인 → 더미 연결 테스트 또는 저장
- 상태 변화: 입력 중에는 목록을 변경하지 않고 저장 후에는 비밀키 입력값을 화면에 다시 표시하지 않는다.
- 처리 결과: 더미 계정의 확인 대기 또는 연동 완료 상태를 생성한다.
- 예외·제한: 실제 인증을 수행하거나 인증정보를 외부로 전송하지 않는다. 필수값이 하나라도 없으면 테스트·저장을 실행할 수 없다.
