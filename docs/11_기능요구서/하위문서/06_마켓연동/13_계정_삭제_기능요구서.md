# 계정 삭제

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 계정 목록의 `삭제`
- 노출 조건: 모든 더미 계정에 표시한다.
- 실행 흐름: 삭제 선택 → 마켓·스토어명과 영향 안내 → 삭제 확정
- 상태 변화: 계정을 목록과 주문수집의 전체 스토어 필터에서 제거하고 계정 수를 갱신한다.
- 처리 결과: 삭제 완료 안내를 표시한다.
- 예외·제한: 해당 스토어의 기존 더미 주문과 처리 이력은 유지하되 연동 스토어 필터 목록에서는 제거한다.
