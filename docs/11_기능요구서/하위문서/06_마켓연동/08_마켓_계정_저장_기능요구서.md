# 마켓 계정 저장

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 마켓 추가 모달의 저장 버튼
- 노출 조건: 공통·마켓별 필수값과 기본 배송중 처리 방식이 입력됐을 때 활성화한다.
- 실행 흐름: 저장 선택 → 입력 확인 → 더미 계정 추가 → 모달 닫기 → 목록·계정 수 갱신
- 상태 변화: 새 계정을 확인 대기 또는 연동 완료 상태로 추가한다.
- 처리 결과: 목록과 주문수집의 스토어 필터에 새 스토어를 표시한다.
- 예외·제한: 동일 마켓에서 같은 스토어명은 중복 저장할 수 없다.
