# 배송비 결제대기 판매자 알림

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 판매자 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 활성화 → 인앱 미리보기 확인 → 저장
- 상태 변화: 더미 소싱 주문이 배송비 결제대기 상태가 되면 알림 예정 상태를 생성한다.
- 처리 결과: 처리 대상 주문과 다음 작업을 안내한다.
- 예외·제한: 이미 결제됐거나 취소된 주문에는 알림 예정 상태를 만들지 않는다.
