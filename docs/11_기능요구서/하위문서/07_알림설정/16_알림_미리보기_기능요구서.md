# 알림 미리보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 선택 알림의 상세 영역 옆 미리보기
- 노출 조건: 알림 종류를 선택하면 표시한다.
- 실행 흐름: 알림 선택 또는 상세값 변경 → 알림 종류에 맞는 템플릿 선택 → 치환값·시간대·옵션 반영
- 상태 변화: 조회용 미리보기만 갱신하고 알림 상태를 변경하지 않는다.
- 처리 결과: 고객명·스토어명·상품명 등 더미 치환값과 최종 형태를 확인한다.
- 예외·제한: 지원하지 않는 미리보기는 다른 알림 내용을 대신 표시하지 않고 `미리보기 준비 중`으로 표시한다.
