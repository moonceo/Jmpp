# 통관부호 수집 SMS

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 고객 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 선택·활성화 → 시간대·안내 옵션 설정 → SMS 형식 미리보기 → 저장
- 상태 변화: 알림톡과 별도의 SMS 설정값을 변경한다.
- 처리 결과: 통관부호 확인이 필요한 더미 주문에 SMS 발송 예정 상태를 시연한다.
- 예외·제한: SMS 글자 수를 넘는 문구의 축약 기준이 필요하며 실제 SMS를 보내지 않는다.
