# 주문 취소 버튼 숨기기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 통관부호 알림톡·SMS의 상세 설정
- 노출 조건: 통관부호 수집 알림을 선택했을 때만 표시한다.
- 실행 흐름: 옵션 ON/OFF → 미리보기의 주문 취소 버튼 표시 갱신 → 저장
- 상태 변화: 선택 알림의 옵션만 변경한다.
- 처리 결과: ON이면 미리보기와 더미 메시지에서 주문 취소 바로가기를 숨긴다.
- 예외·제한: 중국배송·배대지·리뷰·판매자 알림에는 표시하지 않는다.
