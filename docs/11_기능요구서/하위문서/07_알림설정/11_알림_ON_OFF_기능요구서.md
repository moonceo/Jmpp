# 알림 ON/OFF

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 각 알림 카드의 스위치
- 노출 조건: 모든 알림 카드에 표시한다.
- 실행 흐름: 스위치 변경 → 선택 알림 활성 상태 변경 → 미리보기와 저장 대상 갱신
- 상태 변화: OFF이면 해당 알림의 발송 시연을 비활성화하되 기존 상세 설정값은 보존한다.
- 처리 결과: 카드와 상세 영역에 현재 활성 상태를 표시한다.
- 예외·제한: 외부 알림을 실제로 발송하거나 중단하지 않는다.
