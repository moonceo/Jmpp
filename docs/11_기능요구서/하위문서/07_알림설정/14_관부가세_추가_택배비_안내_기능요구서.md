# 관부가세·추가 택배비 안내

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 통관부호 알림톡·SMS의 상세 설정
- 노출 조건: 통관부호 수집 알림을 선택했을 때만 표시한다.
- 실행 흐름: 옵션 ON/OFF → 안내문 미리보기 갱신 → 저장
- 상태 변화: 선택 알림의 추가 비용 안내 여부를 변경한다.
- 처리 결과: ON이면 관부가세와 추가 택배비가 발생할 수 있다는 문구를 표시한다.
- 예외·제한: 관련 없는 알림에는 설정과 문구를 표시하지 않는다.
