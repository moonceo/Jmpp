# 판매자 수신 채널 보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 판매자 알림 상세 설정
- 노출 조건: 신규주문·배송비 결제대기·오류입고 알림 선택 시 표시한다.
- 실행 흐름: 판매자 알림 선택 → 기본 수신 채널 확인
- 상태 변화: 현재 프로토타입에서는 인앱 채널을 변경하지 않는다.
- 처리 결과: 알림이 인앱으로 시연됨을 표시한다.
- 예외·제한: 이메일과 모바일 푸시는 제공하지 않으며 선택 가능한 것처럼 표시하지 않는다.
