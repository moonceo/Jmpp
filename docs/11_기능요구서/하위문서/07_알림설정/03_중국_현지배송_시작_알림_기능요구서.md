# 중국 현지배송 시작 알림

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 고객 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 활성화 → 시간대 설정 → 중국배송 시작 템플릿 미리보기 → 저장
- 상태 변화: 소싱상품 상태가 중국배송중으로 바뀌는 더미 주문을 발송 대상으로 판정한다.
- 처리 결과: 고객에게 현지배송 시작을 안내하는 시연 내용을 표시한다.
- 예외·제한: 통관부호 전용 옵션은 표시하지 않고 실제 메시지를 보내지 않는다.
