# 고객·판매자 알림 전환

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 알림 설정 상단의 고객 알림·판매자 알림 구분
- 노출 조건: 항상 표시한다.
- 실행 흐름: 구분 선택 → 해당 알림 종류 목록 표시 → 첫 알림 또는 마지막 선택 알림 상세 표시
- 상태 변화: 선택 구분과 알림을 변경하되 다른 알림의 설정값은 유지한다.
- 처리 결과: 고객용 발송정책과 판매자용 수신정책을 구분해 확인한다.
- 예외·제한: 선택한 구분에 알림이 없으면 빈 상태를 표시한다.
