# 통관부호 수집 알림톡

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 고객 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 선택·활성화 → 발송 시간과 안내 옵션 설정 → 미리보기 → 저장
- 상태 변화: 선택 알림의 활성·시간대·버튼·추가 비용 안내 값을 변경한다.
- 처리 결과: 개인통관부호가 없거나 형식이 잘못된 더미 주문에 알림톡 발송 예정 상태를 시연한다.
- 예외·제한: 실제 알림톡을 보내지 않으며 정상 통관부호 주문은 발송 대상에 포함하지 않는다.
