# 배대지 출고 알림

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 고객 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 활성화 → 시간대 설정 → 배대지 출고 템플릿 미리보기 → 저장
- 상태 변화: 더미 물류상태가 배대지 출고완료로 바뀐 주문을 발송 대상으로 판정한다.
- 처리 결과: 국내 배송이 시작될 예정임을 고객에게 알리는 시연 내용을 표시한다.
- 예외·제한: 국내송장이 없는 주문에 송장정보를 임의로 표시하지 않는다.
