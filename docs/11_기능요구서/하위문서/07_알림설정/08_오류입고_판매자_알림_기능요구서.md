# 오류입고 판매자 알림

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 판매자 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 활성화 → 인앱 미리보기 확인 → 저장
- 상태 변화: 더미 배대지 상태가 오류입고로 바뀌면 알림 예정 상태를 생성한다.
- 처리 결과: 주문번호·오류 사유·확인 필요 작업을 포함한 시연 내용을 표시한다.
- 예외·제한: 오류 사유가 없으면 임의 사유를 만들지 않고 확인 필요로 표시한다.
