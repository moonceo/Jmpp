# 신규주문 판매자 알림

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 판매자 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 활성화 → 인앱 미리보기 확인 → 저장
- 상태 변화: 신규 더미 주문 수집 시 판매자 인앱 알림 예정 상태를 생성한다.
- 처리 결과: 마켓·스토어명과 신규주문 건수를 포함한 시연 내용을 표시한다.
- 예외·제한: 이메일·모바일 푸시를 실제로 보내지 않는다.
