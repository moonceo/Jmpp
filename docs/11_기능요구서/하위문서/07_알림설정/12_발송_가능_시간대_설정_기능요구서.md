# 발송 가능 시간대 설정

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 고객 알림 상세 설정
- 노출 조건: 시간대 정책을 사용하는 고객 알림을 선택했을 때 표시한다.
- 실행 흐름: 시작시간·종료시간 선택 → 시간 유효성 확인 → 미리보기 갱신 → 저장
- 상태 변화: 선택 알림의 시간대만 변경한다.
- 처리 결과: 알림 발생시각이 시간 밖이면 다음 발송 가능 시각까지 대기한다는 정책을 표시한다.
- 예외·제한: 프로토타입에서는 같은 날의 시작시간이 종료시간보다 빨라야 한다. 같은 시간 또는 자정을 넘기는 범위는 저장하지 않고 안내한다.
