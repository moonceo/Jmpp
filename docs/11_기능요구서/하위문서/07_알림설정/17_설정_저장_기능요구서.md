# 설정 저장

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 알림 설정 화면의 `설정 저장`
- 노출 조건: 설정값이 변경됐을 때 활성화한다.
- 실행 흐름: 설정 저장 → 시간대·필수값 검사 → 더미 설정 저장 → 성공 안내
- 상태 변화: 선택 알림별 ON/OFF와 상세 설정을 저장된 상태로 표시한다.
- 처리 결과: 화면 내에서 다른 알림을 선택했다가 돌아와도 저장값을 유지한다.
- 예외·제한: 실제 메시지를 전송하지 않는다. 현재 프로토타입은 새로고침하면 초기화되므로 성공 문구를 `현재 화면에 적용`으로 바꾸거나 브라우저 저장을 추가해야 한다.
