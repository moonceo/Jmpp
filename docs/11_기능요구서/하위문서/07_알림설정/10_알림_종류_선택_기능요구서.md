# 알림 종류 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 고객·판매자 알림 카드 목록
- 노출 조건: 선택 구분에 속한 모든 알림 카드를 표시한다.
- 실행 흐름: 알림 카드 선택 → 선택 강조 → 해당 알림의 ON/OFF·상세 설정·미리보기 표시
- 상태 변화: 선택 알림만 변경하며 기존에 편집한 다른 알림 값은 유지한다.
- 처리 결과: 선택 알림에 해당하는 설정과 미리보기를 확인한다.
- 예외·제한: 현재 프로토타입은 모든 고객 알림이 공통 상세값을 공유하고 미리보기가 통관부호 알림톡으로 고정되는 불일치가 있다.
