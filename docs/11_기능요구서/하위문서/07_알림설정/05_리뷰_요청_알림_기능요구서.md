# 리뷰 요청 알림

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 고객 알림 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 알림 활성화 → 시간대 설정 → 리뷰 요청 템플릿 미리보기 → 저장
- 상태 변화: 더미 주문이 배송완료된 경우 리뷰 요청 예정 대상으로 판정한다.
- 처리 결과: 상품명과 리뷰 이동 안내를 포함한 시연 내용을 표시한다.
- 예외·제한: 취소·반품·교환 진행 주문은 대상에서 제외한다.
