# 판매자 직접취소 목록 표시

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 취소·반품·교환 목록의 `취소` 유형과 `완료` 진행 단계
- 노출 조건: 주문수집 화면에서 판매자가 더미 주문의 주문취소를 완료한 경우 표시한다.
- 실행 흐름: 주문수집에서 주문취소 완료 → 취소 이력 생성 → 취소·반품·교환 목록에 추가 → 상세보기
- 목록 표시: 마켓·스토어·주문번호, 취소·처리완료, `판매자 직접취소`, 취소 사유, 상품·수량과 취소시각을 표시한다.
- 상세 표시: 접수 주체를 `판매자 직접취소`로 표시하고 접수 사유, 취소 당시 주문·배송·소싱 상태와 상태 이력을 제공한다.
- 상태 변화: 판매자 취소 기록은 완료 상태로 생성한다. 구매자 취소 승인·거부 작업은 제공하지 않는다.
- 처리 결과: 같은 주문은 전체 주문에서 판매자취소 상태로, 취소·반품·교환에서는 완료된 취소 이력으로 조회한다.
- 예외·제한: 동일 주문을 다시 취소해도 취소 이력을 중복 생성하지 않는다. 소싱 결제가 있었던 주문은 소싱환불 후속조치 검토 대상으로 표시한다.
