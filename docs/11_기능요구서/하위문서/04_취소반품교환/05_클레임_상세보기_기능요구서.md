# 클레임 상세보기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 목록의 취소처리·반품처리·교환처리·상세보기 버튼
- 노출 조건: 구매자 신청 행에는 유형별 처리 버튼을, 판매자 직접취소 행에는 상세보기 버튼을 표시한다.
- 실행 흐름: 처리 또는 상세보기 선택 → 상세 열기 → 접수정보·상품·회수·재배송·현재 작업·소싱 후속조치·상태 이력 확인
- 상태 변화: 상세 열림 상태만 변경하며 작업 실행 전에는 클레임 상태를 변경하지 않는다.
- 처리 결과: 현재 상태에서 가능한 작업만 표시한다.
- 예외·제한: 판매자 직접취소 완료 건에는 구매자 취소 승인 작업을 표시하지 않는다. 가능한 작업이 없으면 `현재 작업 없음`을 표시한다.
