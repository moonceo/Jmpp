# 반품 승인

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 네이버 회수완료 또는 쿠팡 입고확인 반품 상세
- 노출 조건: 회수·입고가 완료되고 반품을 확정할 수 있을 때 표시한다.
- 실행 흐름: 반품 승인 → 대상 상품·수량·환불금 확인 → 승인 확정
- 상태 변화: 클레임을 반품완료로 변경하고 연결 주문의 클레임 상태와 이력을 갱신한다.
- 처리 결과: 마켓 반품 완료와 소싱 구매 후속조치 상태를 각각 표시한다.
- 예외·제한: 소싱상품 환불은 자동 완료하지 않고 별도 후속조치로 유지한다.
