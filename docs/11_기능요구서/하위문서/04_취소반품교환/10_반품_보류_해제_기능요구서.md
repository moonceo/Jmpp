# 반품 보류 해제

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 네이버 반품보류 상세
- 노출 조건: 현재 상태가 반품보류일 때 표시한다.
- 실행 흐름: 보류 해제 → 이전 진행상태 확인 → 확정
- 상태 변화: 보류 직전 반품 상태로 복귀하고 이력을 추가한다.
- 처리 결과: 해당 상태에서 가능한 반품 작업을 다시 제공한다.
- 예외·제한: 직전 상태를 확인할 수 없으면 회수완료가 아닌 임의 상태로 변경하지 않는다.
