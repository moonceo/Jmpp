# 반품 거부

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 네이버 반품보류 상세
- 노출 조건: 보류 상태이며 거부 사유를 확정할 수 있을 때 표시한다.
- 실행 흐름: 반품 거부 → 거부 사유 입력 → 확정
- 상태 변화: 클레임을 반품거부로 변경하고 이력을 추가한다.
- 처리 결과: 거부 사유와 처리시각을 표시한다.
- 예외·제한: 사유가 없으면 실행할 수 없다.
