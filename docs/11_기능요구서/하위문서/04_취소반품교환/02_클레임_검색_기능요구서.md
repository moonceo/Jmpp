# 클레임 검색

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 목록 상단 검색 입력창
- 노출 조건: 항상 표시한다.
- 실행 흐름: 상품명·주문번호·클레임 ID 입력 → 부분 일치 검색 → 목록 갱신
- 상태 변화: 검색어를 지우면 다른 필터를 유지한 전체 결과로 돌아간다.
- 처리 결과: 검색 결과와 유형·상태별 건수가 같은 데이터 기준으로 표시된다.
- 예외·제한: 마스킹된 구매자 사유는 검색 대상에 포함하지 않는다.
