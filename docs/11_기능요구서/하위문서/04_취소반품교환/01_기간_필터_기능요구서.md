# 기간 필터

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 클레임 목록 상단 검색·필터 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 오늘·3일·7일·30일·전체 선택 → 클레임 접수일 기준 목록 갱신
- 상태 변화: 선택 기간을 강조하고 다른 필터는 유지한다.
- 처리 결과: 선택 기간과 다른 조건을 모두 만족하는 더미 클레임만 표시한다.
- 예외·제한: 결과가 없으면 구매자 클레임 없음 상태를 표시한다.
