# 마켓·진행단계·접수주체·유형·상태 필터

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 목록 상단 필터 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 필터값 선택 → 모든 선택 조건 결합 → 목록·건수 갱신
- 상태 변화: 유형을 바꾸면 해당 유형에서 유효하지 않은 세부 상태를 전체로 초기화한다.
- 처리 결과: 네이버·쿠팡, 신규요청·처리중·완료, 구매자 신청·판매자 직접취소, 취소·반품·교환과 세부 상태를 조합해 조회한다.
- 예외·제한: 현재 더미데이터에 없는 상태도 선택한 클레임 유형에서 가능한 상태라면 선택지로 유지한다.
