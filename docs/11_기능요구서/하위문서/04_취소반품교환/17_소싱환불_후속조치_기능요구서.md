# 소싱환불 후속조치

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 클레임 상세의 소싱 구매 후속조치 영역
- 노출 조건: 클레임 주문에 결제된 소싱상품이 있고 교환이 아닌 경우 표시한다.
- 실행 흐름: 마켓 클레임 상태 확인 → 소싱 구매 회수 필요 여부 확인 → 소싱환불 요청 → 진행상태 확인
- 상태 변화: 후속조치를 요청 대기·처리 중·완료·실패·검토 필요·결과 확인 필요 중 하나로 변경한다.
- 처리 결과: 마켓 클레임과 소싱 환불의 상태를 별도로 확인한다.
- 예외·제한: 소싱환불 작업은 마켓 클레임 상태를 바꾸지 않으며 실제 환불을 실행하지 않는다.
