# 교환품 재배송·교환 송장 등록

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 네이버 재배송대기 또는 쿠팡 교환 재배송대기 상세
- 노출 조건: 교환 상품의 회수·입고 확인이 끝난 경우 표시한다.
- 실행 흐름: 재배송 작업 선택 → 택배사·재배송 송장번호 입력 → 확정
- 상태 변화: 더미 클레임을 교환 재배송중으로 변경하고 재배송정보와 이력을 저장한다.
- 처리 결과: 상세의 회수 배송과 별도 영역에 교환 재배송정보를 표시한다.
- 예외·제한: 택배사와 송장번호 중 하나라도 없으면 실행할 수 없다.
