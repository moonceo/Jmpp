# 처리기한 필터

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 목록 상단 처리기한 필터
- 노출 조건: 항상 표시한다.
- 실행 흐름: 전체·기한 초과·24시간 이내 선택 → 현재시각과 마감시각 비교 → 목록 갱신
- 상태 변화: 선택한 기한 조건을 유지한다.
- 처리 결과: 기한 초과는 마감시각이 지난 건, 24시간 이내는 현재 이후 24시간 안에 마감되는 건만 표시한다.
- 예외·제한: 이미 기한이 지난 건을 `24시간 이내`에 포함하지 않는다.
