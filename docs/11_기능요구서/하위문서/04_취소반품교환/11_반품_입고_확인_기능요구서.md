# 반품 입고 확인

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 쿠팡 반품 미확인 상세
- 노출 조건: 반품 상품이 더미 회수완료이고 입고 미확인 상태일 때 표시한다.
- 실행 흐름: 입고 확인 → 상품·수량 확인 → 확정
- 상태 변화: 반품 입고확인 상태로 변경하고 이력을 추가한다.
- 처리 결과: 다음 작업으로 반품 승인을 제공한다.
- 예외·제한: 회수정보가 없으면 실행하지 않고 확인 안내를 표시한다.
