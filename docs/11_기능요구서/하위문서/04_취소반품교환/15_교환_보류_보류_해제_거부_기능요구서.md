# 교환 보류·보류 해제·거부

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 교환 상세의 현재 작업 영역
- 노출 조건: 회수완료·재배송대기에서는 보류, 보류 상태에서는 해제·거부를 표시한다.
- 실행 흐름: 작업 선택 → 사유 또는 이전 상태 확인 → 확정
- 상태 변화: 교환보류, 직전 상태 복귀 또는 교환거부로 변경하고 이력을 추가한다.
- 처리 결과: 변경된 상태에서 가능한 다음 작업만 표시한다.
- 예외·제한: 보류·거부 사유가 필요한 작업은 빈 사유로 실행할 수 없다.
