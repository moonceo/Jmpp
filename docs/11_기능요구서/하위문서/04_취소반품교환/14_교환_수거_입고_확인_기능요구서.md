# 교환 수거·입고 확인

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 네이버 교환 회수중 또는 쿠팡 교환 회수완료 상세
- 노출 조건: 마켓·상태에 맞는 수거 완료 또는 입고 확인 작업이 필요할 때 표시한다.
- 실행 흐름: 수거 완료 또는 입고 확인 → 대상 상품·수량 확인 → 확정
- 상태 변화: 교환을 회수완료 또는 재배송대기로 변경하고 이력을 추가한다.
- 처리 결과: 다음 단계인 교환품 재배송 또는 교환 송장 등록을 제공한다.
- 예외·제한: 회수 대상 수량이 없으면 실행하지 않는다.
