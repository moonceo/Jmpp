# 이미출고 처리

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 쿠팡 취소 상세의 현재 작업 영역
- 노출 조건: 취소 요청 주문이 더미 출고 이후인 경우 표시한다.
- 실행 흐름: 이미출고 처리 → 출고정보 확인 → 처리 확정
- 상태 변화: 취소 요청을 반품 후속확인 상태로 변경하고 이력을 추가한다.
- 처리 결과: 취소 완료로 표시하지 않고 회수 또는 반품 절차가 필요함을 표시한다.
- 예외·제한: 미출고 주문에는 제공하지 않는다.
