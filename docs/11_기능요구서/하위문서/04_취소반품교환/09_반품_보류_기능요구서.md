# 반품 보류

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 네이버 반품 상세의 현재 작업 영역
- 노출 조건: 회수대기·회수중·회수완료 상태에서 보류가 필요할 때 표시한다.
- 실행 흐름: 반품 보류 → 보류 사유 입력 → 확정
- 상태 변화: 더미 클레임을 반품보류로 변경하고 이전 상태와 사유를 이력에 남긴다.
- 처리 결과: 반품 승인 기능을 잠그고 보류 해제·반품 거부를 제공한다.
- 예외·제한: 사유가 없으면 실행할 수 없다.
