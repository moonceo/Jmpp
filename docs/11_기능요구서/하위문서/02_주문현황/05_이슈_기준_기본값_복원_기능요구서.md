# 이슈 기준 기본값 복원

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 이슈 기준 설정 모달
- 노출 조건: 설정 모달이 열려 있을 때 표시한다.
- 실행 흐름: `기본값 복원` 선택 → 모든 이슈 기준 활성화 → 적용 선택
- 상태 변화: 적용 전에는 화면 목록을 변경하지 않고 모달의 임시 선택값만 바꾼다.
- 처리 결과: 적용 후 모든 정의된 이슈가 다시 판정 대상이 된다.
- 예외·제한: 기본값 복원 후 모달을 취소하면 기존 저장값을 유지한다.
