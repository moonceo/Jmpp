# 이슈만 보기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 검색 영역의 이슈 필터
- 노출 조건: 항상 표시한다.
- 실행 흐름: 이슈만 보기 ON → 현재 이슈 기준으로 주문 재판정 → 이슈 주문만 집계·표시
- 상태 변화: OFF이면 정상 주문을 포함하고 ON이면 정상 주문을 제외한다.
- 처리 결과: 상태별 전체 건수와 목록이 동일한 필터 결과를 사용한다.
- 예외·제한: 사용자가 `이슈 아님`으로 제외했거나 미루기 중인 주문은 이슈만 보기에서 제외한다.
