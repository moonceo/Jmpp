# 이슈 기준 설정

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 상단 `이슈 기준 설정` 버튼과 설정 모달
- 노출 조건: 항상 표시한다.
- 실행 흐름: 설정 열기 → 통관부호·처리보류·클레임·소싱환불·역마진 기준 ON/OFF → 적용
- 상태 변화: 적용한 기준으로 상태별 처리 필요 건수와 주문별 사유를 다시 계산한다.
- 처리 결과: 선택한 기준만 이슈 판정에 사용한다.
- 예외·제한: 모달을 닫거나 취소하면 변경 전 기준을 유지한다.
