# 주문현황 새로고침

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상단 검색·필터 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 새로고침 선택 → 더미 주문과 미루기 만료 여부 재판정 → 갱신시각·상태 건수·목록 갱신
- 상태 변화: 검색어, 선택 상태와 이슈 기준은 유지한다.
- 처리 결과: 사용자는 마지막 갱신시각과 최신 판정 결과를 확인한다.
- 예외·제한: 현재 프로토타입은 데이터 재판정 없이 갱신시각만 변경하는 불일치가 있다.
