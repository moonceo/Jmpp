# 2시간 미루기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 이슈 주문 행의 작업 영역
- 노출 조건: 현재 판정된 이슈가 있는 주문에 표시한다.
- 실행 흐름: `2시간 미루기` 선택 → 미루기 종료시각 기록 → 현재 목록에서 숨김
- 상태 변화: 주문 상태는 유지하고 이슈 노출만 일시 중지한다.
- 처리 결과: 종료시각 이후 재판정 시 이슈가 남아 있으면 다시 표시한다.
- 예외·제한: 현재 프로토타입은 시간이 지나도 자동 복귀하지 않으므로 새로고침 또는 재진입 시 재판정이 필요하다.
