# 처리 필요 사유 보기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 주문 목록의 `처리 필요` 항목
- 노출 조건: 모든 주문에 표시한다.
- 실행 흐름: 이슈 기준과 주문값 비교 → 일치하는 모든 이슈명과 상세 사유 표시
- 상태 변화: 이슈 기준이 바뀌면 표시 내용을 다시 계산한다.
- 처리 결과: 이슈 주문은 모든 조치 사유를, 정상 주문은 `정상 진행`을 표시한다.
- 예외·제한: 여러 이슈가 동시에 있으면 숨기지 않고 각각 구분해 표시한다.
