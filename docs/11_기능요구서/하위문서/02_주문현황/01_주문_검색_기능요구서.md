# 주문 검색

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 주문현황 상단 검색 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 주문번호·상품명·수령자·연락처·스토어명 입력 → 일치 주문 검색 → 상태별 건수와 선택 상태 목록 동시 갱신
- 상태 변화: 검색어를 변경하거나 지우면 집계와 목록을 즉시 다시 계산한다.
- 처리 결과: 검색 조건과 이슈 조건을 모두 만족하는 주문만 표시한다.
- 예외·제한: 결과가 없으면 기존 주문을 유지하지 않고 빈 상태를 표시한다.
