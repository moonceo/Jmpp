# 주문 흐름 상태 선택

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 주문 흐름 상태표
- 노출 조건: 모든 상태를 건수와 관계없이 표시한다.
- 실행 흐름: 상태 선택 → 선택 강조 → 해당 상태 주문 목록 표시
- 상태 변화: 선택 상태를 바꾸고 목록의 체크·펼침 상태는 초기화한다.
- 처리 결과: 전체 건수와 처리 필요 건수를 함께 확인한다.
- 예외·제한: 0건 상태도 선택할 수 있으며 빈 상태를 표시한다.
