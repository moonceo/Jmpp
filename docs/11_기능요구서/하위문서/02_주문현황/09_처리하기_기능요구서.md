# 처리하기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 모든 주문 행의 작업 영역
- 노출 조건: 주문에 연결할 수 있는 다음 화면이 있을 때 표시한다.
- 실행 흐름: `처리하기` 선택 → 주문 상태를 이동 규칙에 매핑 → 주문수집 탭 또는 취소·반품·교환 화면으로 이동
- 상태 변화: 주문현황의 주문 상태는 변경하지 않는다.
- 처리 결과: 이동한 화면에서 해당 단계의 처리 기능을 확인한다.
- 예외·제한: 이동 대상이 없는 외부 배대지 세부 상태는 발송대기 화면으로 이동하며 정확한 탭 매핑은 프로토타입 범위에서 고정한다.
