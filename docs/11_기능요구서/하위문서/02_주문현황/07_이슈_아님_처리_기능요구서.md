# 이슈 아님 처리

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 이슈 주문 행의 작업 영역
- 노출 조건: 현재 판정된 이슈가 있는 주문에 표시한다.
- 실행 흐름: `이슈 아님` 선택 → 제외 확인 → 현재 이슈 목록에서 제거
- 상태 변화: 주문 자체 상태는 바꾸지 않고 현재 브라우저의 이슈 제외 상태만 저장한다.
- 처리 결과: 이슈만 보기 목록과 처리 필요 건수에서 해당 주문을 제외한다.
- 예외·제한: 이슈 제외는 현재 브라우저의 데모 초기화 전까지 유지한다.
