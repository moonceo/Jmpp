# 기능별 하위문서 목록

화면별 상위 문서에서 분리한 총 119개 기능의 상세 요구사항이다. 기능은 주문관리 핵심 업무 필요성에 따라 `필수`, `중요`, `낮음`으로 분류한다.

이 문서는 전체 기능 수와 화면별 중요도 분포를 비교할 때 사용한다. 실제 기능을 검토할 때는 화면명을 선택해 해당 화면의 `00_기능목록.md`로 이동한 뒤 `필수 → 중요 → 낮음` 순으로 상세 문서를 확인한다. 화면의 전체 흐름을 모르면 먼저 표의 `상위 화면 문서`를 확인한다.
