# 마켓 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 조회 조건 하단의 마켓 선택 목록
- 노출 조건: 항상 표시한다.
- 실행 흐름: 전체 마켓 또는 단일 마켓 선택 → 조회
- 상태 변화: 조회 후 선택 마켓의 주문만 요약·미리보기·다운로드 대상에 포함한다.
- 처리 결과: 사용자는 마켓별 장부 또는 전체 통합 장부를 생성할 수 있다.
- 예외·제한: 선택 마켓의 주문이 없으면 0원·0건과 빈 미리보기를 표시하고 다운로드를 비활성화한다.
