# 직접 입력 비용 반영

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 데이터 표의 `비고` 다음 맨 오른쪽 비고정 연필 아이콘 버튼, 주문수집 상세 `처리하기`의 `비용 추가`
- 입력 대상: 비용 관리 화면에 국제배송비, 화물택배비, 관부가세를 표시하고 자동으로 계산되지 않은 항목만 입력할 수 있다. 구매금액(원화)은 소싱 결제 전 주문에만 표시한다.
- 입력 항목: 구매금액(원화), 국제배송비, 화물택배비, 관부가세
- 자동 항목 제외: 상품URL, 주문·구매·배송 식별정보처럼 프로그램이 소싱·주문 데이터에서 항상 확인할 수 있는 값은 직접 입력 목록에 표시하지 않는다.
- 실행 흐름: 비용 관리 열기 → 현재 정산·비용·예상 마진 확인 → 비용 입력 → 반영 후 예상 마진 확인 → 저장
- 수정 방식: 네 비용을 한 화면에서 수정하며, 입력값을 비우고 저장하면 해당 직접 입력값을 삭제한다. 자동 수집값에는 영향을 주지 않는다.
- 구매금액 표시: `sourcingLifeActualPayment`가 있는 소싱 결제 완료 주문은 구매금액 입력 행을 표시하지 않는다. 실제 결제 전 주문은 예상원가가 있어도 구매금액을 직접 입력할 수 있다.
- 계산 우선순위: 소싱 결제 완료 주문은 실제 결제금액을 사용한다. 미결제 주문은 직접 입력 구매금액을 예상원가보다 우선 사용한다.
- 자동값 표시: 구매금액 이외의 자동 수집 비용은 현재 계산과 입력 영역에 표시하되 입력란을 잠가 수정할 수 없게 한다.
- 예상값 표시: 입력 중인 비용을 기준으로 반영 후 예상 마진과 마진율을 실시간 계산한다.
- 계산 기준: 직접 입력 구매금액을 원가로 사용하고 국제배송비·화물택배비·관부가세를 추가 비용으로 차감한다.
- 반영 범위: 주문·매출·마진·마진율, 장부 데이터 38열과 엑셀 다운로드에 같은 값을 사용한다.
- 반영 설정: 장부 조회 설정 모달의 `직접 입력 반영`이 ON일 때만 입력값을 집계, 장부 데이터와 엑셀에 적용한다.
- 설정 OFF: 입력값은 삭제하지 않고 브라우저에 보관하며 자동 수집값만 사용해 장부를 다시 계산한다.
- 확정 조건: 자동 구매금액이 없더라도 직접 입력 구매금액이 있으면 마진 확정 주문으로 본다.
- 저장 범위: 현재 프로토타입은 브라우저 로컬 저장소에 보관하며 운영 DB 동기화는 제공하지 않는다.
- 예외·제한: 자동 비용값이 존재하는 항목은 직접 입력으로 덮어쓸 수 없고, 금액은 0 이상의 숫자만 허용한다. 이전에 저장된 비계산 직접 입력 항목은 저장소 갱신 시 제거한다.
