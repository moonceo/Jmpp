# 조회 월 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 조회 조건 영역
- 노출 조건: 연도 선택과 함께 항상 표시한다.
- 실행 흐름: 1월부터 12월 중 선택 → 주문일 기준 더미 주문 재선정 → 요약·미리보기 갱신
- 상태 변화: 선택 월을 유지한다.
- 처리 결과: 연도와 월을 모두 만족하는 주문만 표시한다.
- 예외·제한: 다른 월의 고정 데이터를 재사용하지 않는다.
