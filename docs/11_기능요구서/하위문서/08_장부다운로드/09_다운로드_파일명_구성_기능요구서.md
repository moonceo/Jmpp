# 다운로드 파일명 구성

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 다운로드 완료 안내와 생성 파일
- 노출 조건: 파일 생성 성공 시 적용한다.
- 실행 흐름: 월별 조회는 `YYYYMM`, 기간 조회는 `YYYYMMDD-YYYYMMDD` 형식으로 변환 → 파일명 생성
- 상태 변화: 화면 데이터는 변경하지 않는다.
- 처리 결과: 월별 조회는 `commerce-life_ledger_YYYYMM.xlsx`, 기간 조회는 `commerce-life_ledger_YYYYMMDD-YYYYMMDD.xlsx`로 기간을 확인한다.
- 예외·제한: 화면에 적용된 조회 기간과 파일명의 기간이 다르면 다운로드를 완료 처리하지 않는다.
