# 조회 기간 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 조회 조건 상단의 `월별 조회`, `기간 조회` 탭과 날짜 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 조회 방식 선택 → 연·월 또는 시작일·종료일 입력 → 필요 시 빠른 기간 선택 → 조회
- 상태 변화: 조회를 실행하면 적용된 조회 기간을 화면 우측에 표시하고 요약·미리보기·다운로드 대상을 함께 갱신한다.
- 처리 결과: 주문일이 시작일과 종료일을 모두 포함하는 범위의 주문만 제공한다.
- 예외·제한: 시작일이 종료일보다 늦으면 조회하지 않고 날짜 확인 안내를 표시한다.
