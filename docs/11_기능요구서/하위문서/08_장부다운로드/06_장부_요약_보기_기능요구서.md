# 장부 요약 보기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 조회 도구막대 아래 집계 줄. 화면에는 `요약` 제목을 표시하지 않는다.
- 노출 조건: 화면 진입 시 항상 표시한다.
- 실행 흐름: 모든 조회 조건과 직접 입력 비용 적용 → 결제배송비에서 3.3% 차감 후 수익 반영 → 주문·매출·마진 합산 → 마진율 계산
- 상태 변화: 조건 변경 시 로딩 후 새로운 값을 표시한다.
- 처리 결과: `정산예정금액 + (결제배송비 - 결제배송비 × 3.3%) - 구매금액(원화) - 국제배송비 - 화물택배비 - 관부가세`를 마진으로 표시하며, 마진율은 표시 마진을 표시 매출로 나눈 동일 기준을 사용한다.
- 예외·제한: 총 매출이 0이면 마진율을 0%로 표시하고 0으로 나누지 않는다.
