# 취소·반품 제외

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 조회 도구막대의 설정 아이콘 모달
- 노출 조건: 항상 표시한다.
- 실행 흐름: 조건 ON/OFF → 주문 클레임 상태 확인 → 대상 주문 재선정
- 상태 변화: ON이면 취소·반품 주문을 요약·미리보기·다운로드 대상에서 모두 제외한다.
- 처리 결과: 화면과 파일이 동일한 제외 기준을 사용한다.
- 예외·제한: 조건명이 취소·반품 제외이므로 교환 주문은 제외하지 않는다.
