# 엑셀 다운로드

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 화면의 `엑셀 다운로드`
- 노출 조건: 다운로드할 미리보기 행이 1건 이상일 때 활성화한다.
- 실행 흐름: 다운로드 선택 → 적용된 조회 조건 확정 → 파일 생성 중 표시 → 38열 장부 파일 생성 → 다운로드 시작 → 완료 안내
- 상태 변화: 생성 중에는 중복 다운로드를 막고 완료 후 버튼을 다시 활성화한다.
- 처리 결과: 미리보기와 동일한 주문·금액을 원본 장부의 38개 열 순서와 헤더 색상 구간으로 구성한 `.xlsx` 파일을 제공한다.
- 예외·제한: 자동·직접 입력값이 모두 없는 필드는 빈 셀로 둔다. 직접 입력값은 화면과 동일한 열에 반영하며, 파일 생성에 실패하면 완료 안내를 표시하지 않고 다시 시도 안내를 표시한다.
