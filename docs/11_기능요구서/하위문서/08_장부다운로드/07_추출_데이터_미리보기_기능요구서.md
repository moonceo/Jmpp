# 추출 데이터 미리보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 장부 집계 줄 아래 데이터 표
- 노출 조건: 화면 진입 시 항상 표시한다.
- 실행 흐름: 조회 조건 적용 → 다운로드 엑셀과 같은 38개 열 및 조회 결과 전체 행 표시
- 상태 변화: 조건이나 직접 입력값 변경 시 행과 집계 금액을 함께 갱신한다.
- 처리 결과: 사용자는 다운로드 전에 엑셀에 기록될 전체 주문 정보와 계산값을 확인한다.
- 표시 규칙: 열 이름·순서·값은 엑셀 생성에 사용하는 공통 헤더 및 행 변환 결과와 동일해야 한다.
- 탐색 방식: 표 영역 안에서 가로·세로 스크롤할 수 있고, 헤더와 첫 번째 주문일 열은 스크롤 중에도 고정한다.
- 표 제목 표시: 별도의 `장부 데이터`, `엑셀과 동일한 38개 열`, 열·행 수 안내 문구 없이 표를 바로 표시한다.
- 행별 작업: 엑셀 38열의 `비고` 다음 마지막 열에 화면 전용 `직접 입력` 아이콘을 비고정으로 표시하고 각 주문의 입력 모달을 연다.
- 예외·제한: 결과가 없으면 표 헤더를 유지하고 데이터 없음 상태를 표시한다.
