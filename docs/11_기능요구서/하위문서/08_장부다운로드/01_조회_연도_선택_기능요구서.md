# 조회 연도 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 장부 조회 조건 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 2024년·2025년·2026년 중 선택 → 해당 연도 더미 주문 재선정 → 요약·미리보기 갱신
- 상태 변화: 선택 연도를 유지하고 월과 다른 조건은 유지한다.
- 처리 결과: 선택 연도의 주문만 요약과 미리보기에 포함한다.
- 예외·제한: 해당 연도 데이터가 없으면 0원·0건과 빈 미리보기를 표시한다.
