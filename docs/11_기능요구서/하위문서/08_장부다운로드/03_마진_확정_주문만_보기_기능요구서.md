# 마진 확정 주문만 보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 장부 조회 도구막대의 설정 아이콘 모달
- 노출 조건: 항상 표시한다.
- 실행 흐름: 조건 ON/OFF → 주문별 마진 확정 여부 확인 → 요약·미리보기 갱신
- 상태 변화: ON이면 확정 주문만, OFF이면 예상 마진 주문을 포함한다.
- 처리 결과: 총 주문·매출·마진·마진율이 같은 대상 주문 기준으로 변경된다.
- 예외·제한: 소싱라이프 실제 결제금액이나 직접 입력 구매금액이 없는 주문은 확정 주문으로 간주하지 않는다.
