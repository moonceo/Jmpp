# 마진계산 보기

> 중요도: **중요**

## 기능 요구사항

- 목록 노출 위치: 주문목록의 `상품정보` 바로 다음 `결제가격/마진` 컬럼
- 목록 표시값: 결제금액, 마진율, 마진금을 한 셀에 표시한다.
- 목록 계산식: `마진금 = 결제금액 - 매칭·결제 상품금액`, `마진율 = 마진금 ÷ 결제금액 × 100`
- 목록 원가 우선순위: 실제 소싱 결제금액 → 매칭 상품 단가×매칭 수량 → 직접구매 기록 금액
- 목록 예외: 매칭 전이거나 원가를 확인할 수 없으면 결제금액은 표시하고 마진율과 마진금은 `-`로 표시한다. 결제금액이 0원이면 마진율은 0%로 처리하고, 마진금이 음수인 역마진은 경고색으로 구분한다.
- 목록 계산 범위: 플랫폼 판매수수료·소싱 이용료·환전수수료·배송비를 제외한 상품 매입 기준의 간이 마진이다.
- 상세 노출 위치: 매칭된 소싱상품이 있는 주문의 펼친 상세
- 상세 노출 조건: 원주문과 소싱상품이 모두 연결된 경우 표시한다.
- 상세 실행 흐름: 마켓 결제·정산금액 확인 → 판매수수료·상품원가·이용료·환전수수료·예상배송비 계산 → 예상 순이익·마진율 표시
- 상태 변화: 상품·수량·가격이 바뀌면 마진값을 다시 계산한다.
- 처리 결과: 목록에서는 결제가격과 상품 매입 기준 마진을 빠르게 비교하고, 펼친 상세에서는 수수료를 포함한 예상 순이익을 확인한다.
- 상세 예외·제한: 소싱 원가가 없으면 임의 금액을 계산하지 않고 계산 대기 상태를 표시한다.
