# 판매자 주문취소

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 신규주문·상품준비·발송대기의 상태별 처리 영역
- 노출 조건: 판매자 취소가 가능한 주문에만 표시하며 직접전달 방식으로 지정된 주문에는 마켓 처리 완료 여부와 관계없이 표시하지 않는다.
- 실행 흐름: 주문취소 선택 → 취소 사유·상세 사유·수량 입력 → 취소 확정
- 상태 변화: 더미 주문을 판매자취소 상태로 변경하고 일반 주문 단계에서 제외한 뒤 취소·반품·교환 목록의 완료 단계에 추가한다.
- 처리 결과: 취소 완료 안내를 표시하고 취소·반품·교환 목록에서 `접수 주체: 판매자 직접취소`로 조회할 수 있게 한다.
- 예외·제한: 직접전달 방식이 지정된 주문은 직접전달 실행 전이라도 판매자 주문취소를 실행할 수 없다. 구매자 취소 신청과 같은 목록에서 관리하지만 접수 주체를 반드시 구분한다. 같은 주문을 다시 취소하면 목록 행을 중복 생성하지 않고 기존 판매자 취소 기록을 갱신한다.
