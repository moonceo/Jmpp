# 배송추적

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 결제완료 이후 주문 상세의 `처리하기`
- 노출 조건: 배송 이력이 생성된 주문에 표시한다.
- 실행 흐름: 배송추적 선택 → 결제완료·중국배송·통관·국내배송·배송완료 누적 이력 표시
- 상태 변화: 조회만 수행하며 주문 상태를 변경하지 않는다.
- 처리 결과: 현재 배송 단계와 단계별 일시·위치·송장정보를 확인한다.
- 예외·제한: 주문 목록에는 배송추적을 표시하지 않는다. 반품·교환 이력은 원배송 이력과 구분해 표시하며 이력이 없는 단계는 생성하지 않는다.
