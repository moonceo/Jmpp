# 마켓·스토어 필터

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상단 검색 입력창 오른쪽의 마켓·스토어 필터
- 노출 조건: 항상 표시하며 전체 마켓과 사용자가 연동한 모든 더미 스토어를 제공한다.
- 실행 흐름: 필터 열기 → 마켓 복수 선택 → 선택 마켓의 스토어 선택 → 목록 갱신
- 상태 변화: 마켓을 선택하지 않으면 모든 스토어를 활성화하고, 마켓을 선택하면 해당 마켓 스토어만 활성화한다.
- 처리 결과: 선택 마켓 또는 스토어에 해당하는 주문만 표시한다.
- 예외·제한: 현재 탭에 주문이 없는 스토어도 목록에서 숨기지 않으며 선택 결과는 0건으로 표시한다. `전체` 선택 시 마켓과 스토어 선택을 모두 해제한다.
