# 다시 소싱하기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 환불 주문 상세보기의 `처리하기`
- 노출 조건: 소싱환불이 완료됐고 마켓 배송이 시작되지 않은 주문에 표시한다.
- 실행 흐름: 다시 소싱하기 → 기존 `소싱하기`와 동일한 상품 검색·옵션·수량 선택 → 새 상품 매칭 → 배대지 선택 → 구매대행 신청 → 정상 결제 절차 진행
- 상태 변화: 기존 환불 이력은 유지하고 이전 소싱상품 연결·결제·송장 상태를 새 소싱 절차에 맞게 초기화한 뒤 상품준비 단계로 변경한다.
- 처리 결과: 새로 매칭한 상품으로 소싱하기의 정상 절차를 다시 진행한다.
- 예외·제한: 환불 진행 중이거나 마켓 상태가 배송중·배송완료·구매확정이면 기능을 표시하지 않는다. 재소싱 전에는 기존 환불완료 주문의 출고 관련 기능을 차단한다.
