# 가격 인하 요청

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 결제대기 상태의 중국 판매자 채팅 영역
- 노출 조건: 결제 전이며 가격 인하 요청이 진행 중이지 않을 때 `깎아줘`를 표시한다.
- 실행 흐름: 깎아줘 선택 → 요청 확인 → 요청 중 상태 → 더미 판매자 결과 반영 또는 요청 취소
- 상태 변화: 요청 중에는 결제를 잠그고 취소 또는 결과 반영 후 다시 활성화한다.
- 처리 결과: 승인된 더미 가격은 예상 비용과 결제금액에 반영한다.
- 예외·제한: 결제완료 후에는 새 가격 인하 요청을 제공하지 않는다.
