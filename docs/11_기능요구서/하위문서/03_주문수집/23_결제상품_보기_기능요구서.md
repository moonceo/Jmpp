# 소싱상품관리

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 소싱상품 매칭 완료 이후 주문 상세의 `처리하기`
- 노출 조건: 주문에 소싱상품이 매칭된 순간부터 표시한다.
- 실행 흐름: 소싱상품관리 → 매칭 상품·옵션·수량 확인 → 단계에 따라 결제금액·소싱 주문번호·국내송장·판매자 채팅 확인 → 환불 대상이면 구매대행 신청 상품 영역의 `반품·환불 신청`, `환불 진행` 또는 `환불 내역` 선택 → 닫기
- 상태 변화: 소싱상품관리 조회만으로는 주문 상태를 변경하지 않는다. 내부의 결제·환불 기능을 실행한 경우에는 해당 기능요구서의 상태 변경 기준을 적용한다.
- 처리 결과: 매칭 직후부터 소싱상품 정보를 계속 확인하고, 결제대기에서는 결제와 판매자 채팅을 이용하며 결제완료 이후에는 결제정보·대화 이력과 소싱상품 환불 신청·진행·내역을 같은 화면에서 관리한다.
- 예외·제한: 결제 전에는 아직 생성되지 않은 결제금액·소싱 주문번호·국내송장을 표시하지 않는다. 결제완료 이후에는 재결제 기능을 제공하지 않는다.
- 예외·제한: 주문 목록에는 `소싱상품관리`를 표시하지 않는다. 목록과 주문 상세보기의 `처리하기`에는 환불 관련 버튼을 별도로 표시하지 않는다.
