# 기간 빠른 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 상단 검색 영역의 오늘·3일·7일·30일 버튼
- 노출 조건: 항상 표시한다.
- 실행 흐름: 기간 선택 → 주문일시 기준 시작·종료일 계산 → 목록 필터 적용
- 상태 변화: 선택한 기간 버튼을 강조하고 직접 입력 날짜는 초기화한다.
- 처리 결과: 선택 기간과 다른 검색·마켓·스토어·상태 조건을 모두 만족하는 주문만 표시한다.
- 예외·제한: 결과가 없으면 주문 0건을 표시한다.
