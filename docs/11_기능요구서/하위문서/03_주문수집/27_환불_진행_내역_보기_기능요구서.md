# 환불 진행·내역 보기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 환불 신청 이후 주문 상세보기의 `처리하기 > 소싱상품관리 > 구매대행 신청 상품` 영역. 목록과 주문 상세보기의 `처리하기`에는 별도 표시하지 않는다.
- 노출 조건: 환불 요청 또는 완료 이력이 있는 주문에 표시한다.
- 버튼명: 환불 처리 중에는 `환불 진행`, 환불이 종료되면 `환불 내역`으로 표시한다.
- 실행 흐름: 소싱상품관리 → 환불 진행 또는 환불 내역 선택 → 신청정보·판매자 판단·중국 반품정보·환불금액·상태 이력 표시
- 상태 변화: 조회만 수행하며 환불이나 주문 상태를 변경하지 않는다.
- 처리 결과: 환불 요청부터 완료·거절까지 누적 결과를 확인한다.
- 예외·제한: 환불이 거절되거나 실패한 경우 사유를 숨기지 않고 다음 가능한 조치를 함께 표시한다.
