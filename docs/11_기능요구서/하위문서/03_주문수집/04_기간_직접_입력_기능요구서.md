# 기간 직접 입력

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 기간 버튼의 `직접 입력`과 날짜 선택 팝오버
- 노출 조건: `직접 입력`을 선택하면 시작날짜와 끝나는날짜를 표시한다.
- 실행 흐름: 직접 입력 선택 → 시작·종료일 입력 → 날짜 범위 적용
- 상태 변화: 직접 입력 기간을 선택 상태로 유지한다.
- 처리 결과: 시작일 이상·종료일 이하의 주문만 표시한다.
- 예외·제한: 시작일이 종료일보다 늦으면 적용하지 않고 날짜 확인 안내를 표시해야 한다.
