# 주문확인

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 신규주문 목록·주문 상세의 `처리하기`와 선택 주문 일괄 처리 영역
- 노출 조건: 신규주문이며 필수 주문정보를 확인할 수 있을 때 표시한다.
- 실행 흐름: 주문확인 선택 → 즉시 주문확인 처리 → 상품준비 이동
- 상태 변화: 주문 단계를 신규주문에서 상품준비로 변경하고 처리된 주문을 강조한다. 기존 상품 매칭이 있으면 유지하고, 매칭이 없으면 소싱필요 상태를 유지한다.
- 처리 결과: 매칭 여부와 관계없이 상품준비 탭에서 다음 소싱 절차를 진행할 수 있다.
- 예외·제한: 통관부호 오류가 있어도 주문확인은 가능하지만 상품준비에서 소싱하기는 제공하지 않는다. 일괄 주문확인은 선택한 신규주문만 처리한다.
