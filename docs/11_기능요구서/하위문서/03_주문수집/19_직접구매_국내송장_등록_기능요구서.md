# 직접구매 배송처리

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상품준비 주문 상세의 `처리하기`
- 노출 조건: 소싱라이프 결제를 사용하지 않고 직접 구매로 처리할 더미 주문에 표시한다.
- 실행 흐름: 직접구매 배송처리 → 연결 스토어의 기본 배송중 처리 방식 확인 → 직접구매 완료 저장 → 발송대기로 이동
- 기본 방식: 마켓연동에서 스토어별로 저장한 직접전달·해외기타배송·송장입력 값을 사용한다. 직접구매 배송처리에서는 방식을 다시 선택하지 않는다.
- 입력 조건: 직접구매 배송처리 모달에서는 국내 택배사·국내송장번호와 해외 운송장번호를 입력하지 않는다.
- 상태 변화: 직접구매 완료와 스토어 기본 방식만 저장하고 실제 마켓 상태는 변경하지 않은 채 발송대기로 이동한다.
- 후속 처리: 직접구매 완료·발송대기 주문은 송장 유무와 관계없이 상세 `처리하기 → 운송장 수정`을 표시한다. 기본값이 송장입력인 주문은 국내 택배사와 송장번호를 입력하거나 기존 값을 수정한 뒤, 별도의 `배송중 처리`에서 마켓 발송을 실행한다. 기본값이 직접전달·해외기타배송인 주문은 발송대기의 `배송중 처리`에서 저장된 기본값을 사용한다.
- 처리 결과: 직접구매 완료, 운송장 저장, 실제 마켓 발송을 각각 분리해 기록한다. 운송장 수정만으로는 발송대기를 유지하고 배송중 처리가 완료된 시점부터 배송중에서 관리한다.
- 예외·제한: 스토어 기본값이 없으면 송장입력을 기본값으로 사용한다. 직접구매 완료만으로 실제 마켓을 배송중으로 간주하지 않는다. 해외기타배송은 배송중 처리 단계에서 해외 운송장번호가 있어야 실행한다.
