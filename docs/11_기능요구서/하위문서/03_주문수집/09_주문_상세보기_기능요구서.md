# 주문 상세보기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 주문 목록 행
- 노출 조건: 모든 주문 행에서 제공한다.
- 실행 흐름: 행 선택 → 상세 펼침 → 왼쪽에서 구매자·배송정보와 택배정보 확인 → 가운데에서 주문상품 → 소싱상품 순으로 비교 → 매출·정산 → 예상 소싱비용 → 예상 순이익·마진율 순으로 확인 → 오른쪽 처리하기에서 비용 추가와 상태별 작업 확인
- 상태 변화: 한 주문의 상세를 열어도 주문 상태는 변경하지 않는다.
- 처리 결과: 택배정보에는 국내 송장번호와 중국 송장번호를 구분해 표시한다. 마켓에서 직접전달로 처리한 주문은 `직접전달`, 해외기타배송으로 처리한 주문은 `해외기타배송` 배지만 표시한다. 해외기타배송 처리에 사용한 임의 해외 운송장번호와 해외 택배사명은 목록과 펼친 상세에 표시하지 않는다. 넓은 화면에서는 구매자·배송정보 22%, 상품 비교와 마진계산 60%, 오른쪽 `처리하기` 18%를 기준으로 표시하며 왼쪽과 오른쪽은 각각 최소 320px, 260px을 확보한다. `처리하기`의 비용 추가는 해당 주문에서 자동 수집되지 않은 장부 항목만 입력 목록으로 제공한다. 작은 화면에서는 각 영역을 한 줄씩 표시한다.
- 예외·제한: 매칭된 소싱상품이 없으면 상품 비교와 마진계산을 표시하지 않는다.
