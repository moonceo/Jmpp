# 배송정보 수정

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 신규주문·상품준비·발송대기 주문 상세 왼쪽의 `구매자 · 배송정보` 영역. `처리하기`에는 중복 표시하지 않는다.
- 노출 조건: 배송정보를 수정할 수 있는 주문 단계에서 표시한다.
- 실행 흐름: 배송정보 수정 → 수령인명·연락처·우편번호·주소·상세주소·배송메시지·개인통관부호 편집 → 저장
- 상태 변화: 더미 주문의 배송정보를 교체하고 통관부호 오류 여부를 다시 판정한다.
- 처리 결과: 정상 정보로 저장되면 차단됐던 소싱 기능을 다시 제공한다.
- 예외·제한: 필수값 누락 또는 개인통관부호 형식 오류가 있으면 저장하지 않고 입력값 확인 안내를 표시한다.
