# 상태 필터

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상단 마켓·스토어 필터 바로 오른쪽의 `상태 전체` 드롭다운
- 노출 조건: 모든 주문 단계 탭에서 표시한다.
- 실행 흐름: 상태 드롭다운 열기 → 탭별 가능한 상태 선택 → 목록 갱신
- 상태 변화: 선택 상태를 유지하되 다른 탭에서 유효하지 않으면 `상태 전체`로 초기화한다.
- 처리 결과: 현재 주문에 존재하는지와 관계없이 탭별 전체 가능한 상태를 선택지로 유지한다.
- 예외·제한: 선택 상태의 주문이 0건이어도 선택지를 숨기지 않는다.
