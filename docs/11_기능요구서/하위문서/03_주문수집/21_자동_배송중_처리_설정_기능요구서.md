# 자동 배송중 처리 설정

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 상품준비·발송대기 탭의 작업 영역
- 노출 조건: 해당 탭에서 표시한다.
- 실행 흐름: ON/OFF 변경 → 이후 소싱라이프 결제 성공 시 적용 → 주문이 연결된 스토어의 기본 배송중 처리 방식 확인 → 방식별 필수정보 검증 → 마켓 발송 처리
- 상태 변화: ON이면 소싱라이프 구매 완료가 확정된 다음 스토어 기본값으로 마켓 발송과 내부 배송중 전환을 함께 시연하고 OFF이면 발송대기에 유지한다. 직접구매 배송처리는 자동 처리 여부와 관계없이 구매 완료 후 발송대기로 이동한다. `운송장 수정`은 송장정보만 저장하며 실제 마켓 발송은 후속 `배송중 처리`에서 실행한다.
- 처리 결과: 현재 설정 상태를 ON/OFF 문구로 표시한다.
- 예외·제한: 결제 실패·미확정이면 마켓 발송을 실행하지 않는다. 해외기타배송 기본값에 해외 운송장번호가 없거나 송장입력 기본값의 국내배송 시작·택배사·국내송장번호 조건이 충족되지 않으면 발송대기에 유지하고 사유를 안내한다. 이미 완료된 주문의 처리 결과를 소급 변경하지 않는다.
