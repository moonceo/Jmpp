# 배송중 처리

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 구매 완료된 발송대기 주문 상세·목록·화면 상단 일괄 처리 영역과, 마켓 발송은 끝났지만 내부 구매 완료 반영이 남은 주문 상세
- 노출 조건: 소싱라이프 결제 또는 직접구매 완료가 확인되고 마켓 발송이 필요한 주문에 표시한다. 매칭완료·결제대기 등 구매 미완료 주문에는 표시하지 않는다. 직접구매 배송처리에서는 구매 완료와 스토어 기본 방식만 저장한다. 택배정보가 없으면 발송대기 상세의 `운송장 수정`에서 먼저 입력한 뒤 별도의 `배송중 처리`를 실행한다.
- 실행 흐름: 배송중 처리 → 주문이 연결된 스토어의 기본값 표시 → `직접전달`·`해외기타배송`·`송장입력` 중 주문별 지원 방식 확인·변경 → 방식별 필수정보 검증 → 실제 마켓 발송 → 내부 상태 판정
- 마켓별 선택 범위:
  - 네이버: 직접전달, 해외기타배송, 송장입력
  - 11번가: 직접전달, 송장입력
  - 쿠팡·G마켓·옥션: 송장입력
- 상태 변화: 구매 완료 후 실제 마켓 발송 성공 시 마켓 축과 내부 주문을 배송중으로 변경한다. 이는 마켓 발송 처리 상태이며 실제 물류가 국내 배송을 시작했다는 뜻은 아니다. 실제 물류 단계는 소싱 진행상태와 배송추적으로 별도 표시한다. 구매만 완료되고 마켓 발송 전이면 발송대기에서 관리한다.
- 처리 결과: 완료한 마켓 처리 방식과 건수를 안내한다. 직접전달·해외기타배송으로 우선 처리한 주문은 국내배송이 시작되기 전까지 그 방식을 유지하고, 국내배송 시작 후 운송장 수정이 완료되면 송장입력 방식으로 갱신한다.
- 운영 의미: 해외구매대행에서는 구매 완료 뒤 마켓 발송기한을 맞추기 위해 직접전달 또는 해외기타배송으로 우선 처리할 수 있다. 직접전달은 송장 없이, 해외기타배송은 해외 운송장으로 처리한다. 국내송장은 배대지 주문서 생성 시 먼저 발급되지만 실제 국내배송 시작 전에는 프로그램에만 보관한다.
- 기본값 적용: 개별·일괄 처리 모두 주문이 연결된 스토어의 기본 배송중 처리 방식을 최초값으로 사용한다. 일괄 처리에서는 주문마다 각 스토어 기본값을 판정하며, 사용자가 주문에서 다른 지원 방식을 선택하면 주문 선택값을 우선한다.
- 예외·제한: 직접전달은 네이버·11번가에서만, 해외기타배송은 네이버에서만 제공한다. 쿠팡·G마켓·옥션은 송장입력 외 방식을 허용하지 않는다. 세 방식 모두 구매 완료가 필요하며, 송장입력은 국내송장 보유와 국내배송 시작이 필요하다. 단, 직접구매 완료 주문은 사용자가 `운송장 수정`에서 확인한 국내송장을 저장하면 별도 배송중 처리에서 송장입력을 실행할 수 있다. 해외기타배송은 해외 운송장번호가 추가로 필요하다. 직접구매 완료 시 이 정보가 없어도 구매 완료는 저장하지만 실제 마켓 처리는 실행하지 않는다. 기본값이 설정되어도 필수정보가 없거나 마켓이 지원하지 않으면 실행하지 않고 사유를 표시한다. 이미 마켓 배송중이면 같은 우선 발송 처리를 반복하지 않는다. 일괄 처리는 선택 주문이 있으면 선택 주문을 우선한다.

## 더미데이터 확인 범위

| 주문 | 마켓·현재 방식 | 실제 물류 단계 | 화면에서 확인할 결과 |
|---|---|---|---|
| `0036` | 네이버·직접전달 선택 예정 | 매칭완료 | 구매 미완료이므로 배송중 처리 불가 |
| `0053` | 네이버·해외기타배송 선택 예정 | 직접구매 완료 | 발송대기에서 해외 운송장 선처리 가능 |
| `0056` | 네이버·해외기타배송 선처리 완료 | 통관 중 | 내부 국내송장은 보이지만 운송장 수정 잠금 |
| `0045` | 네이버·직접전달 선처리 완료 | 직접구매 완료 | 내부 국내송장은 보이지만 운송장 수정 잠금 |
| `0057` | 네이버·직접전달 선처리 완료 | 국내 배송중 | 운송장 수정 가능 |
| `0039` | 11번가·직접전달 선처리 완료 | 국내 배송중 | 운송장 수정 가능 |
| `0058` | 11번가·송장입력 | 국내 배송중 | 크롤링 운송장 수정 완료 |
| `0059` | 쿠팡·송장입력 전용 | 통관 중 | 국내배송 전이므로 송장전송 불가 |
| `0060` | 쿠팡·송장입력 전용 | 국내 배송중 | 배송중 처리 가능 |
| `0061` | G마켓·송장입력 전용 | 국내 배송중 | 배송중 처리 가능 |
| `0062` | 옥션·송장입력 전용 | 중국 배송중 | 국내배송 전이므로 송장전송 불가 |

더미 상품명 앞에는 대괄호로 시나리오를 표시해 목록에서도 사례를 빠르게 구분한다. 발송대기에는 구매 완료 후 마켓 발송 전, 국내배송 전 송장 잠금, 국내배송 시작 후 송장전송 가능 사례를 복수로 유지한다.
