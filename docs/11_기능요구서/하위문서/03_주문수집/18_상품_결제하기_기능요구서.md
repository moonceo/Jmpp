# 상품 결제하기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 결제대기 주문의 결제상품 화면
- 노출 조건: 구매대행 신청 완료, 가격 인하 요청 종료, 필수 배송정보 정상 상태에서 표시한다.
- 실행 흐름: 상품 결제하기 → 결제수단·약관 확인 → 결제 확정 → 더미 결제완료 처리
- 상태 변화: 결제대기에서 결제완료로 변경하고 더미 소싱라이프 주문번호와 국내송장을 생성한다. 국내송장은 배대지 주문서 생성 시점부터 프로그램에 표시하지만 국내배송 시작 전에는 마켓에 전송하지 않는다. 결제 성공이 확정된 시점부터 별도 배송중 처리를 사용할 수 있다.
- 처리 결과: 자동 배송중 처리 ON이면 결제 성공 기록 뒤 직접전달·해외기타배송 등 선택한 선처리 방식을 실행한다. 송장입력은 국내배송 시작이 확인된 경우에만 실행한다. OFF이면 발송대기에 두고 사용자가 지원 방식을 선택한다. 기존 `소싱상품관리`는 유지하고 배송추적을 추가로 제공한다.
- 예외·제한: 실제 결제를 실행하지 않으며 필수 조건이 충족되지 않으면 모달을 유지하고 사유를 안내한다. 결제 실패·미확정 상태에서는 자동·수동 마켓 배송중 처리를 모두 차단한다.
