# 소싱하기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상품준비 주문의 목록 또는 상세 `처리하기`
- 노출 조건: 소싱이 필요한 주문이며 정상 형식의 개인통관부호와 배송정보가 있을 때 제공한다.
- 실행 흐름: 소싱하기 → 상품 후보·옵션·수량 확인 → 배대지 수령 프로필 선택 → 구매대행 신청 → 결제대기
- 상태 변화: 소싱 신청 전에는 소싱필요, 신청 완료 후에는 결제대기로 변경한다.
- 처리 결과: 원주문·소싱상품·예상 비용과 수익을 비교하고 결제 기능을 사용할 수 있다.
- 예외·제한: 개인통관부호가 `P`와 숫자 12자리 형식이 아니면 실행을 차단하고 배송정보 수정을 안내한다.
