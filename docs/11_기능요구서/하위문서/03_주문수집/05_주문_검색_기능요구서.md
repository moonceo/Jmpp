# 주문 검색

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상단 검색 입력창
- 노출 조건: 항상 표시한다.
- 실행 흐름: 상품명·주문번호·주문자·수령인 입력 → 부분 일치 검색 → 목록 갱신
- 상태 변화: 검색어를 지우면 다른 필터를 유지한 채 전체 검색 결과로 돌아간다.
- 처리 결과: 기간·마켓·스토어·상태 필터와 검색어를 모두 만족하는 주문을 표시한다.
- 예외·제한: 검색 결과가 없으면 기존 결과를 유지하지 않고 빈 상태를 표시한다.
