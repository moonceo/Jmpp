# 환불하기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 주문 상세보기의 `처리하기 > 소싱상품관리 > 구매대행 신청 상품` 영역. 목록과 주문 상세보기의 `처리하기`에는 환불 버튼을 별도로 표시하지 않는다.
- 버튼명: 신규 신청이 가능한 경우 `반품·환불 신청`으로 표시한다.
- 노출 조건: 소싱상품 결제가 완료되고 TaoWorld 구매 주문라인이 연결된 `결제완료·중국배송중·통관 중·국내 배송중` 주문에 표시한다.
- 실행 흐름: 소싱상품관리 → 반품·환불 신청 → 환불 유형·상품 상태·사유·CNY 요청금액·설명·이미지 입력 → 환불 신청 → 더미 판매자 승인·반품 필요 여부 확인
- 상태 변화: 신청 후 주문의 진행상태를 환불 요청 또는 환불 진행으로 변경하고 출고 관련 기능을 차단한다.
- 처리 결과: 환불 신청 모달을 닫아도 `소싱상품관리`를 유지하고 버튼을 `환불 진행`으로 변경한다. 판매자 승인 이후에는 소싱라이프 환불 시연과 동일하게, 중국 반품이 없으면 환불완료로 진행하고 중국 반품이 필요하면 반품 택배정보 입력 후 환불완료로 진행한다.
- 예외·제한: 배송완료부터는 신규 신청을 표시하지 않는다. 이미 환불을 신청한 주문은 후속 단계에서도 `환불 진행` 또는 `환불 내역`을 유지한다. 마켓 취소·반품·교환과 소싱상품 환불은 별도 이력으로 관리하며 실제 환불을 실행하지 않는다.
