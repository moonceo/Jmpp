# 매칭하기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 신규주문 목록과 주문 상세의 `처리하기`
- 노출 조건: 소싱상품이 연결되지 않은 신규주문에 표시한다.
- 실행 흐름: 매칭하기 → 이미지로 찾기 또는 직접 찾기 → 후보 상품 확인 → 옵션·수량 선택 → 원주문과 연결 → 주문확인 함께 처리
- 상태 변화: 선택 상품을 주문의 소싱상품으로 저장하고 신규주문에서 상품준비로 이동한다. 상품 비교·마진계산과 `소싱상품관리`를 표시하고 진행상태를 `매칭완료`로 변경한다. 소싱상품 결제 전에는 직접전달·해외기타배송·송장입력을 포함한 마켓 배송중 처리를 모두 제공하지 않으며 `결제완료`로 표시하지 않는다.
- 처리 결과: 별도의 주문확인 실행 없이 상품준비에서 `소싱상품관리`로 매칭 상품을 확인하고 다음 소싱 절차를 진행할 수 있다.
- 예외·제한: 직접 찾기는 키워드 또는 타오바오·소싱라이프 상품 URL을 사용하며 후보를 선택하지 않으면 기존 상태를 유지한다.
