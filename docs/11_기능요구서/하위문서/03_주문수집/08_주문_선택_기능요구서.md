# 주문 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 주문 목록의 전체 선택과 행별 선택 항목
- 노출 조건: 취소·반품·교환을 제외한 전체·신규주문·상품준비·발송대기·배송중·배송완료 주문 목록에서 제공한다.
- 실행 흐름: 행 선택 또는 전체 선택 → 선택 건수 갱신 → 일괄 기능 활성화
- 상태 변화: 탭·검색·필터 변경 시 현재 화면에 포함되지 않는 주문 선택을 해제한다.
- 처리 결과: 신규주문에서는 일괄 주문확인·주문취소 대상을 지정하고, 발송대기에서는 선택 주문 우선 배송중 처리 대상을 지정한다.
- 예외·제한: 전체·상품준비·배송중·배송완료 탭에도 선택 항목은 표시되지만 현재 화면에는 선택 주문을 사용하는 일괄 실행 버튼이 없다. 일괄 주문확인과 주문취소는 선택 주문이 없으면 실행할 수 없다. 발송대기의 배송중 처리는 선택 주문이 없으면 검색어·기간·마켓·스토어 필터 적용 전의 현재 탭·상태 조건 주문을 대상으로 실행한다.
