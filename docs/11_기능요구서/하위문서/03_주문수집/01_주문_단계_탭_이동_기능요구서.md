# 주문 단계 탭 이동

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 주문관리 상단의 전체·신규주문·상품준비·발송대기·배송중·배송완료 탭
- 노출 조건: 모든 탭을 주문 건수와 관계없이 표시한다.
- 실행 흐름: 탭 선택 → 선택 탭 강조 → 해당 단계 주문 표시 → 탭별 상태 선택지 갱신
- 상태 변화: 탭이 바뀌면 이전 탭에서만 유효한 상태 필터를 `상태 전체`로 초기화하고 행 선택과 상세 펼침을 해제한다.
- 처리 결과: 탭명 옆에 전체 더미 주문 기준 건수를 표시한다.
- 예외·제한: 0건 탭도 이동할 수 있으며 빈 목록을 표시한다.
