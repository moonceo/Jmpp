# 주문수집

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 상단 검색 영역 오른쪽의 `주문수집` 버튼
- 노출 조건: 주문관리의 모든 일반 주문 탭에서 표시한다.
- 실행 흐름: 주문수집 선택 → 수집 중 표시 → 연동된 더미 스토어별 수집 결과 생성 → 신규·갱신 건수 안내 → 주문 목록 갱신
- 상태 변화: 수집 중에는 버튼을 비활성화하고 완료 후 더미 주문과 탭 건수를 갱신한다.
- 처리 결과: 신규 수집 건수, 갱신 건수 또는 수집 결과 없음 안내를 표시한다.
- 예외·제한: 실제 마켓 주문을 호출하거나 변경하지 않으며 실패 시 기존 더미 주문을 유지하고 실패 스토어와 재시도 안내를 표시한다.
