# 상품 이미지 크게 보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 주문 목록과 상세의 주문상품·소싱상품 이미지
- 노출 조건: 표시할 이미지가 있는 상품에 제공한다.
- 실행 흐름: 상품 이미지 선택 → 원본 비율의 확대 이미지 모달 표시 → 닫기
- 상태 변화: 이미지 모달 열림 여부만 변경한다.
- 처리 결과: 작은 썸네일로 확인하기 어려운 상품을 확대해 비교한다.
- 예외·제한: 이미지 주소가 없거나 불러오지 못하면 대체 이미지를 표시하고 확대 기능을 제공하지 않는다.
