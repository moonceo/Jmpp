# 중국 판매자 채팅

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 주문 상세보기의 `처리하기 > 소싱상품관리 > 중국 판매자 채팅` 영역
- 노출 조건: 소싱상품이 매칭되어 `소싱상품관리`가 표시되고, 결제대기·결제완료 이후 더미 판매자 대화방이 생성된 주문에 표시한다.
- 실행 흐름: 채팅 열기 → 메시지 입력 → 전송 → 대화 목록에 추가
- 상태 변화: 주문 단계는 변경하지 않고 더미 대화 이력만 추가한다.
- 처리 결과: 결제 전후에 기존 대화를 계속 조회한다.
- 예외·제한: 외부 판매자에게 실제 메시지를 전송하지 않는다.
