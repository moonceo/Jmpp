# 비용 추가

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 주문수집의 펼친 주문 상세 오른쪽 `처리하기` 작업 목록 가장 아래
- 노출 조건: 모든 주문 상세에서 `비용 추가` 버튼을 표시한다.
- 입력 대상: 국제배송비, 화물택배비, 관부가세를 표시하고 해당 주문에서 자동으로 계산되지 않은 항목만 입력할 수 있다. 구매금액(원화)은 소싱 결제 전 주문에만 표시한다.
- 실행 흐름: 비용 추가 선택 → 현재 계산 확인 → 네 비용 입력 → 반영 후 예상 마진 확인 → 저장
- 결제 구분: 실제 소싱 결제금액이 생성된 주문은 구매금액 입력 행을 숨기고 실제 결제금액을 사용한다. 미결제 주문은 예상원가가 있어도 구매금액을 직접 입력·수정할 수 있으며 직접 입력값을 예상원가보다 우선 계산한다.
- 자동값 표시: 구매금액 이외의 자동 수집 비용은 입력란을 잠가 수정하지 못하게 하고, 입력 중인 비용은 예상 마진과 마진율에 실시간 반영한다.
- 상태 변화: 저장 즉시 같은 브라우저의 장부 화면, 집계 금액과 엑셀 다운로드에 반영한다.
- 비용 계산: 직접 입력 구매금액·국제배송비·화물택배비·관부가세는 주문 마진에서 차감한다.
- 제외 항목: 상품URL, 주문·구매·배송 식별정보처럼 프로그램에서 확인 가능한 값은 입력 목록에 표시하지 않는다.
- 삭제: 직접 입력한 금액을 비우고 저장하면 해당 값을 제거하며 자동 수집값에는 영향을 주지 않는다.
- 예외·제한: 자동 수집값을 직접 입력값으로 덮어쓸 수 없고, 금액은 0 이상의 숫자만 저장한다. 현재 프로토타입에서는 브라우저 로컬 저장소에만 보관한다.
