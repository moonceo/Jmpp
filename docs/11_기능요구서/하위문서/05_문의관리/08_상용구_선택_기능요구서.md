# 상용구 선택

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 답변 작성 모달의 상용구 영역
- 노출 조건: 등록된 더미 상용구가 있을 때 선택지를 표시한다.
- 실행 흐름: 상용구 선택 → 답변 입력란에 내용 반영 → 사용자 수정
- 상태 변화: 답변 초안만 변경하고 문의 상태는 유지한다.
- 처리 결과: 반복 답변을 빠르게 작성한다.
- 예외·제한: 상용구가 없으면 빈 안내를 표시한다. 상용구 관리 바로가기는 연결 전까지 제거하거나 준비 중으로 표시한다.
