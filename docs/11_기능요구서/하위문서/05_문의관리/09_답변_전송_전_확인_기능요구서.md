# 답변 전송 전 확인

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 답변 작성 모달의 `답변 전송`
- 노출 조건: 답변 입력란에 공백이 아닌 내용이 있을 때 활성화한다.
- 실행 흐름: 답변 전송 선택 → 최종 답변·전송 후 수정 제한 안내 표시 → 다시 수정 또는 전송 확정
- 상태 변화: 확인 단계에서는 문의 상태를 변경하지 않는다.
- 처리 결과: 사용자가 최종 내용을 한 번 더 검토한다.
- 예외·제한: 빈 답변은 확인 단계로 이동할 수 없다.
