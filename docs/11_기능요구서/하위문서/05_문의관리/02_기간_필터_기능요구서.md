# 기간 필터

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 문의 조회 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: 최근 1주일·1개월·3개월 선택 → 문의 작성일 기준 필터 적용
- 상태 변화: 선택 기간을 유지하고 요약·탭 건수·목록을 같은 기준으로 갱신한다.
- 처리 결과: 기간과 검색어·상태를 모두 만족하는 문의만 표시한다.
- 예외·제한: 결과가 없으면 상태별 빈 화면을 표시한다.
