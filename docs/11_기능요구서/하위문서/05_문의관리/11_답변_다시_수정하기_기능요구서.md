# 답변 다시 수정하기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 최종 확인 화면
- 노출 조건: 전송 확정 전 표시한다.
- 실행 흐름: 다시 수정하기 선택 → 답변 작성 단계로 복귀 → 내용 수정
- 상태 변화: 작성한 답변을 유지하고 문의 상태는 미답변으로 유지한다.
- 처리 결과: 수정 후 다시 최종 확인을 진행한다.
- 예외·제한: 전송 확정 이후에는 이 기능을 제공하지 않는다.
