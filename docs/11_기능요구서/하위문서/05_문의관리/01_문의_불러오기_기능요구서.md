# 문의 불러오기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 문의관리 상단의 `문의 불러오기`
- 노출 조건: 항상 표시한다.
- 실행 흐름: 문의 불러오기 선택 → 불러오는 중 표시 → 더미 신규 문의 추가 또는 결과 없음 안내 → 요약·탭 건수·목록 갱신
- 상태 변화: 처리 중에는 중복 실행을 막고 완료 후 더미 문의 데이터를 갱신한다.
- 처리 결과: 새로 불러온 문의 수를 안내한다.
- 예외·제한: 외부 마켓에서 실제 문의를 가져오지 않는다. 현재 프로토타입은 3건 안내 후 목록에 추가하지 않는 불일치가 있다.
