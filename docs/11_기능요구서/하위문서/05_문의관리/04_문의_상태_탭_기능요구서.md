# 문의 상태 탭

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 문의 목록 상단의 미답변·답변완료 탭
- 노출 조건: 항상 표시하고 각 탭 건수를 함께 표시한다.
- 실행 흐름: 탭 선택 → 선택 탭 강조 → 해당 상태 문의 목록 표시
- 상태 변화: 답변 전송 완료 시 문의를 미답변에서 답변완료로 이동하고 두 탭 건수를 갱신한다.
- 처리 결과: 상태별 문의를 구분해 확인한다.
- 예외·제한: 0건 탭도 선택할 수 있으며 빈 상태를 표시한다.
