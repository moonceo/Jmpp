# 답변 전송 확정

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 최종 확인 화면의 `확인했습니다, 전송합니다`
- 노출 조건: 최종 확인 단계에서 표시한다.
- 실행 흐름: 전송 확정 → 전송 중 표시 → 더미 답변 저장 → 완료 안내 → 모달 닫기
- 상태 변화: 문의를 답변완료로 변경하고 답변내용·답변시각을 저장하며 요약과 탭 건수를 갱신한다.
- 처리 결과: 답변완료 탭에서 처리된 문의를 확인한다.
- 예외·제한: 외부 마켓에 실제 답변을 전송하지 않으므로 완료 문구는 `데모 답변 처리 완료`로 표시해야 한다.
