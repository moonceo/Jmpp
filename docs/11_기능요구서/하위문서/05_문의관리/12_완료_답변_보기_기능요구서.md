# 완료 답변 보기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 답변완료 문의 행
- 노출 조건: 저장된 답변내용이 있는 문의에 표시한다.
- 실행 흐름: 답변 보기 선택 → 문의 원문·최종 답변·답변시각 표시 → 닫기
- 상태 변화: 조회만 수행한다.
- 처리 결과: 이전에 처리한 답변을 다시 확인한다.
- 예외·제한: 현재 프로토타입에는 기능이 없어 추가가 필요하다.
