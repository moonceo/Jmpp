# 문의 검색

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 문의 조회 영역의 검색 입력창
- 노출 조건: 항상 표시한다.
- 실행 흐름: 문의 내용 또는 주문번호 입력 → 부분 일치 검색 → 목록·건수 갱신
- 상태 변화: 검색어를 지우면 기간과 상태 탭을 유지한 전체 결과로 돌아간다.
- 처리 결과: 일치 문의만 표시한다.
- 예외·제한: 현재 프로토타입은 입력값이 목록에 반영되지 않는 불일치가 있다.
