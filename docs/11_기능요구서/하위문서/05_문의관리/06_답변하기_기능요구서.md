# 답변하기

> 중요도: **필수**

## 기능 요구사항

- 노출 위치: 내부에서 답변 가능한 미답변 문의 행
- 노출 조건: 문의 상태가 미답변이고 내부 답변 대상일 때 표시한다.
- 실행 흐름: 답변하기 선택 → 문의정보·상품정보·작성자 확인 → 답변 작성
- 상태 변화: 답변 모달을 열지만 전송 전에는 문의 상태를 바꾸지 않는다.
- 처리 결과: 직접 입력, AI 초안 또는 상용구를 사용해 최종 답변을 준비한다.
- 예외·제한: 답변완료 문의에는 답변하기를 제공하지 않는다.
