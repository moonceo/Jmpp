# 문의 바로가기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 외부 마켓에서만 답변할 수 있는 문의 행
- 노출 조건: 내부 답변 기능을 제공하지 않는 문의에 표시한다.
- 실행 흐름: 문의 바로가기 선택 → 해당 더미 마켓 문의 페이지를 새 탭으로 열기
- 상태 변화: 커머스라이프의 문의 상태는 변경하지 않는다.
- 처리 결과: 사용자가 외부 처리 위치로 이동했음을 확인한다.
- 예외·제한: 연결 주소가 없으면 버튼을 비활성화하고 이동할 수 없음을 안내한다.
