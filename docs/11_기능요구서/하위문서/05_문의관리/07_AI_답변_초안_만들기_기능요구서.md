# AI 답변 초안 만들기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 답변 작성 모달
- 노출 조건: 내부 답변 대상 문의에서 표시한다.
- 실행 흐름: AI 초안 만들기 선택 → 문의·상품 더미정보 분석 중 표시 → 검토용 초안 입력란에 반영
- 상태 변화: 기존 직접 입력 내용이 있으면 덮어쓰기 전에 확인한다.
- 처리 결과: 사용자가 수정할 수 있는 답변 초안을 제공한다.
- 예외·제한: 과도한 약속이나 확인되지 않은 배송·환불 내용을 확정 표현하지 않는다. 실제 AI 호출 여부와 관계없이 프로토타입은 더미 초안을 사용할 수 있다.
