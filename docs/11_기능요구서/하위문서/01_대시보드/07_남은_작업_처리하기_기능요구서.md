# 남은 작업 처리하기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 신규주문·상품준비·발송대기·취소/반품/교환 작업 카드
- 노출 조건: 각 작업 카드를 항상 표시하고 대상 건수를 함께 표시한다.
- 실행 흐름: 작업 카드의 `처리하기` 선택 → 작업 종류에 맞는 주문수집 탭 또는 클레임 화면으로 이동
- 상태 변화: 이동 대상 화면의 기본 탭을 해당 작업 단계로 설정한다.
- 처리 결과: 사용자는 남은 작업 목록을 바로 확인한다.
- 예외·제한: 대상이 0건이어도 카드와 이동 기능은 유지하며 이동 후 빈 상태를 표시한다.
