# 공지사항 전체보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 공지사항 영역의 `더보기`
- 노출 조건: 공지사항 영역에 항상 표시한다.
- 실행 흐름: `더보기` 선택 → 전체보기 모달 열기 → 공지 제목·날짜·내용 확인 → 닫기
- 상태 변화: 모달 열림 여부만 변경한다.
- 처리 결과: 최근 3건 이외의 더미 공지도 확인할 수 있다.
- 예외·제한: 공지가 없을 때도 모달을 열 수 있으며 빈 상태를 표시한다.
