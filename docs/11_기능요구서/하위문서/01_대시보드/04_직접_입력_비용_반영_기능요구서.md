# 직접 입력 비용 반영

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 월별 통계 조건 영역
- 노출 조건: 대시보드 진입 시 항상 표시한다.
- 실행 흐름: 조건 ON/OFF → 주문별 직접 입력 비용 포함 여부 변경 → 비용·마진 재계산
- 상태 변화: ON이면 직접 입력 비용을 비용 합계에 더하고 예상마진에서 차감한다.
- 처리 결과: 비용과 예상마진이 같은 계산 기준으로 변경된다.
- 예외·제한: 직접 입력 비용이 없는 주문은 조건 변경의 영향을 받지 않는다.
