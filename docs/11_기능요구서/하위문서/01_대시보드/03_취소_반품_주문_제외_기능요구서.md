# 취소·반품 주문 제외

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 월별 통계 조건 영역
- 노출 조건: 대시보드 진입 시 항상 표시한다.
- 실행 흐름: 조건 ON/OFF → 취소·반품 주문 포함 여부 변경 → 통계와 달력 갱신
- 상태 변화: ON이면 취소·반품 처리된 주문을 집계 대상에서 제외한다.
- 처리 결과: 요약 카드와 일별 매출은 동일한 제외 기준을 사용한다.
- 예외·제한: 제외 결과가 0건이면 모든 금액을 0으로 표시한다.
