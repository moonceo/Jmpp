# 마진 확정 주문만 보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 월별 통계 조건 영역
- 노출 조건: 대시보드 진입 시 항상 표시한다.
- 실행 흐름: 조건 ON/OFF → 포함 주문 재선정 → 통계 요약과 일별 매출 갱신
- 상태 변화: ON이면 마진이 확정된 더미 주문만 집계하고 OFF이면 확정 여부와 관계없이 집계한다.
- 처리 결과: 총 매출, 정산예정금, 비용, 예상마진과 주문건수가 같은 대상 주문을 기준으로 변경된다.
- 예외·제한: 현재 프로토타입에서는 조건만 변경되고 통계값이 갱신되지 않는 로직 불일치가 있다.
