# 월별 통계 요약 보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 월별 통계 조건 아래 요약 카드 영역
- 노출 조건: 대시보드 진입 시 항상 표시한다.
- 실행 흐름: 선택 월과 조건 적용 → 더미 주문 집계 → 총 매출·정산예정금·비용·예상마진·주문건수 표시
- 상태 변화: 조건이 바뀌면 로딩 상태를 거쳐 집계값을 교체한다.
- 처리 결과: 모든 카드가 동일한 주문 집합을 사용하며 정보 버튼에서 계산 의미를 확인한다.
- 예외·제한: 계산할 주문이 없으면 카드 자체를 숨기지 않고 0원·0건으로 표시한다.
