# 일별 매출 보기

> 중요도: **낮음**

## 기능 요구사항

- 노출 위치: 일별 매출 달력 영역
- 노출 조건: 대시보드 진입 시 항상 표시한다.
- 실행 흐름: 선택 월 확인 → 날짜별 더미 매출 합산 → 해당 날짜 칸에 축약 금액 표시
- 상태 변화: 조회 월이나 집계 조건이 바뀌면 달력 금액을 다시 계산한다.
- 처리 결과: 선택 월의 일별 매출 합계가 월별 총 매출과 같은 집계 기준을 사용한다.
- 예외·제한: 선택 월 밖 날짜는 흐리게 표시하고 매출이 없는 날짜에는 금액을 표시하지 않는다.
