# 주문현황 보기

> 중요도: **중요**

## 기능 요구사항

- 노출 위치: 화면 제목 영역
- 노출 조건: 항상 표시한다.
- 실행 흐름: `주문현황 보기` 선택 → 주문현황 화면으로 이동
- 상태 변화: 대시보드의 선택 조건은 변경하지 않는다.
- 처리 결과: `/journey` 화면을 표시한다.
- 예외·제한: 이동할 수 없으면 현재 화면을 유지하고 실패 안내를 표시한다.
