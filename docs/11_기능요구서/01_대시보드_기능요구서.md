# 대시보드 기능요구서

> 기능별 중요도와 상세 문서: [대시보드 기능목록](./하위문서/01_대시보드/00_기능목록.md)

## 전체 흐름

```text
대시보드 진입
→ 조회 월과 집계 조건 선택
→ 매출·정산·비용·마진·주문건수 확인
→ 남은 작업 또는 주문현황으로 이동
→ 일별 매출과 공지사항 확인
```

## 화면 구성

1. 화면 제목과 `주문현황 보기`
2. 월별 통계 조건
3. 월별 통계 요약
4. 남은 작업
5. 일별 매출 현황
6. 공지사항

## 월별 통계 조건

| 항목 | 화면 동작 | 현재 상태 |
|---|---|---|
| 이전 월 | 조회 월을 한 달 이전으로 변경 | 현재 동작 |
| 다음 월 | 조회 월을 한 달 이후로 변경 | 현재 동작 |
| 마진 확정만 | 정산 완료 주문만 집계하는 조건 | 미동작 |
| 취소/반품 제거 | 취소·반품을 제외한 순매출 조건 | 미동작 |
| 직접 입력 비용 반영 | 직접 입력 비용을 비용·마진에 반영하는 조건 | 미동작 |

## 월별 통계 요약

| 항목 | 표시 내용 |
|---|---|
| 총 매출 | 해당 월 주문의 총 결제금액 |
| 정산예정금 | 마켓 수수료 등을 제외한 정산 예정금액 |
| 비용 | 매입가, 배송비 등 비용 합계 |
| 예상마진 | 정산예정금에서 비용을 제외한 금액 |
| 주문건수 | 조회 조건에 포함된 주문 수 |

각 항목의 정보 버튼에 계산 의미를 표시한다. 데이터를 불러오는 동안 요약 카드 대신 로딩 상태를 표시한다.

## 남은 작업

| 항목 | 이동 결과 |
|---|---|
| 신규주문 | 주문수집의 신규주문 단계로 이동 |
| 상품준비 | 주문수집의 상품준비 단계로 이동 |
| 발송대기 | 주문수집의 발송대기 단계로 이동 |
| 취소/반품/교환 | 구매자 클레임 화면으로 이동 |

각 작업 카드에는 처리 대상 건수와 `처리하기`를 표시한다.

## 일별 매출 현황

- 선택한 월의 달력 구조를 표시한다.
- 매출이 있는 날짜에 일 매출을 축약 금액으로 표시한다.
- 선택 월 밖의 날짜는 흐리게 표시한다.
- 데이터를 불러오는 동안 달력 로딩 상태를 표시한다.

## 공지사항

- 최근 공지 3개를 중요·일반 구분, 제목, 날짜와 함께 표시한다.
- `더보기`를 선택하면 전체 공지를 모달로 표시한다.
- 전체보기에는 공지 내용까지 표시한다.
- 공지가 없으면 빈 상태를 표시한다.

## 화면 상태

| 상황 | 결과 |
|---|---|
| 최초 진입 | 현재 월을 선택한 상태로 표시 |
| 조건 변경 | 조회 조건은 변경되며 통계 재조회 로딩을 실행 |
| 주문현황 보기 | `/journey`로 이동 |
| 남은 작업 처리하기 | 해당 주문 작업함으로 이동 |
| 공지 더보기 | 공지사항 전체보기 모달 표시 |

## 현재 프로토타입 제한

- 통계, 남은 작업, 공지사항은 모두 고정 데모 데이터다.
- 월과 집계 조건을 바꿔도 통계값은 달라지지 않는다.
- 일별 매출 데이터는 2026년 6월로 고정되어 다른 월에서는 달력 금액이 표시되지 않는다.
- 남은 작업 건수는 주문수집 화면의 실제 건수와 연결되지 않는다.

## 완료 확인 기준

- 모든 통계 조건과 요약 항목이 표시된다.
- 남은 작업별 대상 화면으로 이동할 수 있다.
- 일별 매출과 공지 전체보기를 확인할 수 있다.
- 실제 기능으로 전환할 때는 선택 월과 조건이 통계, 달력, 작업 건수에 동일하게 적용되어야 한다.
