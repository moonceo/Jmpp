# 장부다운로드 기능요구서

> 기능별 중요도와 상세 문서: [장부다운로드 기능목록](./하위문서/08_장부다운로드/00_기능목록.md)

## 전체 흐름

```text
월별 조회 또는 기간 조회 선택
→ 마켓 선택 및 설정 아이콘에서 마진 확정·취소반품·직접 입력 반영 조건 설정
→ 장부 데이터의 주문별 버튼에서 자동 계산되지 않은 비용 직접 입력
→ 조회 실행
→ 주문·매출·마진·마진율과 장부 데이터 확인
→ 엑셀 다운로드
```

## 조회 조건

- 조회 방식, 조회 범위, 빠른 기간, 마켓, 적용 기간, 설정과 조회 버튼을 한 줄 도구막대에 표시한다.
- 도구막대에는 `방식`, `범위`, `빠른 선택`, `마켓` 같은 별도 항목명을 표시하지 않는다.
- 마진 확정, 취소·반품 제외와 직접 입력 반영 조건은 설정 아이콘으로 여는 모달에서 변경한다.
- 좁은 화면에서는 같은 항목을 순서대로 줄바꿈한다.

| 항목 | 요청 내용 |
|---|---|
| 조회 방식 | 월별 조회 또는 시작일·종료일을 지정하는 기간 조회 |
| 빠른 기간 | 오늘, 최근 7일, 이번 달, 최근 3개월 |
| 마켓 | 전체 마켓 또는 단일 마켓 |
| 마진 확정 주문만 | 마진이 확정된 주문만 포함 |
| 취소/반품 제외 | 취소·반품 주문을 제외 |

## 집계 항목

- 조회 도구막대 바로 아래에 별도 제목 없이 주문·매출·마진·마진율과 엑셀 다운로드 버튼을 한 줄로 표시한다.

| 항목 | 표시 내용 |
|---|---|
| 총 주문 | 조회 조건에 포함된 주문 수 |
| 총 매출 | 포함 주문의 결제금액 합계 |
| 총 마진 | 정산예정금액에 결제배송비의 3.3% 수수료 차감 후 금액을 더하고 확정·예상 구매금액과 기타 비용을 차감한 마진 |
| 마진율 | 표시 마진을 기준으로 계산한 비율 |

## 추출 데이터 미리보기

- 집계 항목 바로 아래에 `장부 데이터` 표를 표시한다.

| 항목 | 표시 내용 |
|---|---|
| 표시 열 | 다운로드 엑셀과 동일한 38개 열 전체 |
| 열 순서 | 첨부된 기준 장부의 열 순서와 동일 |
| 표시 행 | 현재 조회 조건에 포함된 주문 전체 |
| 빈 값 | 다운로드 파일과 동일하게 `-`로 표시 |
| 탐색 방식 | 표 영역의 가로·세로 스크롤, 주문일 열과 헤더 고정 |
| 직접 입력 | `비고` 다음의 맨 오른쪽 열에 있는 주문별 연필 아이콘 버튼에서 구매금액·국제배송비·화물택배비·관부가세 추가·삭제. 아이콘 열은 화면에 고정하지 않는다. |

## 엑셀 다운로드

- 월별 조회는 `YYYYMM`, 기간 조회는 `YYYYMMDD-YYYYMMDD`를 파일명에 포함한다.
- 데이터 생성 중에는 버튼을 비활성화하고 `데이터 추출 중`을 표시한다.
- 첨부된 기준 장부의 38개 열, 열 순서, 헤더 색상 구간을 유지한다.
- 자동·직접 입력값이 모두 없는 항목은 빈 셀로 제공한다.
- 직접 입력한 구매금액·국제배송비·화물택배비·관부가세는 마진에서 비용으로 차감한다.
- 구매자가 결제한 국내배송비는 `결제배송비` 열에 표시한다. 무료배송은 0원으로 표시하며, 유료배송은 3.3% 수수료를 차감한 금액을 수익금에 더한다.
- 수익금은 `정산예정금액 + (결제배송비 - 결제배송비 × 3.3%) - 구매금액(원화) - 국제배송비 - 화물택배비 - 관부가세`로 계산한다.
- 직접 입력값은 장부 데이터와 다운로드 파일의 같은 열에 반영한다.
- 실제 파일 다운로드가 시작된 뒤 완료 안내를 표시한다.

## 현재 동작과 제한

- 현재는 최근 90일 범위로 이동된 데모 주문을 사용한다.
- 조회를 실행하면 기간·마켓·마진 확정·취소반품 조건이 집계, 장부 데이터와 다운로드 파일에 동일하게 적용된다.
- 마진 확정은 소싱라이프 실제 결제금액 또는 직접 입력 구매금액 존재 여부로 판단한다.
- 직접 입력값은 현재 브라우저에 저장하며 운영 DB에는 아직 저장하지 않는다.
- `직접 입력 반영`을 끄면 입력값은 보관하되 집계, 장부 데이터와 엑셀에는 적용하지 않는다.
- 실제 `.xlsx` 파일을 생성하며, 원본 장부에 없는 주문 데이터 필드는 빈 셀로 둔다.
- 운영 DB 전체 주문을 직접 조회하는 방식은 아직 연결하지 않는다.

## 완료 확인 기준

- 월별·기간·마켓·마진 확정·취소반품 조건을 조회할 수 있다.
- 직접 입력한 빈 항목이 화면과 파일의 동일한 열에 표시된다.
- 직접 입력 비용이 마진과 마진율에서 차감된다.
- 모든 조회 조건이 집계, 장부 데이터와 다운로드 파일에 동일하게 적용된다.
- 미리보기에는 다운로드 엑셀과 동일한 38개 열과 조회 결과 전체 행이 표시된다.
- 마진금액과 마진율은 같은 계산 기준을 사용해야 한다.
- 다운로드 완료 안내는 실제 파일 생성 성공 후에만 표시해야 한다.
