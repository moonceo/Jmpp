# 마켓연동 기능요구서

> 기능별 중요도와 상세 문서: [마켓연동 기능목록](./하위문서/06_마켓연동/00_기능목록.md)

## 전체 흐름

```text
연동 계정 조회
→ 마켓 추가 또는 기존 계정 설정
→ 마켓별 인증정보 입력
→ 기본 배송중 처리 방식 선택
→ 저장 및 연결 확인
→ 계정 활성화
→ 주문수집 실행
```

## 연동 대상

- 스마트스토어
- 쿠팡
- 11번가
- G마켓
- 옥션

계정 수 제한 없이 여러 스토어를 등록하는 화면 구조다.

## 연동 계정 목록

| 항목 | 표시·기능 |
|---|---|
| 마켓 | 등록된 마켓명 |
| 스토어명 | 사용자가 지정한 스토어명 |
| 기본 배송중 처리 방식 | 스토어별로 저장한 직접전달·해외기타배송·송장입력 중 마켓 지원 방식 |
| 연동상태 | 연동 완료, 확인 대기, 연동 오류, 재인증 필요 |
| 활성 | 주문수집 대상 활성·일시정지 |
| 관리 | 주문수집, 설정, 삭제 |

상단에 활성 계정 수와 전체 계정 수를 표시한다.

## 마켓 추가 공통 항목

| 항목 | 필수 여부 |
|---|---:|
| 마켓플레이스 | 필수 |
| 스토어명 | 필수 |
| 사업자번호 | 필수 |
| 배송중 처리 기본값 | 필수 |
| 마켓별 인증정보 | 필수 |

스마트스토어는 직접전달·해외기타배송·송장입력, 11번가는 직접전달·송장입력을 선택할 수 있다. 쿠팡·G마켓·옥션은 송장입력으로 고정한다. 선택값은 스토어별로 저장하고 해당 스토어 주문의 개별·일괄·자동 배송중 처리에서 기본값으로 사용한다.

## 마켓별 인증 항목

| 마켓 | 입력 항목 |
|---|---|
| 스마트스토어 | 연동용 판매자 ID, Client ID, Client Secret |
| 쿠팡 | Vendor ID, Access Key, Secret Key, 쿠팡 윙 로그인 ID |
| 11번가 | 판매자 ID, API Key |
| G마켓 | Master ID, Seller ID, Secret Key |
| 옥션 | Master ID, Seller ID, Secret Key |

필수항목을 모두 입력해야 추가할 수 있다.

## 추가와 연결 확인

| 기능 | 현재 결과 |
|---|---|
| 테스트 | 실제 연결을 실행하지 않고 더미 확인 결과 표시 |
| 스마트스토어 추가 | 더미 계정 저장 후 연동 완료 상태 시연 |
| 나머지 마켓 추가 | 더미 계정 저장 후 확인 대기 또는 연동 완료 상태 시연 |

저장한 인증정보는 더미데이터이며 설정 화면을 다시 열 때 비밀키 원문을 표시하지 않는다.

## 계정 수정

- 마켓 종류는 수정할 수 없다.
- 스토어명과 사업자번호를 수정할 수 있다.
- 지원 마켓 범위 안에서 스토어별 기본 배송중 처리 방식을 변경할 수 있다.
- 연결 다시 확인을 실행할 수 있다.
- 인증정보를 다시 입력하면 더미 연결 확인 결과를 갱신한다.

## 활성·주문수집·삭제

| 기능 | 처리 결과 |
|---|---|
| 활성 변경 | 더미 계정의 주문수집 대상 여부 변경 |
| 주문수집 | 연동 완료 더미 계정의 수집 상태 시연 |
| 설정 | 계정 수정 모달 표시 |
| 삭제 | 확인 후 더미 계정 목록에서 제거 |

연동 완료가 아닌 계정은 목록의 주문수집 버튼을 비활성화한다.

## 화면 상태

| 상황 | 결과 |
|---|---|
| 처리 중 | 해당 버튼 비활성 및 진행 문구·아이콘 표시 |
| 처리 실패 | 오류 메시지 표시, 기존 더미 상태 유지 |
| 계정 없음 | 빈 테이블과 마켓 추가 안내 표시 |

## 현재 프로토타입 제한

- 추가 화면의 `테스트`는 실제 인증 테스트를 하지 않는다.
- 목록 데이터에는 마지막 수집시각과 마지막 결과가 존재하지만 화면에 표시하지 않는다.
- 새로 추가하거나 수정한 계정의 새로고침 후 유지 범위가 일관되지 않을 수 있다.

## 완료 확인 기준

- 5개 마켓별 필수 인증항목을 입력하고 계정을 저장할 수 있다.
- 계정의 연동상태, 스토어별 기본 배송중 처리 방식과 활성 여부를 확인할 수 있다.
- 수정, 연결 재확인, 주문수집과 삭제 결과를 안내한다.
- 테스트, 연결상태와 주문수집 결과가 모두 더미 시연임을 명확히 표시해야 한다.
