# 취소·반품·교환 기능요구서

> 기능별 중요도와 상세 문서: [취소·반품·교환 기능목록](./하위문서/04_취소반품교환/00_기능목록.md)

## 전체 흐름

```text
구매자 클레임 또는 판매자 직접취소 조회
→ 기간·검색·마켓·단계·접수 주체·유형·상태·기한 필터
→ 취소처리·반품처리·교환처리 진입
→ 신청정보와 대상상품 확인
→ 현재 가능한 마켓 처리 실행
→ 소싱 구매 후속조치 별도 확인
→ 상태 이력 확인
```

판매자가 주문수집 화면에서 직접 취소한 주문도 이 화면에 표시한다. 구매자 신청과 판매자 직접취소는 같은 취소 작업함에서 관리하되 접수 주체로 구분한다.

## 처리 범위

- 구매자가 마켓에서 신청한 더미 취소·반품·교환과 판매자가 직접 취소한 더미 주문을 표시한다.
- 모든 처리 결과는 더미 클레임과 주문 상태에만 반영한다.
- 판매자 직접취소는 취소 유형·완료 단계에 표시하고 별도의 승인 작업은 제공하지 않는다.
- 실제 마켓 조회·승인·거부·송장 전송은 범위에 포함하지 않는다.

## 검색·필터

| 항목 | 값 |
|---|---|
| 기간 | 오늘, 3일, 7일, 30일, 전체 |
| 검색 | 상품명, 주문번호, 클레임 ID |
| 마켓 | 전체, 네이버, 쿠팡 |
| 진행 단계 | 전체, 신규요청, 처리중, 완료 |
| 접수 주체 | 전체, 구매자 신청, 판매자 직접취소 |
| 유형 | 전체, 취소, 반품, 교환 |
| 상태 | 요청 접수부터 처리 완료까지 세부 상태 |
| 처리기한 | 전체, 기한 초과, 24시간 이내 |

필터는 목록, 유형별 건수와 처리기한 표시에 동일하게 적용한다.

## 상세 화면 항목

1. 클레임 유형, 상태, 마켓·스토어, 주문번호와 클레임 ID
2. 처리기한
3. 현재 단계, 다음 작업과 주의사항
4. 접수 주체, 접수 사유, 접수 당시 주문·배송상태
5. 회수 배송과 교환 재배송
6. 대상 상품, 옵션, 주문수량과 요청수량
7. 현재 가능한 처리 작업
8. 소싱 구매 후속조치
9. 상태 이력

## 마켓·상태별 처리

| 마켓 | 유형·상황 | 제공 작업 |
|---|---|---|
| 네이버 | 취소 신규요청·확인중·승인대기 | 취소 승인 |
| 네이버 | 반품 회수대기·회수중 | 반품 보류 |
| 네이버 | 반품 회수완료 | 반품 승인, 반품 보류 |
| 네이버 | 반품 보류 | 보류 해제, 반품 거부 |
| 네이버 | 교환 회수중 | 교환 수거 완료 |
| 네이버 | 교환 회수완료·재배송대기 | 교환품 재배송, 교환 보류 |
| 네이버 | 교환 보류 | 보류 해제, 교환 거부 |
| 쿠팡 | 취소 신규요청·확인중·승인대기 | 출고중지 완료, 이미출고 처리 |
| 쿠팡 | 반품 미확인 | 반품 입고 확인 |
| 쿠팡 | 반품 입고확인 | 반품 승인 |
| 쿠팡 | 교환 회수완료 | 교환 입고 확인 |
| 쿠팡 | 교환 재배송대기 | 교환 송장 등록 |
| 쿠팡 | 교환 보류 | 교환 거부 |

교환 재배송 작업에는 택배사와 재배송 송장번호가 모두 필요하다.

판매자 직접취소는 이미 주문수집 화면에서 처리가 끝난 취소 이력이다. `완료` 단계에서 상세와 소싱 구매 후속조치만 확인하며 구매자 취소 승인 버튼은 표시하지 않는다.

## 소싱 구매 후속조치

- 마켓 클레임과 소싱 구매금액 회수는 별도로 추적한다.
- 후속조치 없음, 요청 대기, 처리 중, 완료, 실패, 검토 필요, 결과 확인 필요를 표시한다.
- 교환이 아니면서 검토 필요·실패·결과 확인 필요이면 데모에서 소싱환불 요청을 제공한다.
- 소싱환불 요청은 마켓 클레임 상태를 변경하지 않는다.

## 화면 상태

| 상황 | 결과 |
|---|---|
| 데모 처리 실행 | 클레임·상품 상태와 이력을 더미데이터에서 변경 |
| 조회 중 | 로딩 상태 표시 |
| 조회 실패 | 오류와 다시 시도 표시 |
| 조회 결과 없음 | 조건에 맞는 취소·반품·교환 내역 없음 표시 |
| 현재 작업 없음 | 현재 상태에서 실행할 작업 없음 표시 |

## 현재 프로토타입 제한

- 데모 실행 결과는 브라우저에 저장해 취소·반품·교환 화면으로 이동한 뒤에도 유지한다.
- 화면의 마켓 필터는 네이버와 쿠팡만 제공한다.
- `24시간 이내`는 이미 기한이 지난 건도 포함할 수 있어 정책 확인이 필요하다.

## 완료 확인 기준

- 구매자 클레임과 판매자 직접취소를 접수 주체, 유형, 상태, 처리기한과 함께 조회할 수 있다.
- 상세에서 신청정보, 대상상품, 처리 작업, 소싱 후속조치와 이력을 확인할 수 있다.
- 상태에 맞는 작업만 표시되고 필수 송장정보가 없으면 교환 재배송을 실행할 수 없다.
- 모든 실행 결과가 더미 클레임·주문·이력에 일관되게 반영되어야 한다.
