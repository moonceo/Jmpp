# 문의관리 기능요구서

> 기능별 중요도와 상세 문서: [문의관리 기능목록](./하위문서/05_문의관리/00_기능목록.md)

## 전체 흐름

```text
문의 불러오기
→ 미답변·답변완료 조회
→ 기간 또는 검색 조건 입력
→ 내부 답변 또는 마켓 문의 바로가기
→ 답변 작성·AI 초안·상용구 선택
→ 최종 확인
→ 답변완료 이동
```

## 상단 요약

| 항목 | 표시 내용 |
|---|---|
| 미답변 문의 | 응대가 필요한 문의 수 |
| 답변 완료 | 이번 달 처리 완료 수 |
| 전체 문의 | 누적 수집 문의 수 |
| 연동 스토어 | 연결된 스토어 수 |

## 조회 영역

| 항목 | 값 |
|---|---|
| 문의 불러오기 | 동기화 중 상태 후 수집 완료 안내 |
| 기간 | 최근 1주일, 최근 1개월, 최근 3개월 |
| 검색 | 문의 내용, 주문번호 |
| 상태 탭 | 미답변, 답변완료 |

## 문의 목록 항목

- 마켓
- 상품 이미지
- 문의 유형
- 상품명
- 문의 내용
- 마스킹된 작성자 정보
- 작성 경과시간
- 답변하기, 문의 바로가기 또는 답변완료 상태

외부 마켓에서만 처리할 수 있는 문의는 `문의 바로가기`로 새 탭을 연다. 내부 처리 문의는 `답변하기`를 제공한다.

## 답변 작성

| 항목 | 요청 내용 |
|---|---|
| 문의 정보 | 문의 원문, 작성자, 상품명과 옵션 표시 |
| AI 초안 만들기 | 문의와 상품정보를 바탕으로 검토용 답변 초안 생성 |
| 직접 입력 | 답변 내용을 직접 작성 |
| 상용구 선택 | 등록 상용구 선택 영역 |
| 답변 전송 | 빈 답변 차단 후 최종 확인 단계로 이동 |

AI 초안은 과도한 약속을 피하는 검토용이며 사용자가 사실관계를 확인하고 수정한 후 전송한다.

## 최종 확인

- 최종 답변 내용을 다시 표시한다.
- 마켓 정책상 전송 후 수정·삭제가 어렵다는 주의를 표시한다.
- `다시 수정하기`와 `확인했습니다, 전송합니다`를 제공한다.
- 확인 후 문의를 답변완료 상태로 이동하고 답변내용과 답변시각을 저장한다.

## 빈 상태

| 탭 | 표시 내용 |
|---|---|
| 미답변 | 모든 문의 처리 완료 안내와 다시 불러오기 |
| 답변완료 | 아직 처리된 문의가 없다는 안내 |

## 현재 프로토타입 제한

- 문의와 요약 수치는 모두 고정 데모 데이터다.
- 기간 선택과 검색 입력은 목록에 적용되지 않는다.
- 문의 불러오기는 `3건` 성공 안내만 표시하고 목록에 문의를 추가하지 않는다.
- 답변 후 목록 상태만 변경하며 실제 마켓에는 전송하지 않지만 성공 문구는 실제 전송처럼 표시한다.
- 답변 후 미답변·답변완료 수치와 탭 배지가 갱신되지 않는다.
- 빈 상태의 다시 불러오기와 상용구 관리 바로가기는 동작하지 않는다.
- 답변완료 문의의 기존 답변내용을 다시 보는 기능이 없다.

## 완료 확인 기준

- 문의 상태별 목록과 문의 기본정보를 확인할 수 있다.
- 내부 답변과 외부 마켓 이동을 구분한다.
- 빈 답변 전송을 차단하고 최종 확인 후 답변완료로 이동한다.
- 실제 기능 전환 시 검색, 기간, 수집, 요약 수치와 전송 결과가 동일 데이터 기준으로 갱신되어야 한다.
