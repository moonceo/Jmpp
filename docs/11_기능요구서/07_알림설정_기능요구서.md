# 알림 설정 기능요구서

> 기능별 중요도와 상세 문서: [알림설정 기능목록](./하위문서/07_알림설정/00_기능목록.md)

## 전체 흐름

```text
고객 알림 또는 판매자 알림 선택
→ 알림 종류 선택
→ ON/OFF 설정
→ 알림별 상세 정책 설정
→ 미리보기 확인
→ 설정 저장
```

현재 화면은 발송 정책 데모이며 알림톡·SMS·이메일·푸시를 실제 전송하지 않는다.

## 알림 종류

### 고객 알림

- 통관부호 수집 알림톡
- 통관부호 수집 SMS
- 중국 현지배송 시작
- 배대지 출고
- 리뷰 요청

### 판매자 알림

- 신규주문
- 배송비 결제대기
- 오류입고

각 알림 카드에는 제목, 설명, ON/OFF 상태와 선택 기능을 제공한다.

## 고객 알림 상세 설정

| 항목 | 요청 내용 |
|---|---|
| 발송 가능 시간대 | 시작시간과 종료시간을 KST 기준으로 선택 |
| 시간 외 발생 | 다음 발송 가능 시간까지 대기 안내 |
| 주문 취소 버튼 숨기기 | 통관부호 안내에서 주문 취소 바로가기 제거 |
| 관부가세·추가 택배비 안내 | 통관 안내문에 추가 비용 가능성 표시 |

주문 취소 버튼과 추가 비용 안내는 통관부호 알림톡·SMS 선택 시에만 표시한다.

## 판매자 알림 상세 설정

- 현재는 인앱 알림을 기본 수신 채널로 안내한다.
- 이메일과 모바일 푸시는 계정별 채널 연결 후 선택하는 후속 범위다.

## 미리보기

- 현재 설정한 발송 가능 시간대를 표시한다.
- 고객명, 스토어명, 상품명은 치환값으로 표시한다.
- 추가 비용 안내 ON/OFF를 미리보기에 반영한다.
- 주문 취소 버튼 숨김 설정을 미리보기에 반영한다.

## 저장

- `설정 저장` 선택 시 데모 상태 저장 성공을 안내한다.
- 설정을 켜더라도 외부 메시지를 전송하지 않는다.

## 현재 프로토타입 제한

- 설정은 새로고침하면 초기값으로 돌아간다.
- 발송 시간대와 통관 안내 옵션이 고객 알림별로 분리되지 않고 모든 고객 알림이 하나의 값을 공유한다.
- 미리보기는 어떤 알림을 선택해도 통관부호 알림톡 내용으로 고정되어 있다.
- SMS, 중국 현지배송, 배대지 출고, 리뷰 요청과 판매자 알림의 개별 미리보기가 없다.
- 시작시간이 종료시간보다 늦은 경우 등 시간대 유효성 검사가 없다.

## 완료 확인 기준

- 고객·판매자 알림을 구분하고 각 알림을 활성화할 수 있다.
- 선택 알림의 상세 정책과 미리보기를 확인할 수 있다.
- 실제 기능 전환 시 설정은 알림별로 저장되고 선택한 알림과 채널에 맞는 미리보기를 표시해야 한다.
