# 소싱하기 모달 와이어프레임

## 1. 모드

| 진입 | 버튼명 | 모드 |
|---|---|---|
| 신규주문 | 매칭하기 | 후보/옵션 매칭 저장 + 주문확인 |
| 상품준비 | 소싱하기 | 후보/옵션/수량 선택 + 배대지 수령 프로필 + 구매대행 신청 |
| 결제대기 | 결제하기 | 신청 요약 + 중국 판매자 채팅 + 별도 결제 진입 |
| 결제완료 이후 | 소싱 진행 조회 | 신청·결제 요약 + 중국 판매자 채팅 조회, 재결제 없음 |
| 소싱환불 완료 후 `다시 소싱하기` | 다시 소싱 | 기존 매칭을 비우고 새 후보/옵션/판매처 선택 + 배대지 + 결제대기 + 재결제 |

## 2. 기본 레이아웃

1. 왼쪽: 현재 주문
2. 중앙: 추천 소싱 상품
3. 오른쪽: 옵션 선택

현재 주문 상품정보에는 주문 유입 마켓 배지를 표시한다.

## 3. 추천 소싱 상품 카드

- 후보 상품은 한 줄에 2개씩 표시한다.
- 썸네일
- 한국어 상품명 값
- 중국어 상품명 값
- 판매처
- 상품별 옵션 드롭다운: 한국어명, 중국어명, 원화 가격, 재고/품절
- 선택 옵션 수량 증감, `옵션가격(재고)` 라벨과 원화 금액·재고 수량 요약

후보 카드에는 `한국어 상품명`, `중국어 상품명` 타이틀 라벨을 표시하지 않는다.
카드 상단의 기본 가격과 카드 하단의 위안화 개당 가격은 표시하지 않는다.
모든 후보 카드는 상품명 길이와 관계없이 동일한 높이를 유지하고 옵션·수량 컨트롤의 위치를 맞춘다.
구매 1회, AI 매칭률, 별점, 배송일수, 배송비, 예상마진은 표시하지 않는다.
카드 안의 옵션이나 수량을 변경하면 후보 상품이 함께 선택되고 오른쪽 선택 상품 영역과 비용·마진 분석에 동일하게 반영된다. 상품별 옵션과 수량 선택값은 카드 단위로 유지한다.

## 4. 선택 상품

- 선택 상품 썸네일, 상품명. 주문 유입 마켓 배지는 중복 표시하지 않는다.
- 데스크톱 3단 영역은 `현재 주문 : 추천 소싱 상품 : 선택 상품`을 약 `19 : 56 : 25` 비율로 구성한다.
- 옵션 드롭다운은 항상 아래로 열린다.
- 선택값과 목록 모두 한국어 옵션명 아래 중국어 옵션명을 표시한다.
- 재고가 없는 옵션은 품절로 표시하고 결제 버튼을 비활성화한다.
- 재고 수량은 추천 소싱 상품의 옵션 드롭다운과 선택 옵션 요약에만 표시하고 선택 상품 영역에서는 제거한다.
- 수량 변경을 제공한다.
- `비용 구성`에는 상품 금액(원/위안), 소싱처 이용료, 통화 환전 수수료, 소싱 총비용을 표시한다.
- `마진 분석`에는 결제 금액을 시작값으로 판매 수수료·상품 금액·소싱처 이용료·환전 수수료·예상 배대지 운임을 각각 차감하는 내역과 예상 순이익·마진율을 표시한다.
- 예상 순이익 공식은 `결제 금액 - 판매 수수료 - 소싱 총비용 - 예상 배대지 운임`이며 마진율은 결제 금액을 분모로 한다.

신규주문 모드는 오른쪽 하단에 다음 버튼을 세로로 배치한다.

1. `주문확인`: 검정 채움의 주 액션. 매칭 저장과 주문확인을 함께 처리한다.
2. `주문취소`: 바로 아래 무채색 테두리 보조 액션. 소싱 모달을 닫고 판매자 주문취소 확인 모달을 연다.

주문취소를 선택하면 현재 후보·옵션 선택값은 저장하지 않는다.

## 5. 검색

`추천 소싱 상품` 영역에는 `키워드 또는 타오바오/소싱라이프 상품 URL 입력` 필드와 `찾기` 버튼을 배치한다.
기본 이미지 매칭 후보 20개를 먼저 표시한다.
키워드로 찾기 실행 시 새 검색 후보 20개를 기존 후보 목록 상단에 추가한다.
URL로 찾기 실행 시 타오바오와 소싱라이프 URL만 허용하며, 해당 상품 1개를 기존 후보 목록 상단에 추가한다.

## 6. 배대지 선택과 결제대기

상품과 옵션을 확정하면 소싱라이프에 저장된 배대지 수령 프로필 카드를 표시한다. 이 화면은 내부 배대지·창고 운영 화면이 아니다.

배대지 선택 화면의 왼쪽 본문은 `주문상품 → 소싱상품 → 마진분석 → 배송대행지 선택` 순서의 카드 섹션으로 구성한다. 주문상품에서 마켓 주문 원본을 먼저 확인하고 소싱상품에서 실제 구매 대상을 대조한 뒤 마진과 배송대행지를 결정한다. 오른쪽 요약 영역에는 소싱 총비용과 `구매대행 신청`, `취소` 버튼을 표시하고, 신청 후 결제대기에 머문다는 안내 문구를 최하단에 배치한다.

`구매대행 신청` 이후에는 결제를 실행하지 않고 다음 구성의 결제대기 화면을 표시한다.

1. 공통 헤더: `결제·채팅`, 현재 상태, 마켓 주문번호
2. 왼쪽: 원주문 상품과 소싱상품 2열 비교, 상품원가·이용료·환전 수수료·예상 배송비·예상 순이익·마진율, 선택 배송대행지, 하단 고정 `주문 취소하기`·`상품 결제하기`
3. 오른쪽: 중국 판매자 채팅 상태, 발신자 구분 메시지 내역, 결제대기 전용 `깎아줘`·`깎아줘 취소`, 문의 입력, 전송 버튼, 민감정보 안내

상단 구매대행 접수 안내 카드와 `판매자 채팅` 배지는 표시하지 않는다. 결제 예정금액은 주문상품에서 한 번만 표시하며, 우측 상단 닫기 버튼이 목록 복귀 역할을 대신하므로 `목록으로` 버튼은 제공하지 않는다.

| 모달 영역 | 결제대기 | 결제완료 |
|---|---|---|
| 헤더 | `결제·채팅`, 결제대기, 마켓 주문번호 | `결제·채팅`, 결제완료, 마켓 주문번호 |
| 왼쪽 상단 | 원주문 상품과 소싱상품 비교 | 신청 상품과 실제 결제금액 |
| 왼쪽 중단 | 상품원가·소싱처 이용료·환전 수수료·예상 배송비·예상 총비용·예상 순이익·마진율 | 결제 및 주문서 처리 결과 |
| 왼쪽 상세 | 선택 배송대행지, 신청시각 | 결제일시, 소싱라이프 주문번호, 주문서 접수·국내송장 반영 결과, 선택 배송대행지 |
| 왼쪽 하단 | `주문 취소하기`, 금액 미포함 `상품 결제하기`. 깎아줘 요청 중에는 결제 비활성 | 결제 CTA 없음, 재결제 불가 |
| 오른쪽 중국 판매자 채팅 | 메시지 조회·작성·전송, `깎아줘`·`깎아줘 취소`와 협상 대기/요청 중 상태 | 결제대기 메시지를 이어서 조회·작성·전송, 가격 협상 버튼은 숨김 |

데스크톱에서는 왼쪽 업무정보와 오른쪽 중국 판매자 채팅 패널을 독립 스크롤로 유지한다. 모바일에서는 업무정보 다음에 채팅 패널을 세로로 배치하되 메시지 입력과 전송 버튼을 생략하지 않는다.

모달을 닫으면 목록 처리하기에는 `결제하기`, 진행상태에는 `결제대기`가 표시된다. `결제하기`를 다시 눌러야 약관 및 결제 정보 입력 화면으로 이동한다. 결제완료 후 발송대기 목록과 자세히 보기의 처리하기에는 모두 `소싱 진행 조회`를 제공하고, 같은 모달을 조회·채팅 전용으로 연다. 배송중 목록에는 `소싱 진행 조회`를 표시하지 않는다. 이후 중국배송중·통관 중·국내 배송중에서는 소싱 모달을 다시 열지 않고 행 자세히 보기의 공통 `배송상태 보기` 모달로 현재 배송 단계만 확인한다.

실서비스 결제 완료 성공 시 선택한 배송대행지 사이트를 열고 주문서를 자동입력한다. `접수대기`와 `접수신청`은 동일 단계이며, 연결된 배송대행지는 접수 성공 응답에서 국내 택배사·송장번호를 즉시 발급한다.

접수·송장 반영 후 모달을 닫지 않고 같은 `결제·채팅` 작업공간의 결제완료 화면으로 전환한다. 왼쪽은 신청 상품, 실제 결제금액·결제일시, 소싱라이프 주문번호, 선택 배송대행지, 주문서 접수·국내송장 반영 결과로 바꾸고 결제 CTA를 제거한다. 오른쪽 중국 판매자 채팅 패널은 위치·크기·입력 가능 상태를 유지하고 결제대기 메시지를 이어서 표시한다. 발송대기·배송중·배송완료에서는 결제 CTA를 절대 표시하지 않는다.

현재 프로토타입은 외부 배송대행지 사이트 열기, 주문서 자동입력, 접수 화면을 생략한다. `결제 완료` 클릭 시 해당 과정이 성공한 것으로 간주해 더미 국내송장을 즉시 생성하고 결제완료 화면에 자동입력 완료 결과를 표시한다.
