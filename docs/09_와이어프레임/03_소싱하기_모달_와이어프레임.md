# 소싱하기 모달 와이어프레임

## 1. 모드

| 진입 | 버튼명 | 모드 |
|---|---|---|
| 신규주문 | 매칭하기 | 후보/옵션 매칭 저장 + 주문확인 |
| 상품준비 | 소싱하기 | 후보/옵션/수량 선택 + 구매대행 신청/결제 |

## 2. 기본 레이아웃

1. 왼쪽: 현재 주문
2. 중앙: 추천 소싱 상품
3. 오른쪽: 옵션 선택

## 3. 추천 소싱 상품 카드

- 썸네일
- 한국어 상품명 값
- 중국어 상품명 값
- 판매처
- 상품원가: 원화와 위안화 함께 표시

후보 카드에는 `한국어 상품명`, `중국어 상품명` 타이틀 라벨을 표시하지 않는다.
구매 1회, AI 매칭률, 별점, 배송일수, 배송비, 예상마진은 표시하지 않는다.

## 4. 옵션 선택

- 옵션 드롭다운은 항상 아래로 열린다.
- 선택값과 목록 모두 한국어 옵션명 아래 중국어 옵션명을 표시한다.
- 재고가 없는 옵션은 품절로 표시하고 결제 버튼을 비활성화한다.
- 수량 변경을 제공한다.

## 5. 직접 찾기

`소싱라이프에서 직접 찾기` 버튼은 `추천 소싱 상품` 제목 오른쪽에 배치한다.

## 6. 결제 화면

상품준비에서 `소싱라이프 결제 하기`를 누르면 모달 안에서 다음 화면을 표시한다.

1. 구매대행 신청 화면
2. 다음 단계 결제 화면

이미지 파일을 여는 것이 아니라 소싱라이프 구매대행 신청 페이지를 화면 형태로 재현한다.
