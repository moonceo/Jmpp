# 소싱하기 모달 와이어프레임

## 1. 모드

| 진입 | 버튼명 | 모드 |
|---|---|---|
| 신규주문 | 소싱하기 | 후보/옵션 매칭 저장 + 주문확인 |
| 상품준비 | 소싱하기 | 후보/옵션/수량 선택 + 배대지 수령 프로필 + 구매대행 신청 |
| 결제대기 | 결제하기 | 신청 요약 + 채팅 + 별도 결제 진입 |
| 결제완료 | 결제완료 보기 | 신청·결제 요약 + 채팅 조회, 재결제 없음 |

## 2. 기본 레이아웃

1. 왼쪽: 현재 주문
2. 중앙: 추천 소싱 상품
3. 오른쪽: 옵션 선택

현재 주문 상품정보에는 주문 유입 마켓 배지를 표시한다.

## 3. 추천 소싱 상품 카드

- 후보 상품은 한 줄에 2개씩 표시한다.
- 썸네일
- 한국어 상품명 값
- 중국어 상품명 값
- 판매처
- 상품별 옵션 드롭다운: 한국어명, 중국어명, 원화 가격, 재고/품절
- 선택 옵션 수량 증감, `옵션가격(재고)` 라벨과 원화 금액·재고 수량 요약

후보 카드에는 `한국어 상품명`, `중국어 상품명` 타이틀 라벨을 표시하지 않는다.
카드 상단의 기본 가격과 카드 하단의 위안화 개당 가격은 표시하지 않는다.
모든 후보 카드는 상품명 길이와 관계없이 동일한 높이를 유지하고 옵션·수량 컨트롤의 위치를 맞춘다.
구매 1회, AI 매칭률, 별점, 배송일수, 배송비, 예상마진은 표시하지 않는다.
카드 안의 옵션이나 수량을 변경하면 후보 상품이 함께 선택되고 오른쪽 선택 상품 영역과 비용·마진 분석에 동일하게 반영된다. 상품별 옵션과 수량 선택값은 카드 단위로 유지한다.

## 4. 선택 상품

- 선택 상품 썸네일, 상품명. 주문 유입 마켓 배지는 중복 표시하지 않는다.
- 데스크톱 3단 영역은 `현재 주문 : 추천 소싱 상품 : 선택 상품`을 약 `19 : 56 : 25` 비율로 구성한다.
- 옵션 드롭다운은 항상 아래로 열린다.
- 선택값과 목록 모두 한국어 옵션명 아래 중국어 옵션명을 표시한다.
- 재고가 없는 옵션은 품절로 표시하고 결제 버튼을 비활성화한다.
- 재고 수량은 추천 소싱 상품의 옵션 드롭다운과 선택 옵션 요약에만 표시하고 선택 상품 영역에서는 제거한다.
- 수량 변경을 제공한다.
- `비용 구성`에는 상품 금액(원/위안), 소싱처 이용료, 통화 환전 수수료, 소싱 총비용을 표시한다.
- `마진 분석`에는 결제 금액을 시작값으로 판매 수수료·상품 금액·소싱처 이용료·환전 수수료·예상 배대지 운임을 각각 차감하는 내역과 예상 순이익·마진율을 표시한다.
- 예상 순이익 공식은 `결제 금액 - 판매 수수료 - 소싱 총비용 - 예상 배대지 운임`이며 마진율은 결제 금액을 분모로 한다.

신규주문 모드는 오른쪽 하단에 다음 버튼을 세로로 배치한다.

1. `주문확인`: 주황색 주 액션. 매칭 저장과 주문확인을 함께 처리한다.
2. `주문취소`: 바로 아래 빨간 테두리 보조 액션. 소싱 모달을 닫고 판매자 주문취소 확인 모달을 연다.

주문취소를 선택하면 현재 후보·옵션 선택값은 저장하지 않는다.

## 5. 검색

`추천 소싱 상품` 영역에는 `키워드 또는 타오바오/소싱라이프 상품 URL 입력` 필드와 `찾기` 버튼을 배치한다.
기본 이미지 매칭 후보 20개를 먼저 표시한다.
키워드로 찾기 실행 시 새 검색 후보 20개를 기존 후보 목록 상단에 추가한다.
URL로 찾기 실행 시 타오바오와 소싱라이프 URL만 허용하며, 해당 상품 1개를 기존 후보 목록 상단에 추가한다.

## 6. 배대지 선택과 결제대기

상품과 옵션을 확정하면 소싱라이프에 저장된 배대지 수령 프로필 카드를 표시한다. 이 화면은 내부 배대지·창고 운영 화면이 아니다.

배대지 선택 화면에서 마진 분석은 왼쪽 상품정보 바로 아래에 배치한다. 오른쪽 요약 영역에는 소싱 총비용과 `구매대행 신청`, `취소` 버튼만 표시한다.

`구매대행 신청` 이후에는 결제를 실행하지 않고 다음 구성의 결제대기 화면을 표시한다.

1. 왼쪽: 결제대기 배지, 신청 상품·옵션·수량, 선택 배대지, `결제하기`
2. 오른쪽: 소싱라이프 채팅 내역, 문의 입력, 전송 버튼

모달을 닫으면 목록 처리하기에는 `결제하기`, 진행상태에는 `결제대기`가 표시된다. `결제하기`를 다시 눌러야 약관 및 결제 정보 입력 화면으로 이동한다. 결제완료 상태에서는 자세히 보기의 처리하기에 `결제완료 보기`를 제공하고, 같은 모달을 조회·채팅 전용으로 연다. 중국배송·통관·국내배송 보기 모달은 제공하지 않는다.

실서비스 결제 완료 성공 시 선택한 배송대행지 사이트를 열고 주문서를 자동입력한다. `접수대기`와 `접수신청`은 동일 단계이며, 연결된 배송대행지는 접수 성공 응답에서 국내 택배사·송장번호를 즉시 발급한다.

접수·송장 반영 후 모달을 닫지 않고 결제완료 화면으로 전환한다. 왼쪽에는 결제금액·결제일시, 소싱라이프 주문번호, 선택 배송대행지, 주문서 접수·국내송장 반영 결과, 신청 상품을 표시하고 오른쪽 채팅은 결제대기부터 이어서 유지한다. 발송대기·배송중·배송완료에서는 결제 CTA를 절대 표시하지 않는다.

현재 프로토타입은 외부 배송대행지 사이트 열기, 주문서 자동입력, 접수 화면을 생략한다. `결제 완료` 클릭 시 해당 과정이 성공한 것으로 간주해 더미 국내송장을 즉시 생성하고 결제완료 화면에 자동입력 완료 결과를 표시한다.
