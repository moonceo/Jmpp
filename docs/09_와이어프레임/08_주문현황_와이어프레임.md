# 주문현황 와이어프레임

경로: `/journey`

~~~text
┌ 주문현황 ───────────────────────────────────────── [새로고침] ┐
│ 주문 흐름과 처리 필요 이슈를 한 화면에서 확인               │
├ [주문번호·상품명·수령자 검색] [이슈만 보기] [이슈 기준 설정] ┤
├ 접수~결제 ───── 소싱·중국 ───── 배대지 ─────────────────────┤
│ [신규 2/이슈1]  [현지발송 1]    [입고대기 0] [오류입고 0] ... │
├ 통관~확정 ───── 소싱 환불 ───── 마켓 클레임 ────────────────┤
│ [국내배송 1]    [환불요청 1] [결과확인 1/1] [반품 1/1] ...   │
├ 선택 상태: 결과 확인 필요 · 1건 ─────────────────────────────┤
│ 주문/상품 │ 현재 상태 │ 이슈 사유 │ [이슈 아님] [2시간 미루기] │
│                                                [처리 화면 열기] │
└──────────────────────────────────────────────────────────────┘
~~~

모바일에서는 그룹과 상태 타일이 한 열로 재배치되고, 목록은 가로 스크롤을 허용한다. 외부 배대지 상태는 조회만 가능하며 내부 창고 작업 액션을 배치하지 않는다.

소싱 환불 그룹은 `환불 요청`, `소싱라이프 확인 중`, `반품 접수 필요`, `중국 반품 중`, `환불 정산 중`, `환불 완료`, `환불 거절`, `결과 확인 필요`를 표시한다. 실제 환불 원장이 없는 취소 주문은 환불 타일로 추정하지 않고 마켓 취소 상태의 `소싱환불 요청 필요` 이슈로 표시하며 처리 링크는 주문수집 전체 화면으로 이동한다.
