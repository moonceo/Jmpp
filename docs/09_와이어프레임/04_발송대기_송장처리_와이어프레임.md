# 발송대기 처리 와이어프레임

## 1. 화면 목적

발송대기 화면은 구매와 국내송장 저장이 완료된 `READY_TO_SHIP` 주문을 마켓 배송중으로 처리하는 화면이다.

송장 없는 주문을 수집하거나 구매를 처리하는 화면이 아니다.

## 2. 상단 기능

- 판매처 필터
- 상태 필터
- `자동 배송중 처리` 토글
- 일괄 `배송중 처리`

송장 유무 필터는 제공하지 않는다.

## 3. 목록 기준

| 항목 | 표시 내용 |
|---|---|
| 판매처 | 마켓과 스토어 |
| 상품정보 | 상품명, 옵션, 수량, 상품주문번호 |
| 택배정보 | 구매 완료 시 저장된 실제 국내 택배사와 송장번호 |
| 배송정보 | 수취인, 주소, 개인통관부호 |
| 상태 | 외부구매 또는 소싱 진행 상태, 마켓 상태 |
| 처리하기 | 목록에는 `배송중 처리` 버튼만 표시 |

## 4. 배송중 처리

`배송중 처리`를 누르면 별도 모달 없이 저장된 국내송장을 마켓 API에 즉시 전송한다.

| 조건 | 처리 결과 |
|---|---|
| 결제완료 + 유효한 국내송장 | 마켓 전송 성공 후 마켓·내부 배송중으로 변경 |
| 결제 미완료 또는 국내송장 없음 | 실행 차단, 발송대기 유지, 오류 안내 |

마켓 API 실패 시 주문은 발송대기에 남기고 실패 사유를 표시한다.
마켓 직접전달은 상품준비 자세히 보기의 `처리하기`에서 별도로 실행한다.

## 5. 금지 상태

- 송장 없는 발송대기
- 구매 미완료 발송대기
- 발송대기에서 소싱라이프 송장 수집
- 발송대기에서 외부 구매 완료

위 상태는 상품준비 또는 오류 처리 대상이다.

## 6. 일괄 처리

- 체크된 주문이 있으면 체크된 주문을 우선 처리한다.
- 체크가 없으면 현재 필터에 표시된 주문을 대상으로 한다.
- 직접전달로 이미 마켓 처리된 주문은 일괄 택배 발송 대상에서 제외한다.
