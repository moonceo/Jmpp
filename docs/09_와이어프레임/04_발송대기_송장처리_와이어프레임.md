# 발송대기 송장처리 와이어프레임

## 1. 화면 목적

발송대기 화면은 `READY_TO_SHIP` 주문의 송장번호 수집, 직접 입력, 배송중 처리를 담당한다.

## 2. 상단 기능

- 송장 상태 드롭다운: `전체`, `송장 있음`, `송장 없음`
- `소싱라이프 송장 수집`
- `배송중 처리`
- `소싱라이프 송장 자동 수집` 토글
- `자동 배송중 처리` 토글

## 3. 송장 상태 드롭다운

| 선택 | 표시 |
|---|---|
| 전체 | 발송대기 전체 |
| 송장 있음 | 송장번호가 있는 주문 |
| 송장 없음 | 송장번호가 없는 주문 |

## 4. 택배정보 셀

발송대기 행의 택배정보는 가로 한 줄 입력 구조를 기본으로 한다.

- 택배사 선택
- 송장번호 입력

버튼은 처리하기 컬럼에 배치한다.

## 5. 처리하기 버튼

- `배송중 처리`는 송장번호가 있으면 활성화한다.
- `주문취소`는 항상 아래에 배치한다.
- 송장번호가 없으면 `배송중 처리`는 비활성화한다.

## 6. 자동화 기준

`소싱라이프 송장 자동 수집`은 소싱라이프에서 송장번호를 가져오는 기능이다.
`자동 배송중 처리`는 송장번호가 입력 또는 수집되면 배송중 처리를 자동 시도하는 기능이다.
두 기능은 분리된 토글로 제공한다.
