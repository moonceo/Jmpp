# 발송대기 송장처리 와이어프레임

## 1. 화면 목적

발송대기 화면은 `READY_TO_SHIP` 상태 주문의 국내송장 확보, 자동저장, 마켓 송장전송을 처리하는 화면이다.

## 2. 디자인 기준

- 주문관리 메인과 같은 운영툴 레이아웃을 사용하되 발송대기 작업에 집중된 전용 화면으로 구성한다.
- 좌측 메뉴는 일반 주문 그룹과 클레임 그룹을 분리하며, 발송대기는 일반 주문 그룹 안에서 선택된 상태로 표시한다.
- 화면 상단에는 송장 수집대기, 송장전송 대기, 전송 실패, 자동화 설정 상태를 요약한다.
- 본문은 좌측 자동화/처리 설정 패널과 우측 발송대기 데이터그리드로 나눈다.
- 국내송장 입력은 데이터그리드 안에서 편집 가능한 필드처럼 표현하되, 별도 저장 버튼 없이 자동저장 상태를 표시한다.
- 자동수집과 자동 송장전송은 서로 다른 토글로 표시한다.

## 3. 화면 구성

1. 페이지 헤더
   - 제목: `주문수집 - 발송대기`
   - 송장 수집대기 건수
   - 송장전송 대기 건수
2. 전역 액션
   - `자동수집 ON/OFF`
   - `자동 송장전송 ON/OFF`
   - `전체 송장 수동수집`
   - `선택 송장 수동수집 n건`
   - `전체 송장전송`
   - `선택 송장전송 n건`
3. 주문 테이블
   - 국내송장 컬럼에서 택배사와 송장번호 입력/표시
   - 실패 사유 컬럼 표시

## 4. 국내송장 입력 경로

| 경로 | 동작 |
|---|---|
| 자동수집 | 소싱라이프에서 발급된 국내송장을 자동 조회 |
| 송장 수동수집 | 운영자가 버튼을 눌러 소싱라이프 국내송장을 조회 |
| 수동 입력 | 운영자가 국내 택배사와 국내송장번호를 직접 입력 |

국내송장은 어떤 경로로 입력되어도 즉시 자동저장된다.
별도 저장 버튼은 제공하지 않는다.

## 5. 자동 송장전송 기준

| 설정 | 처리 |
|---|---|
| 자동 송장전송 ON | 국내송장 자동저장 직후 마켓 송장전송 |
| 자동 송장전송 OFF | 운영자가 `송장전송` 버튼을 눌러 마켓으로 전송 |

송장전송 성공 시 주문상태는 `SHIPPING`으로 변경한다.
송장전송 실패 시 주문상태는 `READY_TO_SHIP`으로 유지하고 실패 사유를 표시한다.

## 6. 대표 더미데이터

| 항목 | 값 |
|---|---|
| 주문상태 | 발송대기 |
| 소싱상태 | 국내송장 수신 |
| 국내송장 | CJ대한통운 / 584912345678 |
| 송장전송 | 전송 대기 |
| 실패 사유 | - |

## 7. 오류 상태

| 상태 | 표시 |
|---|---|
| 국내송장 없음 | 송장대기 표시 |
| 송장전송 실패 | 실패 사유 표시, `READY_TO_SHIP` 유지 |
| 소싱라이프 송장 미발급 | 국내송장 없음 상태 유지 |
