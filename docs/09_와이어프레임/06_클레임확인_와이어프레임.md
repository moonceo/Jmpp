# 클레임확인 와이어프레임

## 1. 화면 목적

클레임확인 화면은 `CLAIM` 상태 주문의 취소, 반품, 교환 사유와 후속 처리 필요 여부를 확인하는 화면이다.

## 2. 진입 기준

- 클레임 그룹의 취소/반품/교환 메뉴에서 `클레임확인` 클릭
- 주문상세 모달에서 `CLAIM` 상태 주문의 `클레임확인` 클릭

## 3. 디자인 기준

- Material UI Dialog 구조를 사용하되, 단순 확인창이 아니라 클레임 판단 패널로 구성한다.
- 좌측에는 주문 요약, 우측에는 클레임 사유와 후속 처리 필요 여부를 배치한다.
- 클레임 유형, 접수일시, 처리 보류 여부는 배지와 정보 카드로 명확히 표시한다.
- 후속 상세 처리는 확장 대상으로 두고, 현재 화면은 사유 확인과 운영 판단에 집중한다.

## 4. 화면 구성

1. 모달 헤더
   - 제목: `클레임확인`
   - 주문상태 배지: 취소/반품/교환
2. 주문 요약
   - 마켓
   - 연동 계정
   - 마켓 주문번호
   - 상품명
   - 구매자명
   - 수령인명
3. 클레임 정보
   - 클레임 유형
   - 클레임 사유
   - 마켓 접수일시
   - 후속 처리 필요 여부
4. 하단 버튼
   - `확인`
   - `닫기`

## 5. 대표 더미데이터

| 항목 | 값 |
|---|---|
| 클레임 유형 | 주문취소 |
| 클레임 사유 | 구매자 단순 변심 |
| 주문상태 | 취소/반품/교환 |
| 마켓 | 쿠팡 |
| 연동 계정 | 쿠팡_생활A |
| 마켓 주문번호 | C202606150002 |
| 후속 처리 | 보류 또는 클레임 관리 확장 대상 |

## 6. 표시 기준

클레임은 주문취소 또는 마켓의 취소/반품/교환 수집으로 진입한다.
후속 상세 처리는 클레임 관리 기능의 확장 대상으로 둔다.
