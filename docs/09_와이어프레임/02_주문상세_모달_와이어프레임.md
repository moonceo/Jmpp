# 주문상세 모달 와이어프레임

## 1. 화면 목적

주문상세 모달은 마켓 주문번호 클릭 시 단일 주문의 공통 정보를 확인하고, 현재 주문상태에서 가능한 다음 단계 액션을 실행하는 화면이다.

## 2. 진입 기준

- 주문 테이블의 `마켓 주문번호` 클릭
- 모달 대상은 클릭한 단일 주문이다.

## 3. 디자인 기준

- Material UI Dialog와 운영툴 상세 패널 구조를 기준으로 한다.
- 단순 세로 목록이 아니라, 상태 진행 패널, 주문 요약 패널, 상세 정보 패널, 다음 액션 패널로 나눈다.
- 주문상태와 다음 액션은 우측 고정 패널에 배치해 상세 정보를 보면서 바로 처리할 수 있게 한다.
- 상품, 구매자, 수령인, 통관, 소싱, 송장, 예외 정보는 카드형 섹션으로 나누되 한 화면 안에서 비교 가능하게 배치한다.
- 하단에는 현재 주문 상태에서 가능한 다음 단계 버튼만 표시한다.

## 4. 모달 구성

1. 모달 헤더
   - 제목: `주문상세`
   - 주문상태 배지
   - 닫기 버튼
2. 좌측 상태 진행 패널
   - 신규주문
   - 상품준비
   - 발송대기
   - 배송중
   - 배송완료
   - 취소/반품/교환
3. 상단 요약 영역
   - 마켓, 연동 계정
   - 마켓 주문번호, 상품주문번호
   - 주문일시, 마켓 결제완료일시
4. 본문 정보
   - 상품 정보
   - 구매자 정보
   - 수령인 정보
   - 통관 정보
   - 소싱 정보
   - 송장 정보
   - 예외 정보
5. 우측 다음 액션 패널
   - 현재 상태에서 실행 가능한 버튼
   - 실패 사유 또는 주의 상태
6. 하단 버튼
   - 현재 주문상태에서 가능한 다음 단계 버튼만 표시한다.

## 5. 공통 표시 항목

| 구분 | 표시 항목 |
|---|---|
| 주문 기본 | 마켓, 연동 계정, 주문상태, 마켓 주문번호, 상품주문번호, 주문일시, 마켓 결제완료일시 |
| 상품 | 상품이미지, 상품명, 옵션명, 수량, 상품단가, 결제금액 |
| 구매자 | 구매자명, 구매자 아이디, 구매자 연락처 |
| 수령인 | 수령인명, 수령인 연락처, 우편번호, 배송지 주소, 배송메시지 |
| 통관 | 개인통관부호, 일치/불일치/확인필요 |
| 소싱 | 소싱상태, 소싱상품명, 소싱옵션명, 예상원가, 실제결제금액, 실제마진, 소싱라이프 주문번호 |
| 송장 | 국내송장 |
| 예외 | 클레임 사유, 실패 사유 |

## 6. 상태별 하단 버튼

| 주문상태 | 하단 버튼 |
|---|---|
| `NEW` | `주문확인`, `소싱하기` |
| `PREPARING` | `소싱하기` |
| `READY_TO_SHIP` | `송장전송` |
| `SHIPPING` | 조회 전용 |
| `DELIVERED` | 조회 전용 |
| `CLAIM` | `클레임확인` |

`주문취소`는 신규주문 테이블 행 액션으로 제공하며 주문상세 모달 하단 버튼에는 표시하지 않는다.
