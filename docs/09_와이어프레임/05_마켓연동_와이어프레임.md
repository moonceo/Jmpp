# 마켓연동 와이어프레임

## 1. 화면 목적

마켓연동 화면은 주문수집에 사용할 마켓 스토어를 추가, 수정, 삭제하는 화면이다.

## 2. 상단

- 제목: 마켓연동
- 우측 상단 버튼: `마켓 추가`

## 3. 목록 컬럼

| 컬럼 | 내용 |
|---|---|
| 마켓 | 스마트스토어, 쿠팡, 11번가, G마켓, 옥션 |
| 스토어명 | 사용자가 입력한 구분명 |
| 연동상태 | 정상, 오류 등 |
| 활성 | 주문수집 대상 포함 여부 |
| 관리 | 수정, 삭제 |

현재 목록에서 플랫폼 수수료율, 마지막 수집, 결과, 판매자 계정명, ID 컬럼은 표시하지 않는다.

## 4. 마켓 추가/수정 모달

- 마켓 선택은 드롭다운이다.
- 선택값: 스마트스토어, 쿠팡, 11번가, G마켓, 옥션.
- 관리 영역의 `설정` 버튼은 마켓 추가와 동일한 형태의 계정 수정 모달을 연다.
- 삭제 버튼은 삭제 확인 모달 후 삭제한다.

## 5. 공통 항목

- 스토어명
- 사업자번호
- 테스트 버튼
- 추가 또는 저장 버튼

## 6. 마켓별 인증 정보

| 마켓 | 필드 |
|---|---|
| 스마트스토어 | 연동용 판매자 ID, 클라이언트 아이디, 클라이언트 시크릿 |
| 쿠팡 | 쿠팡 업체코드(Vendor ID), Access Key, Secret Key, 쿠팡 윙 로그인 ID |
| 11번가 | API Key |
| G마켓 | Master ID, Seller ID |
| 옥션 | Master ID, Seller ID |

결제카드, 마켓 외부 노출명, 마켓 로그인 ID/비밀번호, CS 전화번호는 현재 MVP 모달에서 제공하지 않는다.
