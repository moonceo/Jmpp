# 마켓 설정 와이어프레임

## 1. 화면 목적

마켓 설정 화면은 이미 연동 완료된 판매처별 계정의 활성 여부, 수집 실패 여부, 마켓수수료율을 관리하는 화면이다.

## 2. 진입 위치

`내정보 > 마켓 설정`

## 3. 디자인 기준

- Material UI Settings 화면과 데이터그리드 구조를 기준으로 한다.
- 상단에는 연동 계정 수, 활성 계정 수, 연동 완료 계정 수, 수집 실패 계정 수를 카드로 표시한다.
- 본문은 연동 완료된 마켓 계정 설정 데이터그리드로 구성한다.
- 연동상태, 활성 여부, 수집 실패 여부, 마켓수수료율은 같은 화면에서 확인하고 수정할 수 있게 한다.
- 주문수집 대상이 활성화된 모든 연동 계정이라는 기준을 화면 안내로 표시한다.

## 4. 화면 구성

1. 페이지 헤더
   - 제목: `마켓 설정`
   - 설명: 연동 완료된 계정의 수집 설정을 관리한다.
2. 지표 카드
   - 연동 계정
   - 활성 계정
   - 연동 완료
   - 수집 실패
3. 계정 목록
   - 마켓
   - 스토어명
   - 판매자 계정명
   - 연동상태
   - 활성 여부
   - 마지막 수집시각
   - 수집 실패 여부
   - 마켓수수료율
   - 액션
