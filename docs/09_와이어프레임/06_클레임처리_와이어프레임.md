# 클레임 처리 와이어프레임

## 1. 화면 목적

취소/반품/교환 화면은 `CLAIM` 주문을 유형별로 확인하고 처리하는 화면이다.

## 2. 진입

- 좌측 메뉴: 주문관리 > 취소/반품/교환
- 경로: `/orders?view=claims`

## 3. 상단 필터

- 전체
- 취소
- 반품
- 교환

현재단계 필터는 현재 MVP에서 제공하지 않는다.

## 4. 행 액션

| 클레임 유형 | 버튼 |
|---|---|
| 취소 | 취소처리 |
| 반품 | 반품처리 |
| 교환 | 교환처리 |

## 5. 목록 컬럼

일반 주문 테이블 구조를 최대한 유지하되 클레임 유형과 처리 버튼만 클레임에 맞게 표시한다.

- 처리하기
- 주문일시
- 상품정보
- 택배정보
- 배송정보
- 판매처
- 소싱

## 6. 정책

판매자 직접 `주문취소`는 `CANCELED` 상태로 분리하며, 구매자 요청 클레임인 `CLAIM` 목록에 넣지 않는다.
