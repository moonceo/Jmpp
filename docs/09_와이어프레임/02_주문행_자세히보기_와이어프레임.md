# 주문 행 자세히 보기 와이어프레임

## 1. 화면 기준

현재 MVP는 마켓 주문번호 클릭 모달 대신 주문 행 클릭 시 아래로 펼쳐지는 자세히 보기 영역을 사용한다.

## 2. 섹션 순서

1. 주문상품
2. 구매자
3. 배송정보
4. 택배정보
5. 처리하기
6. 소싱상품

하단의 처리하기와 소싱상품은 데스크톱에서 1:2 비율로 나란히 배치하고 작은 화면에서는 세로로 쌓는다.

## 3. 주문상품

- 썸네일
- 상품명
- 옵션명
- 수량
- 주문일시
- 마켓 / 스토어명

상품주문번호는 현재 자세히 보기에서 표시하지 않는다.

## 4. 구매자

- 이름
- 연락처

## 5. 배송정보

- 이름
- 연락처
- 주소
- 개인통관부호
- 통관부호 일치/불일치
- 수정 버튼

## 6. 택배정보

타이틀 없이 한 줄로 표시한다.

예시:

```text
CJ대한통운 512606170031
```

## 7. 처리하기

- 목록에서 자주 쓰는 버튼과 저빈도 버튼을 포함해 현재 단계에서 허용된 전체 작업을 표시한다.
- 상품준비: `소싱하기`, `국내송장 등록`, `마켓 직접전달`, `주문취소`
- 발송대기: `배송중 처리`, `결제완료 보기`, `주문취소`
- 직접전달 주문: `주문취소` 숨김
- 실행할 수 있는 작업이 없으면 안내 문구를 표시한다.

## 8. 소싱상품

- 썸네일
- 상품명
- 옵션명
- 수량
- 소싱금액
- 소싱라이프 주문번호
소싱라이프 주문번호는 타이틀 오른쪽에 함께 표시한다.
`결제완료 보기`를 포함한 실행·조회 버튼은 왼쪽 처리하기 섹션에 표시하며 소싱상품에는 중복 표시하지 않는다. 중국배송·통관·국내배송 단계에는 보기 버튼을 표시하지 않는다.
