# 주문 행 자세히 보기 와이어프레임

## 1. 화면 기준

현재 MVP는 마켓 주문번호 클릭 모달 대신 주문 행 클릭 시 아래로 펼쳐지는 자세히 보기 영역을 사용한다.

## 2. 섹션 배치

넓은 화면은 다음 세 영역으로 나눈다.

1. 왼쪽: 구매자·배송정보 → 택배정보
2. 가운데: 상품 비교 → 마진계산
3. 오른쪽: 현재 주문에서 사용할 수 있는 버튼을 위에서 아래로 배치

넓은 화면의 기준 비율은 왼쪽 22%, 가운데 60%, 오른쪽 18%다. 왼쪽은 최소 320px, 오른쪽은 최소 260px을 확보한다.

매칭된 소싱상품이 있으면 상품 비교를 주문상품 → 소싱상품 순서의 세로 1열로 표시하고 바로 아래에 마진계산을 표시한다. 마진계산은 매출·정산 → 예상 소싱비용 → 예상 순이익·마진율 순서의 세로 1열로 표시한다. 매칭 전에는 소싱상품과 마진계산을 숨기고 주문상품만 표시한다. 구매자와 수령 정보는 왼쪽 카드 안에서 위아래로 표시하고 택배정보는 그 아래에 배치한다. 작은 화면에서는 상품 비교·마진계산, 구매자·배송정보·택배정보, 처리하기 순서로 한 줄씩 배치하고 버튼의 세로 배치를 유지한다.

## 3. 상품 비교

### 주문상품

- 썸네일
- 상품명
- 옵션명
- 수량
- 주문일시
- 마켓 / 스토어명

상품주문번호는 현재 자세히 보기에서 표시하지 않는다.

### 소싱상품

- 썸네일
- 상품명
- 옵션명
- 수량
- 소싱금액
- 소싱라이프 주문번호

소싱라이프 주문번호는 소싱상품 타이틀 오른쪽에 함께 표시한다. 소싱환불이 있으면 소싱상품 하단에 `CNY 요청금액 · refundId`와 현재 상태 배지를 표시한다.

주문상품 아래에 소싱상품을 표시하며 두 카드를 좌우로 나누지 않는다.

## 4. 마진계산

아래 세 영역을 위에서 아래로 표시한다.

1. 매출·정산
2. 예상 소싱비용
3. 예상 순이익·마진율

- 마켓 결제금액
- 판매 수수료
- 정산예상금액
- 소싱상품 원가
- 소싱처 이용료
- 환전 수수료
- 예상 배송비와 예상 총비용
- 예상 순이익과 마진율
- 수익 예상/역마진 예상 배지

소싱상품 원가가 아직 없으면 계산값 대신 `소싱상품 금액이 확인되면 마진을 계산합니다.` 안내를 표시한다.

## 5. 구매자 · 배송정보

### 구매자

- 이름
- 연락처

### 배송정보

- 이름
- 연락처
- 주소
- 개인통관부호
- 통관부호 일치/불일치
- 수정 버튼

## 6. 택배정보

국내 송장번호와 중국 송장번호를 한 줄씩 표시한다. 직접전달 주문에는 두 번호 사이에 `직접전달`을 추가한다.

예시:

```text
국내 송장번호  CJ대한통운 512606170031
직접전달
중국 송장번호  중통택배 CN0000000035
```

일반 주문에는 `직접전달` 문구를 표시하지 않고, 수신되지 않은 송장번호는 `-`로 표시한다.

## 7. 처리하기

- 목록에서 자주 쓰는 버튼과 저빈도 버튼을 포함해 현재 단계에서 허용된 전체 작업을 표시한다.
- 목록에는 탭별 필수 실행만 두고, 조회·수정·저빈도 실행은 상세 처리하기에서 제공한다. 배송정보 수정은 구매자·배송정보 영역에 유지한다.
- 신규주문: `주문확인`, `매칭하기`, `배송정보 수정`, `주문취소`
- 상품준비: 진행단계에 따라 `소싱하기` 또는 `결제하기`, `외부구매 배송처리`, 지원 마켓의 `배송중 처리`(직접전달), `배송정보 수정`, `주문취소`
- 발송대기: 마켓 상태와 관계없이 `배송중 처리` 하나. 미발송이면 모달에서 방식을 선택하고, 발송 완료면 백엔드 대사로 재전송 없이 내부 상태만 반영. 이와 함께 수정·조회·조건부 환불·취소 제공
- TaoWorld 구매 주문라인이 연결된 결제완료~국내 배송중 소싱상품: `소싱상품관리`의 구매대행 신청 상품 영역에 신규 `반품·환불 신청`; 목록·상세 `처리하기`에는 별도 환불 버튼 미표시
- 소싱환불 완료 + 국내배송 미시작: `소싱상품관리` 안에 `[환불 내역]`, 상세 `처리하기`에 `[다시 소싱하기]` 표시. `다시 소싱하기`는 기존 선택을 비운 소싱 모달을 열어 새 후보·판매처 선택부터 다시 시작
- 결제완료~배송완료: 공통 `소싱상품관리`, `배송추적`; 소싱상품관리 화면에서 중국 판매자 대화와 환불 신청·진행·내역 유지
- 마켓 발송 완료 주문: `주문취소` 숨김
- 활성 또는 재소싱 전 환불완료: `배송중 처리`, `마켓 직접전달` 잠금
- 실행할 수 있는 작업이 없으면 안내 문구를 표시한다.
- 버튼은 오른쪽 영역에서 한 개씩 세로로 배치하고 같은 너비로 표시한다. 작은 화면에서도 세로 배치를 유지한다.

`소싱상품관리`, `배송추적`을 포함한 실행·조회 버튼은 오른쪽 처리하기 영역에 표시한다. 단, 소싱 환불 신청·진행·내역 버튼은 `소싱상품관리`의 구매대행 신청 상품 영역에 표시한다. 배송추적 모달은 결제완료 → 중국배송 → 통관 → 국내배송 → 배송완료의 완료·진행 중·예정과 누적 이벤트 일시·위치·택배사·송장번호를 보여준다. 반품완료·교환완료는 최초 배송 뒤 후속 회수·반송·재배송 타임라인을 이어서 표시하며 배대지·창고 운영 기능은 포함하지 않는다.

## 8. 소싱환불 모달

```text
[타오바오 소싱 환불하기 · API 계약 데모]
마켓 취소·반품과 별도 흐름 안내

[TaoWorld 구매주문] [구매 주문라인] [CNY 결제금액] [국내 결제 참고금액]

1. /order/refund/render
[refundType v] [goodsStatus v]
[render 응답 reasonId v] [maxRefundFee · currency]

2. /order/refund/submit
[refundFee CNY] [마켓 클레임 ID (내부 연결용·선택)]
[refundDesc________________________________]
[refundImages URL__________________________]
[ ] 마켓 주문 취소·구매자 환불은 자동 처리되지 않음 확인
                                      [닫기] [TaoWorld submit 데모]
```

기존 요청은 같은 모달에서 `submit 접수 → message_type=9·query → 반품 물류 → 환불 완료`를 조회한다. `RETURN_REQUIRED`에서는 택배사 코드, 중국 반품 송장, 반품자 전화번호를 입력하는 `/submit/logistics` 카드를 표시한다. 원본 `refundStatus`, `refundId`, 구매 주문라인과 CNY 금액을 숨기지 않는다. 실주문 실행 버튼은 `실전송 비활성`으로 표시한다.
