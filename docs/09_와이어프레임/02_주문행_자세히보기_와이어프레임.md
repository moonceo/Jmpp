# 주문 행 자세히 보기 와이어프레임

## 1. 화면 기준

현재 MVP는 마켓 주문번호 클릭 모달 대신 주문 행 클릭 시 아래로 펼쳐지는 자세히 보기 영역을 사용한다.

## 2. 섹션 순서

1. 주문상품
2. 구매자
3. 배송정보
4. 택배정보
5. 소싱상품

## 3. 주문상품

- 썸네일
- 상품명
- 옵션명
- 수량
- 주문일시
- 마켓 / 스토어명

상품주문번호는 현재 자세히 보기에서 표시하지 않는다.

## 4. 구매자

- 이름
- 연락처

## 5. 배송정보

- 이름
- 연락처
- 주소
- 개인통관부호
- 통관부호 일치/불일치
- 수정 버튼

## 6. 택배정보

타이틀 없이 한 줄로 표시한다.

예시:

```text
CJ대한통운 512606170031
```

## 7. 소싱상품

- 썸네일
- 상품명
- 옵션명
- 수량
- 소싱금액
- 소싱라이프 주문번호

소싱라이프 주문번호는 타이틀 오른쪽에 함께 표시한다.
