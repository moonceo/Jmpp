# 와이어프레임 인덱스

현재 와이어프레임은 프론트 MVP 구현을 기준으로 관리한다.
현재는 별도 정적 와이어프레임 목업이 아니라 Next.js 프로토타입이 최신 화면 기준이다.
HTML 파일은 과거 목업을 표시하지 않는다.
라우트가 있는 화면은 `localhost:3000` 프로토타입을 바로 확인하는 뷰어로 제공하고, 모달/팝오버처럼 독립 라우트가 없는 화면은 별도 HTML로 따로 확인한다.
최신 기준은 같은 번호의 markdown 문서와 현재 프론트 구현을 우선한다.

| 번호 | 문서 | 현재 기준 |
|---|---|---|
| 01 | 주문관리 메인 | 주문수집 탭, 검색/필터, 주문 테이블, 행 확장 |
| 02 | 주문 상세/행 확장 | 행 클릭 자세히 보기 구조 |
| 03 | 매칭하기/소싱하기 모달 | 신규주문 매칭하기·상품준비 소싱하기 |
| 04 | 발송대기 처리 | 저장된 송장 확인, 마켓 배송중 처리 |
| 05 | 마켓연동 | 마켓 추가/수정/삭제 |
| 06 | 클레임 처리 | 취소처리, 반품처리, 교환처리 |
| 07 | 이미지 크게 보기 | 상품정보 썸네일 클릭 후 이미지 확대/복사 |
| 08 | 주문현황 | 6개 그룹·32개 상태 타일, 이슈 필터·목록 |
| 09 | 알림설정 | 고객·셀러 규칙, 발송 시간, 통관 안내 미리보기 |

## HTML 확인 기준

HTML 파일은 개발 서버 실행 후 확인한다.

### 현재 화면 HTML 뷰어

| HTML | 확인 방식 |
|---|---|
| `html-export/00_전체화면_인덱스.html` | 개발 서버 실행 후 현재 앱 화면을 화면별 iframe으로 확인 |

`html-export/` 파일은 별도 목업을 새로 그리지 않고 현재 앱 경로를 표시하는 HTML 뷰어이며, `scripts/generate-wireframe-html.js`로 다시 생성한다.

## 상태 기준

| 코드 | 화면 |
|---|---|
| `NEW` | 신규주문 |
| `PREPARING` | 상품준비 |
| `READY_TO_SHIP` | 발송대기 |
| `SHIPPING` | 배송중 |
| `DELIVERED` | 배송완료 |
| `CLAIM` | 취소/반품/교환 |

`전체` 주문수집 탭은 처리보류를 포함한 일반 주문을 조회하고 `처리보류` 상태 필터를 제공한다.
