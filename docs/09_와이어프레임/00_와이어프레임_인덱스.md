# 와이어프레임 인덱스

## 1. 문서 목적

이 문서는 주문팡팡 + 소싱라이프 기획 기준을 화면 단위 와이어프레임으로 분리해 관리하기 위한 인덱스다.
와이어프레임은 화면 구조, 정보 배치, 버튼 위치, 상태 표현, 대표 더미데이터를 정의한다.

## 2. 작성 기준

- MD 파일은 기준 문서다.
- HTML 파일은 브라우저 확인용 시각화 산출물이다.
- HTML은 실제 API 연동이나 실제 기능 동작을 검증하는 프로토타입이 아니다.
- 화면별 와이어프레임은 `01_서비스기획`부터 `08_유저플로우`까지의 기준을 따른다.
- 상태, 버튼명, 컬럼명은 현재 기준 문서와 동일하게 작성한다.

## 3. 와이어프레임 목록

| 번호 | 문서 | 역할 |
|---|---|---|
| 01 | 주문관리 메인 | 주문수집 화면의 전체 레이아웃, 좌측 메뉴, 필터, 주문 테이블 |
| 02 | 주문상세 모달 | 마켓 주문번호 클릭 시 표시되는 주문 공통 정보와 상태별 하단 버튼 |
| 03 | 소싱하기 모달 | 신규주문/상품준비 상태의 소싱 후보 확인, 매칭 저장, 소싱라이프 이동 |
| 04 | 발송대기 송장처리 | 국내송장 자동수집, 수동수집, 수동 입력, 송장전송 처리 |
| 05 | 마켓 설정 | 연동 완료 계정의 연동상태, 활성/비활성, 마켓수수료율 |
| 06 | 클레임확인 | CLAIM 상태 주문의 사유 확인과 후속 처리 표시 |
| 07 | 이미지 크게 보기 | 상품이미지 클릭 시 크게 보기와 이미지 복사 |

## 4. 대표 상태 기준

| 코드 | 라벨 | 와이어프레임 표시 기준 |
|---|---|---|
| `NEW` | 신규주문 | 주문확인 전 주문 |
| `PREPARING` | 상품준비 | 소싱라이프 구매/결제 진행 |
| `READY_TO_SHIP` | 발송대기 | 국내송장 수집, 입력, 송장전송 대기 |
| `SHIPPING` | 배송중 | 마켓 송장전송 완료 |
| `DELIVERED` | 배송완료 | 마켓 배송완료 또는 구매확정 |
| `CLAIM` | 취소/반품/교환 | 클레임 처리 대상 |

## 5. 다음 단계

와이어프레임 확정 후 핵심 클릭 흐름을 검증하는 프로토타입 또는 프론트엔드 구현으로 진행한다.
