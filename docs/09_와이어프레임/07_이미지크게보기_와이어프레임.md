# 이미지 크게 보기 와이어프레임

## 1. 화면 목적

이미지 크게 보기 모달은 주문 테이블의 상품이미지 썸네일을 클릭했을 때 상품 이미지를 확대해 확인하고 복사할 수 있는 화면이다.

## 2. 진입 기준

- 주문 테이블의 `상품이미지` 클릭
- 주문상세 모달의 상품이미지 클릭

## 3. 디자인 기준

- Material UI Dialog와 이미지 프리뷰어 구조를 기준으로 한다.
- 단순 이미지 확대가 아니라, 이미지 확인 영역과 상품 요약 패널을 나누어 배치한다.
- 이미지 영역에는 확대 이미지, 복사 가능 상태, 로딩 실패 상태를 명확히 표시한다.
- 우측 상품 요약 패널에는 이미지가 어떤 주문과 연결되는지 확인할 수 있는 정보를 표시한다.

## 4. 화면 구성

1. 모달 헤더
   - 제목: `이미지 크게 보기`
   - 닫기 버튼
2. 이미지 영역
   - 상품 이미지 확대 표시
   - 이미지 로딩 실패 시 대체 영역 표시
3. 상품 요약
   - 마켓
   - 연동 계정
   - 상품명
   - 옵션명
   - 마켓 주문번호
4. 하단 버튼
   - `이미지 복사`
   - `닫기`

## 5. 대표 더미데이터

| 항목 | 값 |
|---|---|
| 마켓 | 네이버 스마트스토어 |
| 연동 계정 | 스마트스토어_생활용품 |
| 상품명 | 어린이 연습용 스펀지공 안전 보관 가방 포함 |
| 옵션명 | 9인치 화이트 야구공 12개 |
| 마켓 주문번호 | N202606150001 |

## 6. 결과 메시지

| 상황 | 메시지 |
|---|---|
| 이미지 복사 성공 | 이미지가 복사되었습니다. |
| 이미지 복사 실패 | 이미지를 복사할 수 없습니다. |
| 이미지 로딩 실패 | 이미지를 불러올 수 없습니다. |
