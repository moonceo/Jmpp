# 이미지 크게 보기 와이어프레임

## 1. 화면 목적

이미지 크게 보기 모달은 주문 테이블 상품정보 영역의 썸네일을 클릭했을 때 상품 이미지를 확대해 확인하고 이미지 주소를 복사할 수 있는 현재 구현 화면이다.

## 2. 진입 기준

- 주문 테이블 상품정보 영역의 썸네일 클릭
- 현재 HTML 뷰어는 `/orders?view=new` 프로토타입을 열고, 사용자가 직접 썸네일을 클릭해 모달을 확인한다.

## 3. 디자인 기준

- shadcn/ui Dialog 기반의 단순 확대 모달이다.
- 현재 MVP에서는 이미지 확대와 이미지 주소 복사를 우선 제공한다.
- 별도 상품 요약 패널은 현재 구현하지 않는다.

## 4. 화면 구성

1. 모달 헤더
   - 제목: `이미지 크게 보기`
   - 닫기 버튼
   - 상품명 설명
2. 이미지 영역
   - 상품 이미지 확대 표시
3. 하단 버튼
   - `이미지 복사`
   - `닫기`

## 5. 결과 메시지

| 상황 | 메시지 |
|---|---|
| 이미지 복사 성공 | 상품 이미지 주소를 복사했습니다. |
| 이미지 복사 실패 | 이미지를 복사할 수 없습니다. |

## 6. HTML 확인

`07_이미지크게보기_와이어프레임.html`은 과거 정적 와이어프레임이 아니라 현재 `/orders?view=new` 프로토타입을 iframe으로 보여준다.
개발 서버 실행 후 HTML을 열고 상품 썸네일을 클릭해 실제 모달을 확인한다.
