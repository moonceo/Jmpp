# 주문관리 메인 와이어프레임

## 1. 화면 목적

주문관리 메인 화면은 주문수집 목록을 상태별 탭으로 조회하고, 주문확인, 소싱하기, 국내송장 등록, 마켓 직접전달, 배송중 처리, 주문취소를 수행하는 화면이다.

## 2. 상단 구조

1. 페이지 제목: `주문관리`
2. 검색/필터 바
   - 기간 버튼: `오늘`, `3일`, `7일`, `30일`, `직접 입력`
   - 검색 입력
   - 마켓/스토어 필터 아이콘
   - 판매처 드롭다운: 마켓별 네모 약자 아이콘(`N`, `C`, `11`, `G`, `A`) + 스토어명
   - 상태 드롭다운: 현재 단계의 고정 상태값 제공, 배송완료는 `전체`, `배송완료`, `구매확정`
   - 우측 `주문수집` 버튼
3. 상태 탭
   - 전체
   - 신규주문
   - 상품준비
   - 발송대기
   - 배송중
   - 배송완료
4. 단계별 도구 영역
   - 왼쪽: 현재 단계의 처리 액션 버튼
   - 오른쪽: 판매처·상태·송장·클레임 유형 필터와 자동 처리 설정

## 3. 주문 테이블

컬럼 순서:

1. 선택
2. 진행상태
3. 처리하기
4. 주문일시
5. 상품정보
6. 택배정보
7. 배송정보
8. 판매처

주문상태 컬럼은 상단 탭과 중복되므로 표시하지 않는다.
마켓 주문번호는 상품정보 안에서 텍스트로 표시한다.
진행상태 컬럼은 판매자/소싱라이프 관점의 `소싱필요`, `소싱 검증대기`, `소싱완료`, `결제대기`, `결제완료`, `중국배송중`, `통관 중`, `국내 배송중`, `배송완료`와 마켓의 `마켓 취소요청`, `구매확정` 상태값을 표시한다. 외부 구매 완료도 `결제완료`로 표시하고 자세히 보기의 소싱상품에서 `외부구매`를 안내한다. `마켓 배송중`, `마켓 배송완료`는 표시하지 않는다.

결제대기 건은 목록 처리하기에 `결제하기`를 표시한다. 결제완료 건의 `결제완료 보기`는 자세히 보기의 처리하기에 표시한다. 중국배송·통관·국내배송은 별도 보기 버튼 없이 진행상태 배지만 표시하며 처리하기에는 `처리보류`, `주문취소`, `반품완료`, `교환완료` 같은 운영 결과만 남긴다.

## 4. 상태별 처리 버튼

| 탭 | 버튼 |
|---|---|
| 전체 | 주문 상태에 따른 액션. 처리보류 행은 액션 없음 |
| 신규주문 | 주문확인, 소싱하기, 주문취소 |
| 상품준비 | 목록: 소싱하기, 주문취소 / 상세 처리하기: 소싱하기, 국내송장 등록, 마켓 직접전달, 주문취소 |
| 발송대기 | 목록: 배송중 처리 / 상세 처리하기: 배송중 처리, 결제완료 보기, 주문취소 |
| 배송중 | 조회 전용 |
| 배송완료 | 조회 전용 |

신규주문 상단 `주문확인`과 `주문취소`는 체크된 주문만 처리한다.

## 5. 행 확장

행 클릭 시 아래로 자세히 보기 영역이 열린다.

상세 순서:

1. 주문상품
2. 구매자
3. 배송정보
4. 택배정보
5. 처리하기
6. 소싱상품

하단은 `처리하기 : 소싱상품 = 1 : 2` 비율로 배치한다. 직접전달 주문에는 주문취소를 표시하지 않는다.

배송정보는 자세히 보기에서도 수정 가능하다.
