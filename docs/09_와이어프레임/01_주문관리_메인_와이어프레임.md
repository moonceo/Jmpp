# 주문관리 메인 와이어프레임

## 1. 화면 목적

주문관리 메인 화면은 활성화된 모든 연동 계정에서 수집된 주문을 상태별로 조회하고, 주문확인, 소싱하기, 국내송장 처리, 송장전송, 클레임 확인으로 이어지는 운영 시작 화면이다.

## 2. 디자인 기준

- Material UI와 MUI X Data Grid 계열의 운영툴 화면 구조를 기준으로 한다.
- 화면은 좌측 메뉴, 상단 앱바, 작업 현황 영역, 필터/액션 바, 주문 데이터그리드로 구성한다.
- 좌측 메뉴가 상태 이동을 담당하므로 본문에는 같은 상태 목록을 중복 탭으로 제공하지 않는다.
- 주문 테이블은 화면의 핵심 영역으로 배치하고, 요약 카드와 필터는 테이블 작업을 보조하는 수준으로 둔다.
- 각 주문 상태는 색상 배지로 구분하되, 색상만으로 의미를 판단하지 않도록 상태명을 함께 표시한다.
- 주문수집, 주문확인, 소싱하기, 송장전송 등 주요 액션은 현재 상태와 선택 건수에 맞춰 노출한다.
- 전체 컬럼 노출을 기준으로 하며, 화면 폭이 부족하면 데이터그리드 내부 가로 스크롤을 사용한다.

## 3. 화면 구성

1. 사이드바
   - 대시보드
   - 주문수집
     - 일반 주문: 전체, 신규주문, 상품준비, 발송대기, 배송중, 배송완료
     - 클레임: 취소/반품/교환
   - 문의관리
   - 장부다운로드
   - 내정보
2. 페이지 헤더
   - 제목: `주문수집`
   - 주요 전역 액션: `주문수집`
3. 핵심 지표 카드
   - 신규주문
   - 상품준비
   - 송장 수집대기
   - 송장전송 대기
4. 검색/필터
   - 기간 필터
   - 마켓 필터
   - 계정 필터
   - 상태 필터
   - 주문 검색어
5. 주문 테이블
   - 전체 컬럼 노출을 기준으로 하고, 화면 폭 부족 시 가로 스크롤을 사용한다.

## 4. 필터 드롭다운 항목

| 필터 | 항목 |
|---|---|
| 기간 | 오늘, 7일, 15일, 1개월, 직접 지정 |
| 마켓 | 전체, 네이버 스마트스토어, 쿠팡, 11번가, 지마켓, 옥션 |
| 계정 | 전체 계정, 스마트스토어_생활용품, 스마트스토어_키즈, 쿠팡_생활A |
| 상태 | 일반 주문: 전체, 신규주문, 상품준비, 발송대기, 배송중, 배송완료 |
| 주문 검색 | 마켓 주문번호, 상품주문번호, 상품명, 구매자명, 수령인명, 연락처, 개인통관부호 |

필터는 조회 조건이며 주문수집 실행 범위를 제한하지 않는다.
일반 주문 전체 화면의 상태 필터는 CLAIM을 제외한다.
취소/반품/교환은 상태 필터가 아니라 좌측 클레임 그룹 메뉴로 진입한다.
