# 주문관리 메인 와이어프레임

## 1. 화면 목적

주문관리 메인 화면은 주문수집 목록을 상태별 탭으로 조회하고, 주문확인, 매칭하기, 소싱하기, 송장 직접 입력, 배송중 처리, 주문취소를 수행하는 화면이다.

## 2. 상단 구조

1. 페이지 제목: `주문관리`
2. 검색/필터 바
   - 기간 버튼: `오늘`, `3일`, `7일`, `30일`, `직접 입력`
   - 검색 입력
   - 마켓/스토어 필터 아이콘
   - 우측 `주문수집` 버튼
3. 상태 탭
   - 신규주문
   - 상품준비
   - 발송대기
   - 배송중
   - 배송완료

## 3. 주문 테이블

컬럼 순서:

1. 선택
2. 처리하기
3. 주문일시
4. 상품정보
5. 택배정보
6. 배송정보
7. 판매처
8. 소싱

주문상태 컬럼은 상단 탭과 중복되므로 표시하지 않는다.
마켓 주문번호는 상품정보 안에서 텍스트로 표시한다.

## 4. 상태별 처리 버튼

| 탭 | 버튼 |
|---|---|
| 신규주문 | 주문확인, 매칭하기, 주문취소 |
| 상품준비 | 소싱하기, 직접 구매 처리, 주문취소 |
| 발송대기 | 배송중 처리, 주문취소 |
| 배송중 | 조회 전용 |
| 배송완료 | 조회 전용 |

신규주문 상단 `주문확인`과 `주문취소`는 체크된 주문만 처리한다.

## 5. 행 확장

행 클릭 시 아래로 자세히 보기 영역이 열린다.

상세 순서:

1. 주문상품
2. 구매자
3. 배송정보
4. 택배정보
5. 소싱상품

배송정보는 자세히 보기에서도 수정 가능하다.
