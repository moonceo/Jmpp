# 주문관리 메인 와이어프레임

## 1. 화면 목적

주문관리 메인 화면은 주문수집 목록을 상태별 탭으로 조회하고 주문확인, 소싱하기, 외부구매 배송처리, 단일 `배송중 처리`, 주문취소를 수행하는 화면이다.

## 2. 상단 구조

1. 독립 서비스 사이드바
   - 브랜드: `커머스라이프`
   - 그룹: `주문 운영`, `연동 설정`
   - 메뉴: 주문수집, 취소/반품/교환, 문의관리, 마켓연동
   - 타오바오/1688 전환과 아이템 검색, 찜 리스트, 장바구니, 주문 내역, 배송 조회, 통관고유부호는 표시하지 않음
2. 공통 상단 헤더
   - 사이드바 접기/열기
   - `커머스라이프 > 현재 화면` 브레드크럼
   - `독립 주문관리` 표식과 서비스 상태
3. 페이지 헤더
   - 업무 영역 키커: `COMMERCE LIFE · WORK QUEUE`
   - 제목: `주문관리`
   - 설명: 주문수집·소싱·결제·배송 상태를 하나의 작업 큐에서 처리한다는 안내
4. 카드형 주문 작업 패널
   - 검색·필터, 상태 탭, 단계별 액션, 주문 테이블을 하나의 패널 안에서 구획
5. 검색/필터 바
   - 기간 버튼: `오늘`, `3일`, `7일`, `30일`, `직접 입력`
   - 검색 입력
   - 마켓/스토어 필터 아이콘
   - 판매처 드롭다운: 마켓별 네모 약자 아이콘(`N`, `C`, `11`, `G`, `A`) + 스토어명
   - 상태 드롭다운: 현재 단계의 고정 상태값 제공, 배송완료는 `전체`, `배송완료`, `구매확정`
   - 우측 `주문수집` 버튼
6. 상태 탭
   - 전체
   - 신규주문
   - 상품준비
   - 발송대기
   - 배송중
   - 배송완료
7. 단계별 도구 영역
   - 왼쪽: 현재 단계의 처리 액션 버튼
   - 오른쪽: 판매처·상태·송장·클레임 유형 필터와 자동 처리 설정

## 3. 주문 테이블

컬럼 순서:

1. 선택
2. 처리하기
3. 주문일시
4. 진행상태
5. 상품정보
6. 택배정보
7. 배송정보

주문상태 컬럼은 상단 탭과 중복되므로 표시하지 않는다.
마켓 주문번호는 상품정보 안에서 텍스트로 표시한다.
주문일시는 날짜와 시간을 먼저 표시하고 그 아래에 마켓 약자 아이콘 `N`, `C`, `G`, `11`, `A`와 스토어명을 표시한다. 별도 판매처 컬럼은 두지 않는다.
진행상태 컬럼은 한 행에 대표 배지 하나만 표시한다. 여러 상태가 겹치면 `소싱환불·소싱반품 → 구매확정 → 기본 소싱 진행상태` 순으로 선택한다. 기본 상태는 `소싱필요`, `소싱완료`, `결제대기`, `결제완료`, `중국배송중`, `통관 중`, `국내 배송중`, `배송완료`다. 수동 검증 전은 `소싱필요`, 외부 구매 완료는 `결제완료`로 표시하며 `마켓 취소요청`과 `처리보류`는 진행상태에 표시하지 않는다.

택배정보는 `국내 송장번호 → 중국 송장번호` 순으로 표시한다. 직접전달을 선택한 주문만 두 번호 사이에 `직접전달`을 표시하고, 일반 주문에는 직접전달 관련 문구를 표시하지 않는다. 아직 수신하지 않은 송장번호는 `-`로 표시한다.

결제대기 건도 목록 처리하기에는 `소싱하기`를 표시하고, 실제 `결제하기`는 행 자세히 보기에서 제공한다. 소싱라이프 결제완료부터 배송완료까지 `소싱상품관리`와 `배송추적`은 행 자세히 보기의 처리하기에서만 제공한다.

## 4. 상태별 처리 버튼

| 탭 | 버튼 |
|---|---|
| 전체 | 주문 상태에 따른 액션. 처리보류 행은 액션 없음 |
| 신규주문 | 목록·상세 처리하기: 주문확인, 매칭하기, 주문취소 / 배송정보 수정은 상세 왼쪽 정보 영역에서 제공 |
| 상품준비 | 목록: 소싱하기, 주문취소 / 상세 처리하기: 진행단계별 결제, 외부구매 배송처리, 지원 마켓의 `배송중 처리`(직접전달) / 배송정보 수정은 상세 왼쪽 정보 영역에서 제공 |
| 발송대기 | 외부 구매 등 호환 주문: 목록·상세 `배송중 처리`. 미발송은 스토어 기본 발송 방식 확인, 발송 완료는 백엔드 대사 후 재전송하지 않음 |
| 배송중 | 목록: 없음 / 상세 처리하기: 소싱상품관리, 배송추적, 조건부 배송중 처리, 처리 시작 전 운송장 수정 / 배송중 처리를 누른 뒤 운송장 수정 즉시 숨김 / 소싱상품관리 내부: 조건부 반품·환불 신청 |
| 배송완료 | 목록: 없음 / 상세 처리하기: 소싱상품관리, 배송추적 / 소싱상품관리 내부: 기존 환불 조회 |

신규주문 상단 `주문확인`과 `주문취소`는 체크된 주문만 처리한다.

## 5. 행 확장

행 클릭 시 아래로 자세히 보기 영역이 열린다.

넓은 화면의 상세 배치:

1. 왼쪽: 구매자·배송정보, 택배정보를 세로로 배치
2. 가운데: 상품 비교, 마진계산을 세로로 배치. 상품 비교 안에서는 주문상품 → 소싱상품, 마진계산 안에서는 매출·정산 → 예상 소싱비용 → 예상 순이익·마진율 순서
3. 오른쪽: 현재 주문에서 사용할 수 있는 버튼을 세로로 배치

작은 화면에서는 상품 비교·마진계산, 구매자·배송정보·택배정보, 처리하기 순서로 한 줄씩 배치한다. 직접전달 주문에는 주문취소를 표시하지 않는다.

배송정보는 자세히 보기에서도 수정 가능하다.
자세히 보기의 택배정보도 목록과 같은 세 항목을 같은 순서로 표시한다.
