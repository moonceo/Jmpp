# 주문관리 기능명세

## 1. 적용 기준

현재 MVP는 백엔드 없이 Next.js 프론트엔드, mock data, 브라우저 localStorage를 기준으로 동작한다.
문서와 구현이 다를 경우 현재 프론트 구현을 최신 사양으로 본다.

이 문서는 다음 화면을 기준으로 한다.

| 화면 | 경로 | 역할 |
|---|---|---|
| 주문수집 | `/orders`, `/orders?view=new` | 신규주문 기본 진입 |
| 상품준비 | `/orders?view=preparing` | 소싱라이프 소싱/결제 또는 수동구매 처리 |
| 발송대기 | `/orders?view=waiting` | 국내송장 수집, 입력, 배송중 처리 |
| 배송중 | `/orders?view=shipping` | 배송중 주문 조회 |
| 배송완료 | `/orders?view=delivered` | 배송완료 주문 조회 |
| 취소/반품/교환 | `/orders?view=claims` | 클레임 주문 별도 조회 |
| 마켓연동 | `/me/markets` | 마켓 계정 추가, 수정, 삭제 |

별도 `전체` 주문수집 탭은 현재 화면에 없다.
`CANCELED`는 판매자가 직접 취소 처리한 종료 상태이며, 구매자 요청 클레임인 `CLAIM`과 분리한다.

## 2. 주문 상태

| 코드 | 화면 라벨 | 정의 |
|---|---|---|
| `NEW` | 신규주문 | 마켓 결제완료 주문이 수집되었고 판매자가 주문확인 전인 상태 |
| `PREPARING` | 상품준비 | 주문확인 후 소싱라이프 소싱/결제 또는 수동구매가 필요한 상태 |
| `READY_TO_SHIP` | 발송대기 | 국내송장 수집, 입력, 배송중 처리를 기다리는 상태 |
| `SHIPPING` | 배송중 | 국내송장을 기준으로 배송중 처리된 상태 |
| `DELIVERED` | 배송완료 | 배송완료 또는 구매확정 상태 |
| `CANCELED` | 판매자취소 | 판매자가 직접 주문취소 처리한 종료 상태 |
| `CLAIM` | 취소/반품/교환 | 구매자 요청 또는 마켓에서 수집된 취소, 반품, 교환 클레임 |

## 3. 상단 검색/필터

- 기간 필터: `오늘`, `3일`, `7일`, `30일`, `직접 입력`.
- 기본 기간은 `7일`이다.
- 직접 입력은 시작일과 종료일을 선택하는 작은 모달로 처리한다.
- 검색어는 상품명, 마켓 주문번호, 상품주문번호, 내부 주문 ID, 구매자명, 수령인명, 연락처, 배송메시지, 개인통관부호를 대상으로 부분 일치 검색한다.
- 연락처는 하이픈 포함/미포함 입력을 모두 검색한다.
- 마켓/스토어 필터는 하나의 팝오버에서 제공한다.
- 마켓과 스토어는 중복 선택할 수 있다.
- 아무것도 선택하지 않으면 전체 주문을 표시한다.
- 마켓만 선택하면 선택한 마켓의 전체 스토어 주문을 표시한다.
- 스토어만 선택하면 해당 스토어 주문을 표시하며, 스토어가 속한 마켓은 자동 포함된 것처럼 본다.
- 마켓과 스토어를 함께 선택하면 선택한 마켓 안에서 선택한 스토어 주문만 표시한다.
- 선택한 마켓과 관계없는 스토어는 숨기지 않고 비활성화한다.
- `주문수집` 버튼은 우측에 고정하며, 활성화된 전체 연동 계정 기준으로 수집하는 버튼이다.

## 4. 주문 목록 컬럼

주문수집 목록의 기본 컬럼은 다음 순서로 고정한다.

1. 선택
2. 처리하기
3. 주문일시
4. 상품정보
5. 택배정보
6. 배송정보
7. 판매처
8. 소싱라이프

목록에서 숨긴 데이터도 mock data와 타입에는 유지한다.
필요 시 검색, 계산, 상세 펼침, 추후 컬럼 재노출에 사용할 수 있다.

### 4-1. 상품정보

- 썸네일, 상품명, 옵션명, 수량, 마켓 주문번호를 함께 표시한다.
- 마켓 주문번호는 `마켓 주문번호 : 주문번호` 형식의 텍스트로 표시한다.
- 마켓 주문번호 링크와 주문상세 모달은 제공하지 않는다.

### 4-2. 택배정보

- 발송대기에서는 택배사 선택과 송장번호 입력을 제공한다.
- 송장번호 입력값은 자동 저장된다.
- 송장번호만 입력하고 `배송중 처리`를 누르지 않으면 상태는 발송대기로 유지된다.
- 배송중/배송완료에서는 택배사와 송장번호를 조회 전용으로 표시한다.
- 배송중에서 변경된 송장번호가 있으면 `변경된 송장번호` 값만 표시한다.
- 배송중 송장 변경 전송 버튼은 현재 MVP에서 제공하지 않는다.

### 4-3. 배송정보

- 수령인 이름, 연락처, 주소, 개인통관부호를 표시한다.
- 개인통관부호는 `통관부호 일치` 또는 `통관부호 불일치`로 표시한다.
- 개인통관부호가 없거나 형식이 맞지 않으면 불일치로 본다.
- `수정` 버튼으로 배송정보와 개인통관부호를 수정할 수 있다.

### 4-4. 소싱라이프

- 소싱 전이면 `-`를 표시한다.
- 신규주문에서 매칭하기를 통해 상품준비로 이동한 주문은 `매칭완료`를 표시한다.
- 소싱라이프 주문번호가 있으면 주문번호 링크를 표시한다.
- 주문번호 링크는 임시 상세 페이지를 새 탭으로 연다.
- 처리 버튼은 이 컬럼에 넣지 않고 상태/결과 표시만 한다.

## 5. 행 확장 상세

주문 행을 클릭하면 상세 영역이 아래로 펼쳐진다.
상세는 목록에 없는 주문 관련 정보를 확인하기 위한 보조 영역이다.

상세 섹션 순서는 다음과 같다.

1. 주문상품
2. 구매자
3. 배송정보
4. 택배정보
5. 소싱상품

상세의 구매자는 이름과 연락처만 표시한다.
상세의 배송정보는 수취인 배송정보를 표시하며 수정할 수 있다.
상세의 택배정보는 `CJ대한통운 512606170031`처럼 한 줄로 표시한다.
상세의 소싱상품은 썸네일, 상품명, 옵션명, 수량, 소싱금액, 소싱라이프 주문번호만 표시한다.
소싱금액은 소싱라이프 결제금액을 의미한다.

## 6. 상태별 액션

### 6-1. 신규주문

행 액션:

- `주문확인`: 해당 주문을 상품준비로 이동한다.
- `매칭하기`: 소싱 후보와 옵션을 저장하고 주문확인까지 함께 처리해 상품준비로 이동한다.
- `주문취소`: 확인 모달 후 판매자 직접 취소로 처리한다.

상단 액션:

- `주문확인`: 체크된 신규주문만 일괄 주문확인한다.
- `주문취소`: 체크된 신규주문을 확인 모달 후 일괄 취소한다.
- 체크된 주문이 없으면 일괄 버튼은 비활성화한다.
- 주문 탭, 검색어, 기간, 마켓/스토어 필터, 주문 데이터가 변경되면 기존 체크 선택은 초기화한다.

### 6-2. 상품준비

행 액션:

- `소싱하기`: 추천 소싱 상품, 옵션, 수량을 선택하고 모달 안에서 소싱라이프 구매대행 신청/결제 화면으로 진행한다.
- `수동구매 완료`: 소싱라이프를 통하지 않고 다른 곳에서 구매한 주문을 처리한다.
- `주문취소`: 확인 모달 후 판매자 직접 취소로 처리한다.

수동구매 완료 모달:

- 상단에 상품명, 옵션, 수량, 마켓주문번호를 표시한다.
- 택배사와 국내송장번호 입력은 한 줄로 제공한다.
- `발송대기 처리`: 송장번호가 없어도 발송대기로 이동하고, 송장번호가 있으면 저장 후 발송대기로 이동한다.
- `배송중 처리`: 송장번호가 있을 때만 배송중으로 이동한다.

상품준비 상단 옵션:

- `소싱라이프 송장 수신 시 자동 배송중 처리` 토글을 제공한다.
- OFF이면 소싱라이프 결제 후 송장이 함께 와도 발송대기로 이동한다.
- ON이면 송장이 함께 온 주문은 배송중 처리까지 자동으로 진행한다.

### 6-3. 발송대기

상단 액션:

- 송장 필터 드롭다운: `전체`, `송장 있음`, `송장 없음`.
- `소싱라이프 송장 수집`: 소싱라이프 주문번호가 있고 송장번호가 없는 주문만 대상으로 송장번호를 가져온다.
- `배송중 처리`: 송장번호가 있는 주문만 배송중으로 이동한다.
- `소싱라이프 송장 자동 수집`: 자동 수집 토글이다.
- `자동 배송중 처리`: 송장번호가 입력 또는 수집되면 자동으로 배송중 처리를 시도하는 토글이다.

행 액션:

- `배송중 처리`: 해당 주문의 송장번호가 있을 때 활성화한다.
- `주문취소`: 항상 아래에 배치한다.

처리 대상 기준:

- 발송대기에서 주문이 체크되어 있으면 체크된 주문을 우선 대상으로 한다.
- 체크된 주문이 없으면 현재 필터로 보이는 발송대기 주문을 대상으로 한다.
- `소싱라이프 송장 수집`은 대상 중 소싱라이프 주문번호가 있고 송장번호가 없는 주문만 처리한다.
- `배송중 처리`는 대상 중 송장번호가 있는 주문만 처리한다.
- 조건에 맞지 않는 주문이 선택되어 있어도 해당 액션 대상에서 제외한다.

### 6-4. 배송중, 배송완료

- 기본 조회 전용이다.
- 배송중 송장 변경 전송 버튼은 제공하지 않는다.
- 변경된 송장번호가 있는 경우 사용자 확인용으로 값만 표시한다.

### 6-5. 취소/반품/교환

- `/orders?view=claims`에서 별도 화면으로 관리한다.
- 유형 필터는 `전체`, `취소`, `반품`, `교환`만 제공한다.
- 현재단계 필터는 현재 MVP 화면에서 제공하지 않는다.
- 행 액션은 클레임 유형에 따라 `취소처리`, `반품처리`, `교환처리`를 표시한다.

## 7. 소싱라이프 소싱/결제

### 7-1. 신규주문 매칭하기

- 신규주문에서 `매칭하기`를 누르면 소싱 후보와 옵션을 선택한다.
- 저장 시 소싱 매칭 정보를 localStorage에 저장하고 주문확인을 함께 처리한다.
- 처리 후 주문은 상품준비로 이동한다.

### 7-2. 상품준비 소싱하기

- 상품준비에서 `소싱하기`를 누르면 소싱 후보 선택 모달을 연다.
- 후보 카드는 한국어 상품명, 중국어 상품명, 판매처, 상품원가를 표시한다.
- 상품원가는 원화와 위안화를 함께 표시한다.
- AI 매칭률, 별점, 구매횟수, 배송비, 예상마진은 현재 MVP 후보 카드에서 사용하지 않는다.
- 옵션 드롭다운은 한국어 옵션명 아래 중국어 옵션명을 표시한다.
- 옵션 품절이면 결제 버튼을 비활성화한다.
- 수량은 모달 안에서 변경할 수 있다.
- `소싱라이프에서 직접 찾기`는 추천 소싱 상품 제목 오른쪽에 배치한다.
- `소싱라이프 결제 하기`를 누르면 모달 안에서 구매대행 신청 화면으로 전환한다.
- 구매대행 신청 다음 단계에서는 약관 동의와 결제 정보 입력 화면을 표시한다.

### 7-3. 소싱상태

| 코드 | 의미 |
|---|---|
| `NOT_LINKED` | 소싱라이프와 연결 전 |
| `MATCHING` | 매칭 진행 중 |
| `MATCH_SAVED` | 매칭 저장 완료 |
| `PAYMENT_READY` | 결제 가능 |
| `PAID` | 소싱라이프 결제 완료 |
| `INVOICE_RECEIVED` | 국내송장 수신 |
| `HOLD` | 처리 보류 |

현재 주문 목록의 소싱라이프 컬럼은 상태 전체를 자세히 보여주지 않고 `-`, `매칭완료`, 소싱라이프 주문번호 링크만 표시한다.

## 8. mock/localStorage 데이터 흐름

현재 주문 MVP는 서버 API 없이 mock data와 client state로 동작한다.

사용 중인 localStorage 키:

| 키 | 용도 |
|---|---|
| `jumunpangpang.syncedInvoices` | 소싱라이프 송장 수집 결과 |
| `jumunpangpang.sourcingMatches` | 소싱 후보/옵션 매칭 저장 |
| `jumunpangpang.sourcingPayments` | 소싱라이프 결제 완료 가정 결과 |

현재 구현은 주문 화면 진입 시 위 키를 초기화하고 mock 주문 데이터를 다시 구성한다.
좌측 하단 `데이터 초기화` 버튼도 같은 키를 삭제해 데모 데이터를 초기 상태로 되돌린다.
주문 화면에서 탭, 필터, 검색어 또는 데이터가 바뀌면 체크 선택과 행 확장 상태는 현재 화면 기준으로 다시 초기화된다.

React Query는 의존성에 포함되어 있으나 현재 주문 MVP 화면의 핵심 데이터 흐름은 mock data, React state, localStorage 중심이다.
Zustand는 현재 대시보드 store 중심으로 사용된다.

## 9. 마켓연동

마켓연동 화면은 `/me/markets`이다.

목록 컬럼:

1. 마켓
2. 스토어명
3. 연동상태
4. 활성
5. 관리

`마켓 추가` 버튼은 우측 상단에 배치한다.
마켓 선택은 드롭다운이며 `스마트스토어`, `쿠팡`, `11번가`, `G마켓`, `옥션`을 제공한다.
관리 버튼은 마켓 추가와 동일한 구조의 계정 수정 모달을 연다.
삭제 버튼은 삭제 확인 모달 후 삭제한다.

현재 MVP 화면에서 제거 또는 보류한 항목:

- 플랫폼 수수료율
- 마지막 수집
- 결과
- 별도 계정설정 페이지
- 마켓 외부 노출명
- 마켓 로그인 ID/비밀번호
- CS 전화번호
- 결제카드
