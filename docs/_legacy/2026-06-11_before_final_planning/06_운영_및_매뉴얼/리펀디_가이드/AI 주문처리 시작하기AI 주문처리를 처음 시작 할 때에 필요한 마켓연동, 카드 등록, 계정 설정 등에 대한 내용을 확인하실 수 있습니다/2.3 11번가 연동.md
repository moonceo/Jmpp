#### 5. 사용하고 계시는 셀링툴이 있는 경우, 설정되어 있는 셀링툴을 그대로 두신 후, 'IP 직접 입력 항목'만 수정해주시면 됩니다.

![image](../../../_assets/refundy_guide/img_2404c9b96d0ed16ef7fcaf8984cad937.png)

#### 6. IP 정보를 모두 수정입력하셨다면, 하단의 수정하기 버튼을 클릭해주세요.

![image](../../../_assets/refundy_guide/img_9f189d6c9b4289e6a18a5b92d7465fff.png)

#### 7. 수정된 정보를 바탕으로 새로운 API KEY 값을 리펀디에 입력하기 위해 인증하기 버튼을 클릭합니다.

![image](../../../_assets/refundy_guide/img_54be47feb6aa3b6b789f5777ab818ad4.png)

#### 8. 인증 후 새로 업데이트 된 API KEY 를 복사하여, 리펀디 연동하기 페이지에 입력합니다.

![image](../../../_assets/refundy_guide/img_50f89cf2a28e969b74272ea8204d232f.png)

#### 9. 복사한 API KEY 를 인증정보에 입력합니다.

![image](../../../_assets/refundy_guide/img_c545d411f5c2d5193cd859f74ca29c89.png)

#### 10. 테스트 버튼을 클릭하여 발급된 API Key 로 연동이 완료 되었는지 확인합니다.

![image](../../../_assets/refundy_guide/img_8ff5ec297e1c50f35cd2dfb7cab79149.png)

#### 11. 테스트 결과 스토어 연결이 성공되었다면, 추가 버튼을 클릭하여 연동 상태를 저장합니다.

![image](../../../_assets/refundy_guide/img_f8b02ec07278d1e4f9c09faa232f23d6.png)
