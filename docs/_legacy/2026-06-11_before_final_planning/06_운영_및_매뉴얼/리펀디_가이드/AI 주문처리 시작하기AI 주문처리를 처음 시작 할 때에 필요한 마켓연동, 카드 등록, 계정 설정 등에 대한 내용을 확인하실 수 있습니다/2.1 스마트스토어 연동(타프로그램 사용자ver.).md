커머스 API센터 접속 후 스마트 스토어 아이디로 접속해 주세요.

바로가기(클릭)

https://apicenter.commerce.naver.com/ko/member/home

#### 1. [등록하기] 클릭

애플리케이션 등록 우측에 [등록하기]를 클릭해 주세요.

링크 :https://apicenter.commerce.naver.com/ko/member/home

![image](../../../_assets/refundy_guide/img_06c1dbea0898e1f75e83c809c89ab991.png)

#### 이미 애플리케이션이 등록되어 있는 경우

타프로그램 사용시 이미 애플리케이션이 등록되어 있습니다.

등록 되어있는 애플리케이션 클릭해 주세요.

![image](../../../_assets/refundy_guide/img_026481a885ee559cebe39ed6909866b8.png)

#### 이미 애플리케이션이 등록되어 있는 경우

수정버튼 클릭후 2번 절차로 넘어가주세요

![image](../../../_assets/refundy_guide/img_3fc4618179cf29e7c731b9b426d40e74.png)

#### 2. [애플리케이션 이름] - AI주문처리 연동 혹은 임의로 설정

애플리케이션 이름은 단순 작성용으로 사용됩니다. 리펀디 AI 주문처리 연동 혹은 임의로 설정하셔도 무방합니다.

![image](../../../_assets/refundy_guide/img_1375f64a1553f33eddafd0f813e02b18.png)

#### 3. [설명] - 리펀디 AI 주문처리 입력

애플리케이션 설명은 단순 작성용으로 사용됩니다. 리펀디 AI 주문처리 연동 혹은 임의로 설정하셔도 무방합니다.

![image](../../../_assets/refundy_guide/img_af1fb23178a57233ea03832ce952e272.png)

#### 4. [API호출 IP] - 34.64.92.73 추가

타 프로그램 연동 이력이 있다면, 이미 api 번호가 등록되어 있을 수 있습니다. 리펀디 AI 주문처리 api [34.64.92.73]를 추가 입력해 주세요.

![image](../../../_assets/refundy_guide/img_f78a8758555653844feb714f5c97dd5a.png)

#### 5. [전체 API 그룹] - 5가지 모두 추가 클릭

현재 리펀디 AI 주문처리 자동화에서는 주문 수집~배송 관리까지 가능합니다. 이 외에 고객 문의 관리 및 정산 기능은 순차적으로 업데이트될 예정입니다.

![image](../../../_assets/refundy_guide/img_2c129990139c7a22965aee8948b1ad05.png)

#### 6. [등록] 클릭해 주시면, 마켓 시스템에서 API 키가 발급됩니다

![image](../../../_assets/refundy_guide/img_c79b669f0223e12a82264a478d96c7ad.png)

#### 7. 성공적으로 발급된, [애플리케이션 ID / 시크릿 키] 복사하여 리펀디 AI 주문처리에 각각 입력해 주시면 됩니다.

![image](../../../_assets/refundy_guide/img_bc484464afef83653645db7d83b27c05.png)

#### 8. 리펀디 AI 주문처리 스토어 등록에 붙여넣기

[Client ID] → 애플리케이션 ID

[Client Secret] → 애플리케이션 시크릿

![image](../../../_assets/refundy_guide/img_085bf94538a033cd543552de2963b41e.png)

![image](../../../_assets/refundy_guide/img_33a48024cdc7d89ea265b45d8a9893ee.png)
