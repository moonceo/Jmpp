# [심층 분석] 주문팡팡 AI 이용가이드 전수 조사 리포트 (최종)

사용자의 요청에 따라 가이드 내 **25개 모든 아티클**을 전수 조사하여, 기존 기획서에 반영해야 할 **최종 상세 로직 및 예외 케이스**를 정리했습니다.

---

## 1. AI 주문처리 시작하기 (연동 및 설정)
- **API 공통 설정**: 모든 마켓 연동 시 API 허용 IP로 `34.64.92.73` 등록이 필수임.
- **마켓별 특이 권한**:
    - **쿠팡**: 반품지 주소 대신 전용 리턴 URL(`https://oms.jumunpangpang.com/`) 입력 필수.
    - **ESM**: 셀러툴 관리에서 'AI 주문팡팡'을 상품/주문 관리 각각에 대해 직접 선택해야 함.
    - **11번가**: 연동 과정에서 배송방법을 일괄 등록하는 전용 UI 존재.

## 2. 주문처리 자동화 (신규/발송/배송)
- **통관부호 수집 (2.2)**: 
    - **UI**: 미수집 시 '확인 필요' 빨간 텍스트 표시, 수집 시 '통관부호 확인' 파란 버튼 활성화.
    - **로직**: 최대 3회 자동 리마인드 알림 발송 스케줄링.
- **선발송 처리 (2.3)**:
    - **⚠️ 시장 제약**: 쿠팡/ESM은 실송장 자동 업데이트가 지원되나, **스마트스토어/11번가는 수동 업데이트**가 필수임 (가이드 명시).
    - **11번가 가송장**: '배송중'이 아닌 '직접전달' 방식으로 처리되는 특이 로직.
- **배송중 & CS (3.1~3.6)**:
    - **중판대화**: 우측 패널에서 실시간 자동 번역(한↔중) 지원.
    - **배대지 CS 버튼**: `사진 촬영`, `폐기`, `정밀검수`, `특수포장`, `콘센트 추가` 등 구체적인 작업 요청 버튼 구성.
    - **반품(환불) 로직**: 1단계(중국 판매자 반품지 획득) → 2단계(배대지 반품 신청서 작성)의 엄격한 선결 조건 구조.

## 3. 배송대행서비스 이용안내 (물류 디테일)
- **과금 공식**: 부피중량 `(가로*세로*높이) / 6000` 기준 적용.
- **보관료**: 30일 초과 시 송장당 500원/일 부과.
- **실비 데이터**: 간이통관 3,000원, 돼지코 변환 500~1,000원 등.

## 4. 고객 알림 및 기타
- **알림톡 트리거**: 통관부호 미수집(발송대기), 중국 현지 발송(소싱 완료), 국내 배송 시작(배대지 출고) 3단계.
- **장부 필터**: '마진 확정' 필터를 통해 정산 완료된 건만 정밀 추출 가능.
- **장부 다운로드**: 대시보드 통계와 실제 엑셀 데이터 간의 일치 확인 로직 포함.
