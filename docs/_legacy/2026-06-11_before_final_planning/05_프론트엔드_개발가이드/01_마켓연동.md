# [Step 1] 마켓 연동 상세 가이드

주문팡팡 시스템이 각 마켓플레이스의 판매 데이터를 수집하고 관리하기 위해, 가장 먼저 수행해야 하는 '인증 정보 연동' 단계입니다.

---

## 1. 공통 필수 입력 항목
모든 마켓 연동 시 기본적으로 DB에 저장하고 관리해야 하는 정보입니다.

- **마켓플레이스**: 연동할 쇼핑몰 종류 (네이버 스마트스토어, 쿠팡, 지마켓, 옥션, 11번가)
- **마켓 별명**: 사용자가 여러 마켓 계정을 구분하기 위해 설정하는 이름 (예: 코코샵_강남점)
- **사업자 번호**: `-`를 제외한 숫자 (사업자 인증 및 세금 처리용)

---

## 2. 마켓별 상세 인증 정보 (API Key & Account)

개발자는 아래 표에 명시된 항목들을 입력받아 API 호출을 위한 인증 객체를 생성해야 합니다.

| 마켓플레이스 | 주요 인증 항목 (필수 입력) | 발급 및 확인 위치 (가이드) | 비고 |
| :--- | :--- | :--- | :--- |
| **네이버 스마트스토어** | `Client ID`, `Client Secret`, **스토어명** | [스마트스토어 센터 > 커머스 API 센터] | API 사용 승인 필수 |
| **쿠팡 (Coupang)** | `업체코드(A...)`, `Access Key`, `Secret Key`, **쿠팡윙 아이디**, **스토어명** | [쿠팡윙 > 추가판매정보 > API 관리] | **180일 주기 갱신** 필수 |
| **G마켓 / 옥션 (ESM)** | `Master ID`, `Seller ID` | [ESM Plus > 계정 관리] | 사이트별(G/A) ID 확인 |
| **11번가 (11st)** | `Open API Key (Seller Key)` | [11번가 셀러오피스 > 서비스 등록/확인] | API 사용 승인 필요 |

---

## 3. 개발자 구현 유의사항

### 3.1 스토어명 수집의 목적
- **네이버/쿠팡**의 경우, API 호출 시 특정 요청에서 내부적인 식별자로 '스토어명'이 문자열 형태로 요구될 수 있습니다. (사용자가 판매자 센터에서 사용하는 실제 상호명과 일치해야 함)

### 3.2 쿠팡 인증 갱신 로직
- 쿠팡 API Key는 발급 후 180일이 지나면 만료됩니다. 개발자는 연동 시점으로부터 180일 뒤를 만료일로 계산하여 DB에 저장하고, 만료 전 사용자에게 갱신 알림을 보낼 수 있는 로직을 설계해야 합니다.

### 3.3 보안 정책
- `Secret Key`, `Client Secret`, `Password` 등 민감 정보는 DB 저장 시 반드시 **양방향 암호화**를 적용하여 저장해야 합니다.
