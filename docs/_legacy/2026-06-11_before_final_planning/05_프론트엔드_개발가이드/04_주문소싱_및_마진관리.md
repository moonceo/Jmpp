# [Step 4] 주문 소싱 및 마진 관리

발주 확인이 끝난 주문에 대해 해외 쇼핑몰(타오바오, 알리익스프레스, 1688)에서 실제 구매할 상품을 매칭하고, 최종 수익성을 분석하는 단계입니다.

---

## 1. 상품 소싱 및 매칭 (Sourcing)
사용자가 주문받은 상품과 동일하거나 가장 저렴한 해외 상품을 연결하는 과정입니다.

- **소싱 API 연동**: 타오바오 등 해외 사이트의 `Product ID`, `Option/SKU` 정보를 수집합니다.
- **매입가 확정**: 실제 해외 사이트에서 결제할 위안화(CNY) 또는 달러(USD) 가격을 저장합니다.

---

## 2. 실시간 마진 분석 (Margin Analysis)
사용자가 소싱한 상품의 가격을 기준으로 최종 수익을 계산합니다.

> **순이익 = 판매가 - (매입가(환율 적용) + 플랫폼 수수료 + 해외/국내 배송비)**
> **마진율 = (순이익 / 판매가) × 100**

- **환율 적용**: 결제 시점의 실시간 환율을 반영하여 매입가격을 원화로 변환합니다.
- **수수료 계산**: [Step 1]에서 연동된 마켓별 수수료율을 자동 적용합니다.

---

## 3. 통관 관리 (PCCC Management)
해외 직구 시 반드시 필요한 개인통관고유부호를 최종 확인하고 검증합니다.

- **PCCC 유효성 체크**: 수령인 성함과 통관부호가 일치하는지 관세청 API 등을 통해(혹은 형식 검사) 확인합니다.
- **오류 수정**: 통관부호가 없거나 틀린 경우 사용자에게 알림을 보내고 수정을 요청하는 UI를 제공합니다.

---

## 4. 개발자 구현 가이드

### STEP 1: 마진 계산기 모듈 (Calculator)
- 입력값이 바뀔 때마다(매입가 수정 등) 화면에서 즉시 마진율을 계산해주는 React 상태 로직을 구현합니다.

### STEP 2: 소싱 상품 바인딩
- 수집된 주문(Order) 데이터에 소싱 상품(Sourced Product) 정보를 1:1 또는 1:N으로 연결할 수 있는 DB 관계를 설정합니다.

---

## 5. 참고 사항
> [!IMPORTANT]
> - "마진 분석은 소싱이 완료된 후에나 의미가 있습니다." 매입가가 확정되지 않은 상태에서는 예상 마진만 보여주고, 소싱이 완료된 후 **최종 마진**을 확정하는 프로세스로 구현하세요.
