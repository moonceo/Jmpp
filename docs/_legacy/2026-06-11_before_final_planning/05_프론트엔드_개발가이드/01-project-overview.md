# 프로젝트 개요

## 주문팡팡이란?

주문팡팡은 해외 소싱 기반 이커머스 셀러를 위한 **AI 주문 통합 관리 시스템**입니다. 여러 마켓플레이스(네이버, 쿠팡 등)의 주문을 한 곳에서 관리하고, 소싱부터 배송까지의 전 과정을 자동화합니다.

## 핵심 기능

### 1. 대시보드
- 실시간 매출/정산/비용 현황
- 업무 처리 현황 (신규주문, 발송대기, 클레임)
- 월별 매출 캘린더

### 2. 주문 관리
- 전체 주문 통합 조회
- 단계별 주문 처리 (신규 → 발송대기 → 배송중 → 완료)
- 마진 검토 및 소싱 확정
- PCCC(개인통관고유부호) 검증

### 3. 문의 관리
- 멀티 마켓 문의 통합 인박스
- 2단계 확인 답변 시스템

### 4. 내 정보
- 마켓 API 연동 관리
- 플랜 및 결제
- 알림 설정
- 장부 다운로드

## 개발 환경 설정

### 요구 사항

- Node.js 18.x 이상
- npm 또는 pnpm

### 설치 및 실행

```bash
# 저장소 클론
git clone <repository-url>
cd jumunpangpang

# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:3000)
npm run dev

# 프로덕션 빌드
npm run build

# 린트 검사
npm run lint
```
