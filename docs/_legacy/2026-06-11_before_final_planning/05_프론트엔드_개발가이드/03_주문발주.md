# [Step 3] 주문 발주 확인 (Marketplace Acknowledge)

수집된 신규 주문을 확인하고, 마켓플레이스 판매자 센터에 "우리가 이 주문을 인지했고 처리를 시작했다"고 알리는 '발주 확인' 단계입니다.

---

## 1. 개요
신규 주문 상태에서 다음 단계(발송 대기/소싱 시작)로 넘어가기 위한 필수 절차입니다. 이 작업을 수행해야 마켓 측에서 주문이 취소되는 것을 방지하고 배송 준비 상태로 전환됩니다.

---

## 2. 주요 기능 및 API 연동

### 2.1 발주 확인 처리 (Acknowledge)
- **대상**: 상태가 `신규주문`인 모든 건.
- **액션**: 마켓 API의 '발주 확인(Order Acknowledge)' 함수를 호출합니다.
- **결과**: 마켓플레이스 상의 주문 상태가 `배송준비중`으로 변경됩니다.

### 2.2 주문 상태의 로컬 동기화
- API 호출 성공 시, 주문팡팡 DB의 상태도 `발주확인완료` 또는 `발송대기`로 즉시 업데이트합니다.
- 이 시점부터 해당 주문은 '마진 검토' 및 '소싱' 대상 리스트에 포함됩니다.

---

## 3. 개발자 구현 가이드

### STEP 1: 대량 발주 확인
- 사용자가 여러 주문을 선택하여 한 번에 발주 확인을 처리할 수 있도록 벌크(Bulk) 처리 로직을 구현합니다.

### STEP 2: 예외 처리
- 이미 마켓에서 취소된 주문이나, 유효하지 않은 주문번호일 경우 에러 메시지를 반환하고 사용자에게 알립니다.

---

## 4. 참고 사항
> [!NOTE]
> - 이 단계에서는 실제 상품 구매(소싱)가 일어나는 것이 아니라, 마켓플레이스에 **"주문을 확인했다"**는 신호만 보내는 것입니다. 실제 구매는 [Step 4]에서 진행됩니다.
