## 1. 공통 레이아웃

### 1.1 메뉴 (좌측 사이드바)

| 메뉴 | URL | 기본 노출 상태 |
|---|---|---|
| 주문관리 > 전체 | `/orders` | 모든 내부 상태 |
| 주문관리 > 신규주문 | `/orders/new` | `NEW`, `UNKNOWN` |
| 주문관리 > 상품준비 | `/orders/preparing` | `ORDER_CONFIRMED`, `SOURCING_REQUIRED`, `SOURCING_PAYMENT_PENDING`, `SOURCING_PAYMENT_COMPLETED`, `DOMESTIC_TRACKING_PENDING` |
| 주문관리 > 발송대기 | `/orders/waiting` | `MARKET_INVOICE_PENDING`, `MARKET_INVOICE_FAILED` |
| 주문관리 > 배송중 | `/orders/shipping` | `SHIPPING` |
| 주문관리 > 배송완료 | `/orders/delivered` | `DELIVERED`, `PURCHASE_CONFIRMED` |
| 주문관리 > 취소/반품/교환 | `/orders/claims` | 클레임 상태군 전체 |

- 각 메뉴 우측에 처리 대기 건수 뱃지를 표시한다. (신규주문: `NEW` 건수, 발송대기: `MARKET_INVOICE_PENDING + MARKET_INVOICE_FAILED` 건수 등)

### 1.2 상단 도구 모음 (전 메뉴 공통)

| 요소 | 명칭 | 동작 |
|---|---|---|
| 통합 검색바 | placeholder: "상품명, 주문번호, 수령인 검색" | 상품명/마켓 주문번호/수령인명 동시 검색 |
| 마켓 필터 | [마켓] 버튼 → 팝오버 | 전체 / 네이버 / 쿠팡 / 11번가(확장) / 지마켓·옥션(확장) 다중 선택 |
| 상태 필터 | [상태] 버튼 → 체크박스 팝오버 | 해당 메뉴 소속 내부 상태만 노출. 선택 수 뱃지 표시 |
| 기간 필터 | [기간] 버튼 | 주문일 기준. 오늘/7일/30일/직접 지정 |
| 주문 불러오기 | [주문 불러오기] 버튼 (우측 상단) | 수동 수집 실행. 호버 시 "마지막 수집: YYYY-MM-DD HH:mm" 툴팁 |

### 1.3 공통 주문 테이블

| 컬럼 | 표시 내용 | 비고 |
|---|---|---|
| 선택 | 체크박스 | 일괄 액션이 있는 메뉴에서만 표시 |
| 확장 | 펼침 아이콘 | 행 클릭 시 상세 영역 토글 |
| 주문일시 | `YYYY-MM-DD HH:mm` + 상대시간 | |
| 마켓 | 마켓 아이콘 + 스토어명 | |
| 상품정보 | 썸네일 + 상품명 + 옵션 + 수량 + 마켓 주문번호 | |
| 처리상태 | 내부 상태 뱃지 | 라벨/색상은 3장 기준 |
| 소싱 | 소싱라이프 연동 상태 뱃지 | `-` / 매칭완료 / 결제대기 / 결제완료 / 입고 / 실패 |
| 수령자 | 성함 + 연락처 + PCCC 뱃지 | PCCC 클릭 → 통관부호 모달 |
| 금액 | 결제금액 / 예상 마진율 | 마진 < 0% 시 빨강 강조 |
| 작업 | 메뉴별 주요 액션 버튼 | 2장 기준 |

- 데이터 없음: "주문이 없습니다."
- 행 확장 영역: 인적 정보, PCCC, 비용 상세(결제금액/수수료/소싱원가/환율/배송비/예상마진), 국내송장 정보, 내부 메모, [히스토리] 버튼.

## 2. 메뉴별 화면 명세

### 2.1 신규주문 (`/orders/new`)

- **목적**: 수집된 결제완료 주문 확인 후 발주확인 처리.
- **행 버튼**: [발주확인]
- **상단 일괄 버튼**: [선택 발주확인]
- **버튼 활성 조건**: 내부 상태 = `NEW`.
- **확인 모달**: "선택한 N건을 발주확인 처리합니다. 마켓에 발주확인이 전송됩니다. 진행하시겠습니까?" — [확인] / [취소]
- **결과 토스트/모달**:
  - 전체 성공: "N건 발주확인이 완료되었습니다."
  - 부분 실패: 결과 모달 — 성공 N건 / 실패 N건 목록 + 실패 사유.
- **쿠팡 배송지 변경 감지 시**: 해당 행에 `배송지 변경됨` 주황 뱃지 + 확장 영역에 변경 전/후 주소 비교 표시.

### 2.2 상품준비 (`/orders/preparing`)

- **목적**: 소싱 매칭 → 마진 검토 → 소싱라이프 결제 → 국내송장 확보.
- **상태별 행 버튼**:

| 내부 상태 | 버튼 | 동작 |
|---|---|---|
| `SOURCING_REQUIRED` | [소싱 매칭] | 소싱 상품 검색/마진 검토 모달 → [소싱 확정] |
| `SOURCING_PAYMENT_PENDING` | [소싱라이프 결제] | 소싱라이프 결제 진행 (외부 연동) |
| `SOURCING_PAYMENT_COMPLETED` | (버튼 없음, 자동 진행) | 송장 분기 대기 표시 |
| `DOMESTIC_TRACKING_PENDING` | [송장 입력] | 국내송장 수동 입력 모달 |

- **소싱 확정 모달**: 좌(주문 상품/정산 예상액) · 중(소싱 후보 상품) · 우(상세 분석: 원가/환율/배송비/순이익/마진율) 3단 구성. [소싱 확정] 클릭 시 확정.
  - 마진 음수 경고: "예상 마진이 마이너스입니다. 그래도 확정하시겠습니까?" — [확정] / [취소]
- **소싱라이프 결제 실패 시**: 행에 `소싱 실패` 빨강 뱃지 + [재시도] 버튼.

### 2.3 발송대기 (`/orders/waiting`)

- **목적**: 국내송장 확보 주문의 마켓 송장전송.
- **행 버튼**: [송장전송] (상태 `MARKET_INVOICE_PENDING`), [재시도] (상태 `MARKET_INVOICE_FAILED`), [송장 수정] (전송 전 송장 변경)
- **상단 일괄 버튼**: [선택 송장전송]
- **버튼 비활성 조건과 안내**:
  - 국내송장 없음: 버튼 비활성 + 툴팁 "국내송장이 등록되어야 전송할 수 있습니다."
  - 쿠팡 `ACCEPT` 상태: 비활성 + 툴팁 "발주확인(상품준비중 처리)이 먼저 필요합니다."
- **확인 모달**: "선택한 N건의 송장을 마켓에 전송합니다. 전송 성공 시 주문이 배송중으로 변경됩니다. 진행하시겠습니까?"
- **실패 배너**: `MARKET_INVOICE_FAILED` 1건 이상 시 화면 상단 — "송장전송 실패 N건이 있습니다. 확인 후 재시도해주세요." (클릭 시 실패 필터 적용)
- **실패 사유 표시**: 행 확장 영역에 마켓 오류 코드 + 메시지 + 시도 이력.

### 2.4 배송중 (`/orders/shipping`)

- **목적**: 송장 등록 완료 주문의 배송 추적.
- **추가 컬럼**: 택배사 / 송장번호 (클릭 시 배송조회 새 창).
- **행 버튼**: [송장 수정] (마켓 지원 시에만 노출).
- 상태 갱신은 자동 수집으로만 진행. 수동 상태 변경 버튼 없음.

### 2.5 배송완료 (`/orders/delivered`)

- **목적**: 배송완료/구매확정 확인 및 정산 참고.
- 행 버튼 없음 (조회 전용). 구매확정 건은 `구매확정` 뱃지.

### 2.6 취소/반품/교환 (`/orders/claims`)

- **목적**: 클레임 인입 확인과 승인/거부 처리.
- **상태별 행 버튼**:

| 내부 상태 | 버튼 |
|---|---|
| `CANCEL_REQUESTED` | [취소 승인] / [취소 거부] |
| `RETURN_REQUESTED` | [반품 승인] / [반품 거부] |
| `RETURN_IN_PROGRESS` | [반품 완료] |
| `EXCHANGE_REQUESTED` | [교환 승인] / [교환 거부] |
| `EXCHANGE_IN_PROGRESS` | [재발송 송장 입력] |

- **소싱 결제 완료 건 취소 승인 시 확인 모달**:
  "이 주문은 소싱라이프 결제가 완료된 주문입니다. 취소 승인 시 소싱 주문 취소를 함께 요청합니다. 소싱 취소가 불가능한 경우 재고로 처리해야 합니다. 진행하시겠습니까?" — [승인 진행] / [돌아가기]
- **거부 시**: 마켓 표준 거부 사유 드롭다운 선택 필수.
- **클레임 인입 알림**: 신규 클레임 수집 시 헤더 알림 + 메뉴 뱃지 카운트 증가.

### 2.7 전체 (`/orders`)

- 모든 상태 통합 조회. 행 버튼은 해당 주문의 현재 상태에 맞는 버튼을 그대로 노출 (각 메뉴와 동일 규칙).

## 5. 마켓 연동 화면 (`/me/markets`) 보강 사항

- 마켓별 카드: 마켓명, 연동 상태(`연동됨`/`재인증 필요`/`미연동`), 마지막 수집 시각, [연동하기]/[재인증]/[설정] 버튼.
- 네이버: 애플리케이션 ID/Secret 입력. 쿠팡: vendorId / Access key / Secret key 입력.
- 인증 실패 상태의 마켓은 카드 테두리 빨강 + "주문 수집이 중단되었습니다" 경고 문구.
