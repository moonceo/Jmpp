# [기획서] 3.2 마켓 연동

## 1. 개요
스마트스토어, 쿠팡, 11번가 등 오픈마켓 계정을 연동해 판매/주문 데이터를 끌어오는 핵심 설정 화면.

## 2. 상세 명세

### 2.1 마켓별 입력 항목 정의 (Data Specification)
사용자가 마켓 연동 화면에서 입력해야 하는 정보의 정의입니다. 디자인 및 QA 시 해당 항목의 노출 여부와 유효성 체크의 기준이 됩니다.

| 구분 | 항목명 | 필드 타입 | 필수 여부 | 설명 및 비고 |
| :--- | :--- | :--- | :---: | :--- |
| **공통** | 마켓플레이스 | Select Box | 필수 | 쿠팡, 스마트스토어, 11번가, ESM 중 선택 |
| **공통** | 스토어 별명 | Text | 필수 | 주문팡팡 내 관리용 (예: 쿠팡-강남점) |
| **공통** | 사업자 번호 | Text (Num) | 필수 | 해당 마켓 등록 사업자 번호 |
| **공통** | CS 전화번호 | Text (Num) | 필수 | 고객 응대용 전화번호 |
| **쿠팡** | 업체코드 | Text | 필수 | Coupang Wing 내 업체코드 (Vendor ID) |
| **쿠팡** | Access Key | Text | 필수 | Coupang API 인증키 |
| **쿠팡** | Secret Key | Password | 필수 | Coupang API 보안키 |
| **네이버** | 커머스 API ID | Text | 필수 | 네이버 커머스 API 센터 발급 ID |
| **네이버** | API Secret | Password | 필수 | 네이버 커머스 API 센터 발급 Secret |
| **11번가** | API 인증키 | Text | 필수 | 11번가 오픈 API 센터 발급 키 |
| **ESM** | Master ID | Text | 필수 | 지마켓/옥션 통합 마스터 아이디 |
| **ESM** | Seller ID | Text | 필수 | 마켓별 개별 셀러 아이디 |

## 3. 운영/기획 결정 필요 사항
### 3.1 API 연동 한도(Quota) 제한 관리
- 각 마켓플레이스별 일일 API 호출 한도(Rate Limit) 초과 방지를 위한 동기화(Polling) 간격 최적화 정책.
### 3.2 보안 및 토큰 관리
- 커머스 API 연동키의 암호화 저장 방식 및 토큰 만료 전 고객(셀러) 대상 갱신(Renew) 알림 주기 결정.
### 3.3 동기화 실패 및 예외 처리
- API 연동 일시 오류 시의 시스템 알림 방식 및 장애 복구 후 누락된 주문을 백필(Backfill) 처리하는 아키텍처.
### 3.4 신규 마켓 확장 방안
- 추후 11번가, 롯데온 및 글로벌 마켓 연동을 위한 공통 인터페이스 규격 체계 정의.
### 3.5 결제 수단 명확화
- 사용자가 등록하는 카드의 결제 목적(해외 배달, 관세 등) 사전 고지 등 예외 처리.
