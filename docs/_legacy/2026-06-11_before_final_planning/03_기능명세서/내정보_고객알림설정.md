# [기획서] 3.3 고객 알림 설정

## 1. 개요
구매자에게 배송 진행 상태, 결제 관련 알림을 카카오톡/문자로 자동 발송하는 템플릿 제어 메뉴.

## 2. 상세 명세

### 2.1 알림 항목 및 데이터 정의 (Data Specification)
고객에게 발송되는 자동 메시지의 트리거 및 템플릿 항목입니다.

| 구분 | 항목명 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **통관부호 수집** | 알림 사용 여부 | Boolean | 활성 | 주문 접수 시 카톡 전송 여부 |
| **통관부호 수집** | 전송 시간대 | Range | 09:00~21:00 | 고객 방해 금지 야간 전송 제한 시간 |
| **통관부호 수집** | 메시지 템플릿 | LongText | [시스템 기본] | 통관부호 입력 요청 가이드 텍스트 |
| **중국 현지배송** | 알림 사용 여부 | Boolean | 활성 | 중국 내 송장 번호 발생 시 전송 여부 |
| **중국 현지배송** | 메시지 템플릿 | LongText | [시스템 기본] | 현지 송장 번호 및 위치 안내 텍스트 |
| **배대지 출고** | 알림 사용 여부 | Boolean | 활성 | 배대지에서 한국으로 발송 시 전송 |
| **배대지 출고** | 운송장 정보 | String | 자동 매핑 | 국내 택배사 및 등기 번호 포함 여부 |

## 3. 운영/기획 결정 필요 사항

### 2.1 발송 채널 및 벤더 선정
- 주 활용 채널(카카오톡 알림톡) 및 실패 시 대체 전송 채널(SMS/LMS) 정책 및 알림톡 벤더사(비즈톡 등) 선정.
### 2.2 발송 조건 및 횟수 제한 정책
- 알림 전송의 정확한 트리거 기준, 리마인드 재발송 빈도 및 고객 에티켓 시간(야간 발송 금지) 규정.
### 2.3 메시지 템플릿 관리
- 카카오톡 알림톡 사전 승인 정책을 고려한 템플릿 관리 방안 및 기본 노출 텍스트 템플릿 확정.
### 2.4 비용 산정 및 과금 로직
- 알림톡 사용에 따른 요금제 과금 방식(선불 충전제 vs 플랜 내 기본 제공량 차감 방식) 결정.
### 2.5 예외 상황(취소/환불) 처리
- 시스템 에러나 고객 단순 변심 시 알림톡 전송 내역에 대한 취소/환불 여부 및 CS 대응 가이드라인.
### 2.6 향후 고도화(자동 챗봇 연동)
- 자동 응답 AI 챗봇과의 연계를 통한 단순 CS 방어 및 인건비 절감 모색 방안.
