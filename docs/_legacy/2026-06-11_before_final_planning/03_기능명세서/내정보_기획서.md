# [기획서] 3.0 내 정보 (My Info)

## 1. 개요
'내 정보' 메뉴는 사용자의 구독 상태, 마켓 연동, 고객 알림 설정, 매출 장부 데이터 및 계정 보안을 통합 관리하는 설정 센터이다.

## 2. 서브 메뉴별 상세 명세

### 3.1 플랜 결제하기 (구독 및 멤버십 관리)
이 페이지는 주문팡팡 서비스의 이용 등급을 선택하고 비용을 관리하는 곳입니다. 회사의 자산이 어떻게 사용되고 있는지, 현재 어떤 혜택을 받고 있는지 한눈에 파악할 수 있도록 설계되었습니다.

![내정보_메뉴](../_assets/내정보_1_메뉴.png)

- **구독 현황 관리 (현재 플랜)**:
    - **상태**: 현재 이용 중인 등급(예: Basic)과 금액(월 20,000원)을 보여주며, '활성' 배지를 통해 정상 이용 중임을 확인해 줍니다.
    - **비용 예측**: 다음 결제일과 결제될 금액을 미리 안내하여 예산 계획을 돕습니다.
    - **요금제 업그레이드 버튼**: 현재 플랜 보다 상위 요금제로 업그레이드, 예시 'Standard로 업그레이드'
    - **서비스 혜택**: AI 소싱, 마진 분석, 통합 주문 관리, 실시간 배송 추적 등 현재 등급에서 누릴 수 있는 주요 기능들이 목록으로 나열되어 있습니다.
- **지출 수단 관리 (결제 수단)**:
    - 서비스 비용이 자동 결제될 카드 정보를 관리합니다. 카드 번호는 보안을 위해 뒷자리만 노출되며, '카드 추가' 버튼으로 간편하게 결제 수단을 변경할 수 있습니다.
    - **현재 등록 된 카드 기본 정보**:
        - 카드 종류, 뒷번호
        - 여러 카드 등록 시 기본 카드 표시
    - **새 카드 등록 모달 상세 (Verified)**:
        - **카드번호**: 16자리 숫자 입력 (4자리씩 구분).
        - **유효기간**: MM / YY 형식 입력.
        - **카드 비밀번호 앞 2자리**: 보안을 위해 앞 2자리만 입력.
        - **생년월일(YYMMDD) 또는 사업자번호**: 개인/법인 카드 구분을 위한 정보 입력.
        - **안내 문구**: "카드 정보는 안전하게 암호화되어 저장됩니다. 실제 결제는 주문 처리 시 진행됩니다."
        - **버튼**: 취소/카드등록
- **지출 증적 (플랜 결제 내역)**:
    - 서비스 이용을 위해 지불한 모든 비용의 이력을 제공합니다. 결제 일시, 플랜명, 금액, 그리고 **성공/취소완료** 상태를 투명하게 공개하여 회계 처리를 지원합니다.

### 3.2 마켓 연동하기 (판매 채널 관리)
여러 쇼핑몰에서 발생하는 주문을 주문팡팡 시스템으로 자동으로 가져오기 위해 각 마켓을 연결.

- **연동 현황판**: 현재 어떤 쇼핑몰들이 주문팡팡과 연결되어 있는지, 서비스가 정상적으로 작동하고 있는지 한눈에 보여줍니다. '연결됨' 표시와 마지막 확인 시각을 통해 데이터의 최신성을 보장합니다.
- **스토어 목록 및 관리 (Data Table)**:
    - 마켓 플레이스: 스마트스토어, 쿠팡, 11번가 등 오픈마켓 종류 표시, 마켓 로고와 이름
    - **마켓 정보**: 사용자가 설정한 **마켓 별명(상점명)**, 그리고 로그인 ID를 표시하여 여러 계정을 쉽게 구분합니다.
    - **사업자 정보**: 등록된 사업자 번호와 고객센터 연락처를 노출합니다.
    - **인증 상태**: '연결됨(Green)' 상태 배지와 함께 **마지막 확인 시각(Timestamp)**을 초 단위까지 보여주어 데이터 동기화 상태를 확신할 수 있습니다.
    - **결제 카드**: 해당 마켓의 주문 처리에 사용되는 카드 정보(카드사, 끝 4자리)를 목록에서 바로 확인합니다.
    - **관리 액션**:
        - **설정(Gear)**: 인증 정보 갱신 및 배송 정책 수정.
            - 해당 스토어 정보 입력된 마켓연동하기 모달
        - **마켓 이동(External Link)**: 클릭 시 해당 쇼핑몰 판매자 센터(어드민)로 즉시 이동.
- **쇼핑몰 추가 (+ 마켓 연동하기)**:
    - 네이버 스마트스토어, 쿠팡, 11번가, G마켓, 옥션 등 국내 주요 쇼핑몰 연동을 지원합니다.
    - **마켓 연동 모달 상세 (Verified)**:
        - **공통 입력 항목**:
            - **기본 정보**: 마켓플레이스(선택), 마켓 별명, 로그인 ID, 비밀번호(눈 아이콘으로 토글), 사업자번호, CS 전화번호.
            - **결제 카드**: 등록된 카드 목록에서 선택 가능하며, `+ 새 카드 등록` 버튼 제공.
        - **마켓별 인증 정보 (Authentication Info)**:
            - **공통 필수 사항**:
                - 마켓별 **로그인 ID/비밀번호** (시스템 접속용) 
                - **사업자 번호** 및 **CS 전화번호**
                - **정산/결제 카드 정보** (주문 처리 및 서비스 이용료 결제용)

            | 마켓플레이스 | 주요 인증 항목 (API Key) | 비고 |
            | :--- | :--- | :--- |
            | **네이버 스마트스토어** | Client ID, Client Secret, 커머스 ID | 커머스 API 센터에서 발급 |
            | **쿠팡** | 업체코드(A...), Access Key, Secret Key | 쿠팡윙(API 관리)에서 발급, **180일 주기 갱신 필수** |
            | **11번가** | Open API Key (Seller Key) | 셀러오피스 API 사용 승인 필요 |
            | **G마켓 / 옥션** | ESM ID (마켓 ID), API 인증키 | 사이트별(G/A) 인증키 별도 발급 |
            | **롯데온** | API Key, Vendor ID (업체번호) | 스토어 센터에서 발급 |
            | **SSG.COM** | Partner ID, API Key | 파트너 오피스에서 발급 |

            *마켓플레이스를 선택하기 전에는 "마켓플레이스를 먼저 선택해주세요." 문구 노출.*
        - **검증 및 저장**: '취소'와 '추가' 버튼 제공. '추가' 클릭 시 실제 연동 테스트 진행 후 저장.
    - 가이드에 따라 정보를 입력하면 주문팡팡 AI가 연결 가능 여부를 테스트하고 즉시 연동을 완료합니다.

### 3.3 고객 알림 설정 (메시지 자동 발송 관리)

> [!IMPORTANT]
> **추가 기획 필요**: 해당 기능에 대한 세부적인 추가 기획이 진행될 예정입니다. 현재 명세된 내용은 유지하며, 추후 확정된 기획안을 바탕으로 수정될 수 있습니다.

배송 과정의 주요 시점마다 고객에게 카카오 알림톡을 자동으로 발송하여 상담 문의를 획기적으로 줄여주는 똑똑한 비서 기능입니다.

*   **자동 알림 단계 (3단계)**:
    1.  **통관부호 수집 (ON/OFF)**: 해외 직구에 꼭 필요한 '개인통관고유부호'가 누락된 고객에게 입력을 요청합니다. **(최대 3회 자동 리마인드 발송)**
    2.  **중국 현지배송 시작 (ON/OFF)**: 물건이 해외 현지에서 이동하기 시작했음을 알려 불안감을 해소합니다. (소싱 완료 시점)
    3.  **배대지 출고 알림 (ON/OFF)**: 물류센터 검수가 끝나고 한국으로 출발했음을 안내합니다.
*   **세부 운영 정책**:
    *   **발송 시간 제한 (에티켓 설정)**: 너무 늦은 시간에 알림이 가서 고객이 불편해하지 않도록, 오전 10시~오후 8시처럼 원하는 시간대에만 발송되도록 설정할 수 있습니다.
    *   **메시지 맞춤화 (템플릿)**: 
        - **기본 템플릿**: 주문팡팡이 제공하는 표준 문구 사용.
        - **고객 안내 커스텀**: 우리 업체만의 말투로 직접 문구를 수정하여 브랜드 이미지를 강화할 수 있습니다.
    *   **추가 옵션 (Verified)**:
        - **주문 취소하기 버튼 숨기기 (Toggle)**: 활성화 시 알림톡에서 "주문 취소하기" 버튼이 제거되어 불필요한 취소를 예방합니다.
        - **관부가세/경동 택배비 안내 추가 (Toggle)**: 활성화 시 알림톡 문구에 관부가세 및 경동택배 배송비 관련 안내가 자동으로 포함됩니다.
*   **실시간 미리보기**: 
    
    ![내정보_고객알림설정](../_assets/내정보_고객알림설정.png)

    설정한 내용이 고객의 스마트폰 화면(카카오톡)에서 어떻게 보여질지 우측의 모바일 화면을 통해 즉시 확인할 수 있습니다.

### 3.4 장부 다운로드 (데이터 추출 및 정산 관리)

> [!IMPORTANT]
> **추가 기획 필요**: 해당 기능에 대한 세부적인 추가 기획이 진행될 예정입니다. 현재 명세된 내용은 유지하며, 추후 확정된 기획안을 바탕으로 수정될 수 있습니다.

판매자가 직접 수기 장부를 적지 않아도, 주문팡팡이 모은 방대한 주문 데이터를 엑셀 파일로 추출해 주는 데이터 센터입니다. 세무 신고나 수익 분석에 필수적인 정보를 제공합니다.

![내정보_장부다운로드](../_assets/내정보_장부다운로드.png)

*   **최신 데이터 자동 갱신**: 주문 데이터는 매일 새벽 2시와 오후 2시, 하루 두 번 주문팡팡 AI가 자동으로 최신 상태로 업데이트하여 정확한 장부 작성을 돕습니다.
*   **간편한 기간 선택**: 원하는 연도와 월을 선택하면 해당 기간의 총 주문 건수를 즉시 확인하고 데이터를 정제할 수 있습니다.
*   **스마트 필터 (데이터 정제)**:
    *   **마진 확정 주문만 보기**: 배송이 끝나고 이익이 정확히 계산된 주문들만 골라낼 수 있습니다.
    *   **취소/반품 주문 제거**: 환불되거나 취소된 건을 제외하고 실제로 벌어들인 순매출 이력만 추출하여 장부의 정확성을 높입니다.
*   **엑셀 생성 및 저장**: 우측 상단의 다운로드 버튼을 누르면 엑셀 파일(.xlsx)이 생성되어, 컴퓨터에 영구 보관하거나 세무사에게 전달하는 등 비즈니스 목적으로 즉시 활용할 수 있습니다.

### 3.5 설정 (계정 정보 및 작업)
주문팡팡 서비스를 안전하게 이용하기 위한 개인 보안 및 시스템 설정 공간입니다.

- **계정 정보 (Verified)**: 현재 로그인된 관리자 이메일과 마지막 로그인 기록을 통해 계정 보안을 자가 진단할 수 있습니다.
- **계정 작업 (Verified)**:
    - **비밀번호 변경**: 정기적인 보안 강화를 위해 비밀번호를 변경할 때 사용합니다. `변경하기` 버튼을 클릭하여 수행합니다.
    - **로그아웃**: 업무를 마치거나 공용 컴퓨터를 사용할 때, 현재 기기에서 안전하게 로그아웃하여 타인의 접근을 차단합니다. `로그아웃` 버튼을 클릭하여 수행합니다.

## 4. 공통 UI/UX 정책
*   **반응형**: 모바일에서도 설정 변경이 가능하도록 Card 리스트 형태의 UI 채택 (Not Table).
