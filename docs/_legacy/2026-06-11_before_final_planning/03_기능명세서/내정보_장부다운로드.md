# [기획서] 3.4 장부 다운로드 (데이터 추출 및 정산 관리)

> [!IMPORTANT]
> **추가 기획 필요**: 해당 기능에 대한 세부적인 추가 기획이 진행될 예정입니다. 현재 명세된 내용은 유지하며, 추후 확정된 기획안을 바탕으로 수정될 수 있습니다.

## 1. 개요
판매자가 직접 수기 장부를 적지 않아도, 주문팡팡이 모은 방대한 주문 데이터를 엑셀 파일로 추출해 주는 데이터 센터입니다. 세무 신고나 수익 분석에 필수적인 정보를 제공합니다.

![내정보_장부다운로드](../_assets/내정보_장부다운로드.png)

## 2. 상세 명세

### 2.1 장부 추출 필터 정의 (UI Input Spec)
사용자가 엑셀을 다운로드하기 전 설정하는 조건 데이터입니다.

| 항목명 | 데이터 타입 | UI 컨트롤 | 설명 |
| :--- | :--- | :--- | :--- |
| **추출 기간** | Date (YYYY-MM) | Date Picker | 특정 연도와 월을 선택 (월 단위 추출) |
| **마진 확정 필터** | Boolean | Checkbox/Switch | 정산 완료된(이익이 확정된) 건만 포함 |
| **정상 주문 필터** | Boolean | Checkbox/Switch | 취소, 반품, 환불 건 자동 제외 여부 |

### 2.2 상세 기능 명세
#### 2.2.1 최신 데이터 자동 갱신
주문 데이터는 매일 새벽 2시와 오후 2시, 하루 두 번 주문팡팡 AI가 자동으로 최신 상태로 업데이트하여 정확한 장부 작성을 돕습니다.

#### 2.2.2 간편한 기간 선택
원하는 연도와 월을 선택하면 해당 기간의 총 주문 건수를 즉시 확인하고 데이터를 정제할 수 있습니다.

#### 2.2.3 스마트 필터 (데이터 정제)
- **마진 확정 주문만 보기**: 배송이 끝나고 이익이 정확히 계산된 주문들만 골라낼 수 있습니다.
- **취소/반품 주문 제거**: 환불되거나 취소된 건을 제외하고 실제로 벌어들인 순매출 이력만 추출하여 장부의 정확성을 높입니다.


### 2.4 엑셀 생성 및 저장
우측 상단의 다운로드 버튼을 누르면 엑셀 파일(.xlsx)이 생성되어, 컴퓨터에 영구 보관하거나 세무사에게 전달하는 등 비즈니스 목적으로 즉시 활용할 수 있습니다. 
다운로드되는 엑셀 장부의 템플릿 항목은 총 36개 컬럼으로 다음과 같이 구성됩니다:
- **기본/고객 정보**: 주문일, 마켓, 스토어명, 마켓주문번호, 마켓주문상태, 수령자명, 통관부호, 연락처, 우편번호, 배송지주소
- **상품 정보**: 상품명, 옵션, 수량, 단가
- **정산/마진 정보(원화)**: 고객 총 결제 금액, 마켓 판매 수수료, 수수료율(%), 정산예상금, 총비용, 최종마진, 마진율(%)
- **마진 구성요소(소싱/배대지/배송)**: 소싱금액(CNY), 적용환율, 소싱 결제 카드, 소싱 결제 금액, 소싱 결제 상태, 배대지배송비, 배대지부가비용, 배대지 결제 카드, 배대지 결제 금액, 배대지 결제 상태, 국내 배송 운송사, 국내 배송 운송장
- **기타 관리용**: 사업자번호, 주문 메모, 배송비 메모

# [역기획] 내정보: 장부다운로드

## 1. 개요
쇼핑몰 결산 및 세무 증빙을 위한 엑셀 데이터 추출 포맷과 다운로드 주기 정책입니다.

## 2. 운영/기획 결정 필요 사항
### 2.1 데이터 갱신 및 보존 정책
- 지정된 배치 처리 간격(일 2회)의 지연 리스크 방어, 그리고 추출 가능한 과거 데이터 보존 최대 기간(예: 3년) 명시.
### 2.2 장부 엑셀 데이터 항목 및 포맷 (36 컬럼 기준)
- 다운로드 엑셀 파일명 규칙(장부_YYYY년MM월_계정명.xlsx) 및 필수 포함 36개 컬럼 항목 확인 완료.
### 2.3 스마트 필터 정합성 및 세무 지원
- '마진 확정 건만 보기' 필터링의 정확한 시점 기준(정산금 입금일 등) 및 복수 사업자 분리 저장 가이드라인 마련.
