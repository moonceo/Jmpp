# [기획서] 3.1 플랜 결제하기

## 1. 개요
쇼핑몰 판매 플랜(구독형 요금제)을 결제하고 관리하는 메뉴입니다.

## 2. 상세 명세

### 2.1 주요 데이터 항목 정의 (Data Specification)
사용자의 구독 상태 및 결제수단 관리를 위한 UI 노출/입력 항목입니다.

| 구분 | 항목명 | 데이터 타입 | 노출 형식 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **현재플랜** | 구독 플랜명 | String | Label | 현재 이용 중인 등급 (Basic/Pro 등) |
| **현재플랜** | 잔여 주문 한도 | Number | Progress Bar | 현재 월 잔여 처리 가능 주문 수 |
| **현재플랜** | 다음 결제 예정일 | Date | Text | 자동 연장 결제가 발생하는 날짜 |
| **결제수단** | 카드사명 | String | Label | 등록된 결제 카드 브랜드 (예: 현대, 삼성) |
| **결제수단** | 카드번호 | String | Masking | **** **** **** 1234 형태로 마스킹 노출 |
| **결제수단** | 기본 카드 여부 | Boolean | Badge/Toggle | 여러 카드 중 주 결제 수단 활성화 여부 |
| **결제내역** | 결제 일시 | DateTime | List Item | 실제 결제가 일어난 시각 |
| **결제내역** | 결제 금액 | Currency | Text | KRW (원화) 기준 최종 결제액 |
| **결제내역** | 상태 | Enum | Badge | 결제완료 / 취소 / 실패 등 |

### 2.2 기능 상세 명세
#### 2.2.1 현재 플랜 관리
- 현재 구독 중인 플랜 정보 표출 및 다음 결제 예정일 / 잔여 혜택(주문 건수 한도) 노출.
#### 2.2.2 결제 수단 관리
- 카드 등록, 변경 및 삭제 기능. 주 결제 카드 설정 기능 포함.
#### 2.2.3 결제 내역 (역사)
- 월별 결제 히스토리, 영수증 다운로드 기능 제공.


# [역기획] 내정보: 플랜결제하기
## 1. 개요
플랜 결제를 위한 등급 체계 및 환불/과금 프로세스 정책입니다.

## 2. 운영/기획 결정 필요 사항
### 2.1 플랜 구성 및 금액 산정(Pricing)
- 티어별 혜택 및 과금 주기(월/년 결제), 첫 가입 체험판(Free Trial) 할인 정책 규정.
### 2.2 플랜별 서비스 스코프 한도
- 한도(주문 처리 건수, AI 소싱 제한 등) 초과 시 서비스 동작 제한안 마련.
### 2.3 플랜 변경(업그레이드/다운그레이드) 로직
- 도중 요금제 변경 시 즉시 혹은 다음 결제일 적용 환급액 정산 계산법.
### 2.4 PG 연동 및 결제 실패 처리
- 잔액 부족 등으로 월간 자동 결제 실패 시 재시도(Retry) 스케줄러 정책 및 서비스 정지 트리거 시점 제어.
