# [기획서] 3.5 설정

## 1. 개요
쇼핑몰 관리자의 계정 정보 변경, 보안 조치, 기기 세션을 관리하는 총괄 제어 화면입니다.

## 2. 상세 명세

### 2.1 계정 관리 데이터 정의 (Data Specification)
사용자 개인 계정 및 보안 관련 필드 사양입니다.

| 구분 | 항목명 | 데이터 타입 | 필드 형식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **프로필** | 프로필 이미지 | Image | File Upload | JPG/PNG/WebP 지원 |
| **프로필** | 아이디(이메일) | String (Email) | Read-only | 가입 시 이메일 (변경 불가) |
| **보안** | 현재 비밀번호 | Password | Input | 본인 확인용 |
| **보안** | 새 비밀번호 | Password | Input | 영문/숫자/특수문자 조합 |
| **세션** | 로그인 기기명 | String | Label | 접근한 브라우저/OS 정보 |
| **세션** | 최근 접속 IP | String (IP) | Label | 마지막 로그인 IP 주소 |
| **세션** | 서비스 로그아웃 | Action | Button | 해당 기기 세션 강제 종료 |

## 3. 운영/기획 결정 필요 사항

### 2.1 계정 보안 기준
- 주기적인 비밀번호 강제 변경(예: 3개월 단위) 규칙 및 비정상 접근(해외 IP 등) 탐지 기준 확립.
### 2.2 휴면 계정 정책 
- 미접속 기준 기간(예: 1년) 도래 시 휴면 계정 전환 기준 정의 및 마켓 연동 자동 해제 관련 약관 고지.
### 2.3 동시 접속 및 세션 제어
- 다중 기기 중복 로그인 허용 범주 및 웹 세션 자동 로그아웃 타임아웃(예: 30분 무응답) 기준.
### 2.4 회원 탈퇴 및 서브 권한 관리
- 계정 삭제(회원 탈퇴) 시 데이터 파기 규정 및 향후 부직원(서브 계정) 도입을 위한 RBAC 권한 분리 모델 구상.
