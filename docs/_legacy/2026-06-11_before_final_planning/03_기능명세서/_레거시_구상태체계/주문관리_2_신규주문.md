# 주문관리: 2. 신규주문 (New)

## 1. 개요
마켓에서 수집된 초기 주문을 검증(PCCC)하고, 마진을 검토하여 **발주(소싱)를 확정**하는 단계이다.

*   **URL**: `/orders/new`
*   **공통 UI 적용**: [0_공통.md](file:///f:/dev4/jumumpangpang/docs/주문관리_0_공통.md)의 도구 모음 및 테이블 규격을 따른다. **신규주문 특화**로 '선택(Checkbox)' 및 '일괄발주 플로팅 바' 기능이 활성화된다.

## 2. 처리 상태 (Processing Status)
*   **신규 주문**: 마켓에서 갓 수집되어 판매자가 확인하기 전의 상태.

### 2.1 상태 필터 목록 (Status Filter Options)
상단 도구 모음의 '상태 필터' 드롭다운에서 선택 가능한 옵션:
| 상태명 | 설명 |
| :--- | :--- |
| `신규 주문` | 마켓에서 수집되어 아직 발주 처리 전인 주문 |
| `알 수 없는 상태` | 마켓 API 오류 등으로 상태 파싱 실패 |
![로컬: 상태 필터](../_assets/신규주문/주문관리_신규주문_처리상태필터.png)


## 3. 화면 구성 및 특화 기능

### 3.1 리스트 뷰 (List View)
주문 목록을 표시하는 표준 Grid 규격이며, **신규주문 페이지 특화** 기능이 적용된다.

- **표준 컬럼 구성**:
    - **선택 (Check)**: (신규주문 특화) 테이블 좌측 체크박스. 1개 이상 선택 시 하단 **일괄발주 플로팅 바** 활성.
    - **확장 (Expand)**: 접기/펼치기 아이콘. 행 배경 클릭 시 상세 내역(Expand) 토글.
    - **작업 (Action)**: `발주 확인하기`, `마진 검토하기` 등 주요 워크플로우 버튼 배치.
    - **주문일시**: `YYYY-MM-DD HH:mm` 형식 및 n분 전 상대 시간 표기.
    - **상품정보**: 썸네일, 상품명, 옵션, 마켓 주문번호. AI 옵션 이미지 배지 포함.
    - **처리상태**: `신규 주문`, `알 수 없는 상태` 등의 컬러 배지.
    - **수령자**: 성함, 연락처 및 **PCCC 배지**.
        - (신규주문 특화) 상태에 따라 **'통관부호 요청' (Red)** 또는 **'통관부호 확인' (Green)** 버튼 노출.
    - **결제/마진**: 
        - **판매가**: 마켓 결제 금액 (Bold)
        - **예상 마진**: 정산 예정액 기반 단일 마진율 및 범위(%). 마진 < 0% 시 Red 강조.
    - **마켓**: 마켓 아이콘 및 상점명.
    - **메모**: 내부 관리용 메모 아이콘 및 텍스트 요약 (최대 2줄).

- **일괄발주 플로팅 바**:
    - 구성: `{n}개 주문 선택됨`, `선택 해제` 버튼, `일괄 발주 확인하기` (Green) 버튼.

### 3.2 상세 정보 확장 (Expand Row - 3단 레이아웃)
행 클릭 시 펼쳐지는 상세 영역은 벤치마킹 사이트 규격에 맞춰 **3단 그리드**로 구성된다.

![벤치마크: 신규주문 리스트 확장](../_assets/신규주문/주문관리_신규주문_목록_확장_벤치마크.png)

1.  **좌측 (정보 영역)**:
    - **주문자 정보**: 성함, 연락처.
    - **수령인 정보**: 성함, 연락처, 주소, 배송 메시지 (**수정 기능 지원**).
    - **PCCC 정보**: 통관부호 텍스트 및 상태 배지 (**자동 연동/검증**으로 별도 조작 버튼 없음).
2.  **중앙 (상세 내역 영역)**:
    - **주문 상품**: 썸네일, 상품명, 옵션, 수량, 단가.
    - **비용 상세**: 결제가격, 마켓 수수료, 정산 예상 금액.
    - **AI 예상 마진 (Blue Box)**: 파란색 배경의 강조 박스로 구성.
        - 예상 마진 범위 (%), 정산 예상 금액, 소싱 상품 금액, 배대지 비용, 최종 순이익.
3.  **우측 (워크플로우 영역)**:
    - **액션 버튼**: 모든 버튼은 아이콘을 제거하고 텍스트를 중앙 정렬(`justify-center`)하여 아래 순서로 배치한다.
        1. **주문 히스토리 보기** (Secondary, h-9)
        2. **발주 확인하기** (Primary 블랙, h-11)
        3. **마진 검토하기** (Secondary, h-9)
        4. **주문 취소하기** (Ghost, h-8) - 하단 영역에 분리 배치
    - **내부 관리 메모**: 
        - 셀러가 자유롭게 입력할 수 있는 공간.
        - **[저장]** 버튼을 클릭하여 시점별 기록 가능.
        - 저장된 메모는 테이블의 **'메모' 컬럼에 실시간 반영**되며, 가독성을 위해 **최대 2줄(말줄임표)**로 요약 출력된다.

## 4. 핵심 액션 (Actions)
1.  **발주 확인하기 (Primary)**: 
    - 주문을 인지했음을 마켓에 알리고 송장 번호(선택)를 입력하는 **[운송장 번호 입력]** 모달을 띄운다. 완료 시 `발송대기` 상태로 전환된다.
2.  **마진 검토하기 (Secondary)**: 
    - AI가 추천하는 소싱처를 선택하고 비용을 재계산하여 `소싱 진행`을 확정하는 **[마진 검토]** 모달을 오픈한다.
3.  **주문 취소하기 (Destructive)**: 
    - 품절, 고객 변심 등 취소 사유를 선택하고 마켓에 전송하는 **[주문 취소]** 모달을 오픈한다.

# [역기획] 주문관리: 2. 신규주문

## 1. 개요
수집된 신규 들어온 주문에 대한 원가 분석 처리 및 소싱 결정 자동화 기획 지침입니다.

## 2. 운영/기획 결정 필요 사항
### 2.1 AI 마진 최적화 평가 수용성
- 신규 주문 발생 시 AI가 가장 낮은 단가의 해외 소싱 상품을 매칭하되, 마진이 마이너스(-)일 때 사전 자동차단(거절) 할지 검토만 하게 둘지에 대한 결정.
### 2.2 대량 발주에 따른 리스크 체계 관리
- 50건 이상 다중 발주 확정 시 일부 타오바오 상품 재고 품절 등으로 실패(Partial Failure)했을 때의 일괄 롤백(Roll-back) vs 개별 에러 표기 정책.
### 2.3 PCCC 유효성 검증(Validation)
- 신규 접수됨과 동시에 통관부호 조회망(관세청 API 등)을 태울지, 발송대기 전환 전에 태울지에 대한 성능 이슈.
### 2.4 수동 소싱 대체제
- AI가 제공하는 소싱 아이템이 부적합할 경우 고객이 URL을 직접 넣는 UI 우회 방법 여부 확정.
