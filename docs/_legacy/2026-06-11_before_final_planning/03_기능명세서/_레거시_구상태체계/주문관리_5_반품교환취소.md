# 주문관리: 5. 반품교환취소 (Claims)

## 1. 개요
반품, 교환, 취소와 같은 고객의 클레임 요청을 통합하여 관리하고 처리하는 단계이다.

*   **URL**: `/orders/claims`
*   **공통 UI 적용**: [0_공통.md](file:///f:/dev4/jumumpangpang/docs/주문관리_0_공통.md)의 규격을 따른다.

## 2. 처리 상태 (Processing Status)
- **부제목**: "반품/교환/취소 요청을 확인하고 처리합니다."
- **검색바 플레이스홀더**: "마켓 주문번호, 주문 ID, 주문자, 수령인 정보, 상품명 검색"
- **특화 기능**:
  - **상태별 통합 필터**: 상단 도구 모음의 '상태 필터'를 통해 취소, 반품, 교환의 세부 상태를 선택하여 조회 가능.
  - **작업 컬럼 (Quick Action)**: 리스트의 '작업' 컬럼에서 즉시 처리가 필요한 버튼(`반품 처리`, `국내 송장 확인` 등)을 바로 노출.

### 2.1 상태 필터 목록 (Status Filter Options)
상단 도구 모음의 '상태 필터' 드롭다운에서 선택 가능한 옵션:

| 구분 | 상세 상태 | 설명 |
| :--- | :--- | :--- |
| **취소 (Cancellation)** | `취소 요청` / `취소 처리중` / `취소 완료` / `취소 거부` | 주문 취소 관련 단계별 상태 |
| **반품 (Return)** | `반품 요청` / `반품 수거중` / `반품 수거 완료` / `반품 완료` / `반품 거부` | 반품 프로세스 진행 상태 |
| **교환 (Exchange)** | `교환 요청` / `교환 처리중` / `교환 완료` / `교환 거부` | 교환 프로세스 진행 상태 |

### 2.2 상세 정보 (확장 레이아웃)
리스트 왼쪽의 `>` 버튼을 클릭하여 확장 시 노출되는 상세 정보 구성:

- **주문자/수령인 정보**: 이름, 연락처, 주소 등 기본 배송 정보.
- **국내 배송 정보**: 국내 배송 출발 여부 및 송장 번호 정보.
- **주문 상세 내역**:
  - **상품 정보**: 마켓 판매 상품 정보.
  - **결제/정산 정보**: 결제 금액, 정산 예정액 요약.
  - **비용/마진 분석**: 실 결제 원가, 수수료 등을 반영한 **예상 마진** 및 **마진율**.
- **처리 액션 섹션**: 해당 클레임 건에 대해 수행할 수 있는 모든 작업 버튼 노출.

## 3. 핵심 액션 (Actions)
모든 버튼은 아이콘을 제거하고 텍스트를 중앙 정렬하여 배치한다.

### 3.1 주요 처리 버튼
1.  **반품 처리 / 교환 처리 (Claim Processing)**
    - 승인 또는 거부 처리를 수행하는 핵심 액션. (상태에 따라 버튼명 가변)
2.  **국내 송장 확인 (Check Invoice)**
    - 입력된 국내 송장 번호를 확인하거나 수정.
3.  **추가 소싱하기 (Add Sourcing)**
    - 교환 등의 사유로 새로운 소싱이 필요할 때 사용.
4.  **배송대행지 관리 (Warehouse Management)**
    - 해당 주문과 연결된 배행지 주문서 연동 및 관리.
5.  **소싱주문 관리 (Sourcing Management)**
    - 해외 현지 소싱 주문 상태 확인 및 관리.
6.  **주문 히스토리 보기 (Order History)**
    - 해당 주문의 전체 이력을 타임라인으로 조회.
7.  **배송 추적 (Tracking)**
    - 현재 배송 위치 및 상태를 실시간 추적.
