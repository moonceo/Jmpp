주문목록

Path
GET
https://www.sellerpick.co.kr/partner/v1/getOrderList.php
Request Parameters
Path Segment Parameter
Name	Required	Type	Description
Key	O	Header	셀러픽에서 발급받은 API Key
sellerProdId		String	업체상품아이디
ordStatusCode		String	주문상태 코드
page		String	페이지 번호
페이지당 데이터 개수는 100개 입니다.
Request Sample

https://www.sellerpick.co.kr/partner/v1/getOrderList.php?ordStatusCode=RP
