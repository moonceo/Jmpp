# [기획] 서비스 FAQ 및 전문 용어 사전

주문팡팡을 이용하면서 궁금할 수 있는 질문들과 서비스에서 사용되는 주요 용어들을 정리했습니다.

## 1. 자주 묻는 질문 (FAQ)

**Q: 주문 수집은 얼마나 자주 일어디나요?**
A: 기본적으로 1시간마다 자동으로 수집되며, `대시보드`나 `주문관리` 상단의 '새로고침' 버튼을 눌러 즉시 수집할 수도 있습니다.

**Q: 통관부호가 잘못되었을 때 어떻게 하나요?**
A: 시스템에서 자동으로 오류를 감지합니다. 해당 주문의 `통관부호 요청` 버튼을 누르면 고객에게 수정 링크가 발송되며, 고객이 직접 입력하면 즉시 데이터에 반영됩니다.

## 2. 전문 용어 사전 (Glossary)

| 용어 | 설명 | 비고 |
| :--- | :--- | :--- |
| **PCCC** | 개인통관고유부호. 해외 직구 주문 시 세관 통관을 위해 반드시 필요한 수령인의 식별 번호입니다. | - |
| **소싱 (Sourcing)** | 판매할 상품을 현지(주로 중국) 도매처에서 구매하는 행위입니다. | - |
| **배대지** | 배송대행지. 현지에서 구매한 상품을 대신 받아 검수하고 한국으로 발송해주는 물류 거점입니다. | - |
| **정산예정금** | [거시적/대시보드용] 마켓 판매가 합계에서 마켓수수료 합계를 제외하고 셀러에게 실제 지급될 예정인 **총 금액**입니다. | **결제일** 기준 집계 |
| **정산예상금** | [미시적/주문별] **`고객 총 결제 금액 - 플랫폼 수수료`**. 개별 거래 단위에서 실제 정산될 것으로 추정되는 금액입니다. | 개별 마진 기준 |
| **플랫폼 수수료** | 스마트스토어, 쿠팡 등 각 오픈마켓 플랫폼 이용 시 발생하는 판매 수수료 및 결제 수수료의 합계입니다. | 마켓별 상이 |
| **총 비용** | `원화 매입가 + 배송비 합계 + 소싱 수수료(환전/카드)`. 취소/반품 시 매몰된 비용도 포함하여 계산됩니다. | 지불 총액 |
| **정확한 마진** | `정산예상금 - 총 비용`. (관부가세 대납 시 관부가세 추가 공제) | 실질 순수익 |
| **마진율 (%)** | `(최종 마진 / 정산예상금) * 100`. 수익성 지표. | - |
| **현지 상품 금액** | (소싱 원가) 타오바오 등 해외 소싱처에서 결제하는 순수 외화 상품 가격(CNY 등)입니다. | 외화 기준 |
| **환전 수수료** | 해외 결제 시 발생하는 카드사 수수료 및 은행 환전 수수료입니다. (보통 약 3% 내외 산정) | 매입가에 포함 |
| **소싱 총비용** | `(현지 상품 금액 * 적용 환율) + 환전/카드 수수료`. 즉, 소싱을 위해 실제 통장에서 출금된 통화(KRW) 총액입니다. (매입가) | 실 인출액 |
| **배대지 예상비용** | 실측 전 물품의 예상 무게 및 부피를 기반으로 산출된 가배송비. (최종 배송비 합계와 차이가 발생할 수 있음) | 마진 검토용 |
| **가송장** | 마켓의 발송 기한 패널티를 방지하기 위해 실송장 채번 전 임시로 입력하는 가상의 송장 번호입니다. | 패널티 방어용 |
| **적용 환율** | 해외 소싱처 **실제 결제 시점**의 전산 환율 (카드사/은행 고시 기준). | 결제 시점 기준 |
| **HS Code** | 수출입 물품을 숫자 코드로 분류한 국제 표준식별번호입니다. 통관 시 세금 산정의 기준이 됩니다. | 통관 필수 정보 |
| **목록/일반통관** | 물품 가액(@$150) 및 상품군에 따라 구분되는 통관 방식. 목록통관은 관세가 면제되는 경우가 많습니다. | 관부가세 결정 |
| **배송비 합계** | `현지 물류비 + 배대지 운임/부가서비스 + 국내 배송비`. (관부가세 미포함) | 실 물류 총비용 |
| **캐시백** | 타오바오 소싱 금액의 **0.38%**가 자동 적립되는 리워드. 60일 후 승인되며 5,000원 이상 출금 가능. | 자동 수익 강화 |
| **오류입고** | 배대지 검수 중 파손/오배송 발견 상태. '오류무시(출고)' 또는 '의견전달(교환/반품)'로 처리. | 물류 예외 관리 |
| **중판대화** | 중국 셀러와의 실시간 대화 기능. 자동 번역을 통해 소싱처와 원활한 소통 지원. | CS/소싱 도구 |
| **매칭률 (%)** | AI가 마켓 상품과 소싱 상품의 유사도를 판별한 점수. 높을수록 동일 상품 가능성 큼. | AI 엔진 신뢰도 |
| **부가서비스** | 정밀/작성 검수, 원산지 작업, 특급 포장 등 배대지에서 제공하는 추가 유료 옵션들. | 물류 품질 관리 |
| **직접전달** | 별도 송장 없이 처리하는 발송 방식. 11번가 가송장 패널티 방어 등에 활용. | 특수 발송 정책 |
| **합배송** | 서로 다른 주문을 배대지에서 하나의 운송장으로 묶어서 효율적으로 배송하는 방식입니다. | 물류비 절감 |
| **옵션 매핑** | 오픈마켓의 옵션명과 해외 소싱처의 옵션명을 시스템 내에서 동기화시키는 작업입니다. | 자동화 핵심 |
| **API 연동** | 마켓(네이버, 쿠팡 등)과 주문팡팡 시스템 간에 데이터를 주고받기 위한 기술적 연결입니다. | - |
| **마켓 페널티 비용** | 발송 지연, 판매자 취소 등으로 인해 오픈마켓에서 셀러에게 부과하는 벌금. | 정산예상금 차감 |
| **선결제 배송비(고객)** | 고객이 주문 시 상품 가격과 별도로 결제한 선배송비. (가끔 수수료 계산 시 상품가와 분리됨) | 마켓 수수료 계산용 |
| **소싱처 이용료** | '환전 수수료' 외에 1688 등 플랫폼 자체 결제 대행 수수료(알리페이 카드 수수료 등). | 비용 합산 요인 |
| **실측 배송비** | 배대지 입고 후 포장된 상태에서 측정한 최종 무게/부피를 기준으로 부과되는 확정 물류비. | 배대지 예상비용 대응 |
| **부피 무게** | 상품의 실 무게보다 부피가 클 경우, 체적(가로x세로x높이)을 기준으로 환산하는 항공 운임 무게. | 물류비 측정 기준 |
| **반품/회수 비용** | 통관 보류, 수취 거부 시 배대지나 국내 창고로 물건을 회수할 때 발생하는 추가 물류/보관 비용. | 예외 변동비 |
| **관부가세 대납액** | 고객 부담분이나, 통관 지연 방지를 위해 셀러가 관세사를 통해 선납한 세금. | 최종 마진 직접 차감 |
| **정산 확정일** | 마켓에서 셀러의 통장으로 '정산예정금(정산예상금 합계)'이 실제 입금 완료된 날짜. | 자금 흐름 기준 |
| **미수금** | (지연 정산금) 배송은 완료되었으나 마켓 정산 주기에 의해 아직 입금되지 않고 묶여 있는 자금. | 자금 현황 지표 |
| **매몰 비용(Sunk Cost)** | 이미 소싱 결제 및 배송이 진행되어 환불이나 회수가 불가능해진 완전한 순손실 총액. | 마진 손실 확정 |
