# [기획] 핵심 프로세스 플로우차트 (Flowcharts)

사용자가 시스템을 통해 주문을 처리하는 핵심 과정을 흐름도로 정의합니다.

## 1. 전제 주문 처리 프로세스 (Order To Delivery)

마켓에서 수집된 주문이 최종 배송 완료되기까지의 전체 흐름입니다.

```mermaid
graph TD
    A[마켓 주문 수집] --> B{신규주문 단계}
    B --> C[PCCC 통관부호 검증]
    C --> D[AI 마진 검토 및 소싱처 확정]
    D --> E[발송대기 단계]
    E --> F[배대지 전송 및 해외 송장 입력]
    F --> G[배송중 단계]
    G --> H[국내 운송장 전환 및 추적]
    H --> I[배송 완료]
    
    style B fill:#f9f,stroke:#333,stroke-width:2px
    style E fill:#bbf,stroke:#333,stroke-width:2px
    style G fill:#dfd,stroke:#333,stroke-width:2px
```

---

## 2. 소싱 및 마진 검토 프로세스 (Sourcing Flow)

AI 기반으로 최적의 상품을 찾아 마진을 확정하는 상세 단계입니다.

```mermaid
graph LR
    A[신규주문 확인] --> B[AI 소싱처 추천]
    B --> C{셀러 검토}
    C -- 가격/품질 적합 --> D[소싱 확정]
    C -- 부적합 --> E[대체 소싱처 검색]
    E --> B
    D --> F[최종 마진 계산 및 저장]
    F --> G[발송대기 이동]
```

---

## 3. PCCC (개인통관고유부호) 관리 프로세스

해외 직구 필수 정보인 통관부호의 유효성을 검사하고 수집하는 방식입니다.

```mermaid
graph TD
    A[주문 수집] --> B{통관부호 유무?}
    B -- 없음/오류 --> C[고객 알림 전송]
    B -- 정상 --> D[검증 완료 처리]
    C --> E[고객 전용 입력 페이지]
    E --> F[부호 재입력]
    F --> B
```

---

## 4. 반품 및 클레임 처리 프로세스

고객의 요구나 현지 사정으로 발생하는 클레임 처리 과정입니다.

```mermaid
graph TD
    A[클레임 접수] --> B{사유 분석}
    B -- 단순 변심 --> C[반품/취소 승인]
    B -- 오배송/파손 --> D[현지 재발송/보상 협의]
    B -- 품절/가격 변동 --> E[구매 취소 안내]
    C --> F[마켓 상태 동기화]
    D --> F
    E --> F
```
