# 워크스루 - 신규주문 UI 및 모달 정교화

벤치마킹 사이트(`oms.jumumpangpang.co`)와 동일한 수준의 데이터 밀도와 시각적 명확성을 확보하기 위해 신규주문 페이지의 UI와 주요 모달들을 정교화했습니다.

## 1. 테이블 리스트 UI 개선
목록에서 더 많은 정보를 한눈에 파악할 수 있도록 컬럼 구성을 최적화했습니다.

- **결제가/마진 컬럼**: 결제가, 예상 마진%, 마진 범위를 3단으로 구성하여 수익성을 즉시 파악 가능.
- **마켓 컬럼**: 아이콘과 스토어명을 사양에 맞게 병렬 배치.
- **PCCC 상태**: 통합 인증 상태를 뱃지 형태로 표시.

## 2. 모달 4종 정교화 및 벤치마킹 비교
각 액션별 모달을 벤치마킹 사이트와 1:1로 비교하며 픽셀 퍼펙트하게 구현했습니다.

### 3. 마진 검토 3단 레이아웃 구현
소싱 상품 선택 시 우측에 상세 분석 화면이 추가되는 3단 레이아웃을 구현했습니다.
*   **좌측**: 주문 상품 기본 정보 및 정산 가격.
*   **중앙**: AI 추천 소싱 상품 리스트 및 검색.
*   **우측**: 선택된 소싱 상품 상세, 배송 무게 입력, 실시간 마진 분석 및 발주 버튼.
