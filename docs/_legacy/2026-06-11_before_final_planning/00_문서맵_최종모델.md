## 작업 원칙

1. 새 기능/정책은 항상 🟢 정식 문서에 반영한다. 레거시 문서는 수정하지 않는다.
2. 🔵 참고 문서를 인용할 때는 최종 모델 기준으로 재작성해 🟢 문서에 반영한다.
3. 내부 상태 코드/라벨은 07 정식 문서가 유일한 원본이다. 다른 문서는 참조만 한다.
4. 영역별로 🟢 문서가 1종 이상 유지되도록 한다(현재 01~07 각 1종 확보).
