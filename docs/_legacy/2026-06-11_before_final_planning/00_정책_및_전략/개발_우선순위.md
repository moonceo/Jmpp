# 메뉴별 세부 개발 우선순위

모든 메뉴와 서브 메뉴를 독립된 섹션으로 나누어, 개발 순서와 중요도를 정리했습니다.

---

## 📂 1. 내 정보 (My Info)
전체 설정 공간이지만, **[마켓 연동하기]**가 개발의 0순위 엔진 역할을 합니다.

### 1-1. 마켓 연동하기
> **목표**: 마켓과 통신하여 데이터를 가져올 파이프라인 구축
- [ ] **[우선순위: ⭐⭐⭐]** 마켓별 API 인증 (스마트스토어, 쿠팡, 11번가 등)
- [ ] **[우선순위: ⭐⭐⭐]** 연동 현황판 (연결됨/마지막 확인 시각 표시)
- [ ] **[우선순위: ⭐⭐]** 마켓 이동(External Link) 및 설정 갱신 기능

### 1-2. 플랜 결제하기
> **목표**: 서비스 유료화 및 결제 수단 관리
- [ ] **[우선순위: ⭐]** 구독 현황 및 비용 예측 UI
- [ ] **[우선순위: ⭐]** 카드 등록 및 관리 (결제 수단)
- [ ] **[우선순위: ⭐]** 플랜 결제 내역 조회

### 1-3. 고객 알림 설정
> **목표**: 카카오 알림톡을 통한 자동 고객 케어
- [ ] **[우선순위: ⭐]** 알림 단계별 ON/OFF (통관부호/해외발송/배대지출고)
- [ ] **[우선순위: ⭐]** 알림톡 템플릿 커스텀 및 미리보기
- [ ] **[우선순위: ⭐]** 발송 시간 제한(에티켓) 설정

### 1-4. 장부 다운로드
> **목표**: 정산 및 세무 증빙 데이터 제공
- [ ] **[우선순위: ⭐]** 최신 데이터 자동 갱신 로직 (새벽 2시/오후 2시)
- [ ] **[우선순위: ⭐]** 기간별/조건별(마진확정 등) 필터링
- [ ] **[우선순위: ⭐]** 엑셀(.xlsx) 파일 생성 및 다운로드

### 1-5. 설정
> **목표**: 계정 보안 및 관리
- [ ] **[우선순위: ⭐⭐]** 계정 정보 조회 및 비밀번호 변경
- [ ] **[우선순위: ⭐⭐]** 로그아웃 기능

## 📂 2. 주문관리 (Order Management)
데이터 수집 후 **이익을 남기고 발송하는** 핵심 비즈니스 로직입니다.

### 2-1. 공통 (Common)
- [ ] **[우선순위: ⭐⭐⭐]** 주문 통합 검색 및 마켓/상태별 필터 툴바
- [ ] **[우선순위: ⭐⭐⭐]** 표준 주문 테이블(Grid) 및 행 확장(Expand) 레이아웃
- [ ] **[우선순위: ⭐⭐⭐]** 주문 히스토리(로그) 및 통관부호 정보 모달

### 2-2. 신규주문
- [ ] **[우선순위: ⭐⭐⭐]** **마진 검토 모달**: AI 추천 소싱처 선택 및 수익 계산
- [ ] **[우선순위: ⭐⭐⭐]** **PCCC 관리**: 개인통관고유부호 검증 및 수집 링크 생성
- [ ] **[우선순위: ⭐⭐]** 주문 취소 모달 (마켓 취소 연동)

### 2-3. 발송대기
- [ ] **[우선순위: ⭐⭐]** **소싱상품 결제하기**: 실제 구매를 위한 비용 세부 설정
- [ ] **[우선순위: ⭐⭐]** **발주 확인 모달**: 배대지 전송 및 송장 입력 처리
- [ ] **[우선순위: ⭐]** 가송장 필터 및 직접전달 처리

---

## 🏆 개발 로드맵 요약
1. **[내 정보 > 마켓 연동하기]**: 주문 수집 시작 (1st)
2. **[주문관리 > 공통 & 신규주문]**: 마진 계산 및 소싱 확정 (2nd)
3. **[주문관리 > 발송대기]**: 실제 발주 및 송장 처리 (3rd)
4. **기타 '내 정보' 페이지들**: 운영 보조 기능 (Bottom)
