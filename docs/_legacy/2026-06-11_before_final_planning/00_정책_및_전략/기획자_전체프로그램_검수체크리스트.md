# 주문팡팡 전체 프로그램 상세 검수 체크리스트

기획자가 개발자와 화면을 같이 보면서 기능별로 하나씩 확인할 수 있도록 세분화한 검수 체크리스트입니다.

## 1. 공통

- [ ] 좌측 메인 메뉴가 `대시보드 / 주문관리 / 문의관리 / 내정보` 구조로 보이는가?

- [ ] 현재 메뉴 위치가 사이드바 활성 상태로 표시되는가?
- [ ] 상단 브레드크럼이 현재 메뉴명과 맞게 표시되는가?
- [ ] 각 화면 진입 시 페이지 제목과 설명 문구가 보이는가?
- [ ] 데이터가 없을 때 빈 상태 문구가 표시되는가?
- [ ] 저장/처리/동기화 시 사용자에게 진행 상태가 보이는가?
