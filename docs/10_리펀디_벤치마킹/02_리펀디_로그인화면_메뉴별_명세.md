## 2. 대시보드

- 연·월 이동과 마진 확정, 취소·반품 제거, 직접 입력 비용 반영 토글
- 총매출, 정산예정금, 비용, 예상마진, 주문건수
- 신규주문·상품준비·발송대기·클레임 남은 작업
- 마켓별·일별 매출과 공지사항
- 캐시백 혜택 진입

## 3. 주문현황

- 주문번호·상품명·수령자·연락처 통합 검색
- 이슈만 보기와 이슈 기준 설정
- 6개 업무 그룹, 31개 세부 상태, 상태별 전체·처리필요 건수
- 상태 타일 선택 후 주문 목록과 처리 화면 연결
- 이슈 아님, 일정 시간 미루기, 일괄 처리
- 약 1분 자동 새로고침, 이슈 우선·오래된 순 운영

## 4. 주문관리

### 목록 공통

- 리펀디 추천순 정렬과 주문 불러오기
- 마켓 주문번호, 내부 주문 ID, 배대지 주문번호, 주문자·수령자, 상품명, 메모 검색
- 작업, 주문일시, 상품정보, 처리상태, 수령자, 결제가격·마진, 마켓, 메모 컬럼
- 상태별 작업함과 빈 상태 안내

### 확장 상세

- 구매자·수령자·개인통관고유부호
- 마켓 판매상품과 소싱상품 비교
- 상품원가·수수료·배대지비·직접비·예상·실제마진
- 결제내역 다운로드와 이전 소싱 이력
- 소싱 추가·발주·환불, 중국 판매자 대화
- 외부 배대지 주문, 배송조회, 마켓 상품관리, 내부 메모

## 5. 문의관리

- 미답변, 답변완료, 전체 문의, 연동 스토어 요약
- 문의 불러오기와 기간·검색·답변상태 필터
- 주문·상품 정보와 문의 연결
- 주문 데이터를 바탕으로 AI 답변 생성
- 답변기한 경과 시 자동답변 설정
- 답변 전송 이후 수정 제한

## 6. 배대지관리

- 자동 연결되지 않은 노데이터 조회·주문 매칭
- 토스토스·퀵스타·에이셉 운임, 검수시간, 통관시간, CS, 보험 비교
- 메인 배대지 지정과 무게별 운임 비교
- 검수·포장 부가서비스 기본값
- 배송비 자동결제와 스토어별 예외
- 주문서 입고·부분입고·검수·오류입고·견적·재포장·결제·출고 상태
- 배대지 통합 채팅·CS, 합배송, 반품
- 선택 상품 또는 전체 상품 주문서 복제

## 7. 캐시백

- 소싱 구매 캐시백 적립과 혜택
- 지원 플랫폼 안내
- 적립·환급 현황 확인
- 쿠폰 사용 가이드와 연결

## 8. 플랜·마켓연동

- 현재 플랜, 다음 결제일·금액, 업그레이드, 포함 기능
- 구독 카드와 플랜 결제내역
- 마켓·연결 상태·사업자번호 검색·필터
- 계정 선택과 일괄 수정
- 사업자·마켓 설정, 2차 로그인 인증, 결제카드, 최근 수정, 판매자센터 바로가기

## 9. 알림 설정

- 고객: 통관 알림톡·문자, 중국 현지배송, 배대지 출고, 리뷰 요청
- 판매자: 신규주문, 배송비 결제대기, 오류입고
- 고객 발송 가능 시간대
- 기본 템플릿과 커스텀 문구
- 주문취소 버튼 숨김, 관부가세·추가 택배비 안내
- 치환 문구와 버튼 미리보기

## 10. 장부

- 월별·기간 조회와 마켓 필터
- 마진 확정, 취소·반품 제거, 직접 입력 비용 반영
- 총매출, 총마진, 평균 마진율, 주문건수
- 정산예상금, 소싱금액, 배대지합계, 총비용, 최종마진, 실제마진
- 직접비가 있는 취소·반품 행의 별도 합계 규칙
- 최근 주문 기준 정기 업데이트와 엑셀 다운로드

## 11. 일반 설정

- AI 가격협상 기본값
- 협상 성공 시 자동결제와 금액 조건
- 스토어별 예외
- 중국판매자·배대지 채팅 모바일 푸시
- 모바일 홈 화면 설치
- 이름·휴대폰·비밀번호·로그아웃

## 12. 실험실

### 문자 보내기

- 알리고 API Key, User ID, 발신번호 연동·테스트
- 발송 서버 IP 등록 안내
- 셀러 알리고 포인트 차감과 발신번호 책임 안내
- 발송, 템플릿, 전송 이력

### 타오바오 상품검색

- 상품명 검색
- 이미지 붙여넣기·드래그·파일 검색
- 타오바오 URL 검색
- 검색결과, 최근 이미지 검색, 즐겨찾기
- 월 사용량과 잔여 검색 횟수
- 쿠폰 적용 최저가격 안내
