# 리펀디 메뉴 트리

## 1. 문서 목적과 읽는 법

이 문서는 리펀디 OMS의 메뉴와 각 화면 안에서 다시 진입하는 탭·상태·상세 기능을 하나의 계층으로 보존한다. 커머스라이프 MVP 채택 여부를 판단하는 문서가 아니며, 리펀디에서 확인한 기능을 제외 없이 기록하는 벤치마킹 원장이다.

- 기준 화면: 2026-08-12 로그인 상태의 https://oms.refundy.co/
- 1단계: 사이드바 그룹
- 2단계: 실제 메뉴
- 3단계 이하: 화면 내부 탭, 상태, 상세 패널, 주요 액션
- 괄호 안 값: 내부 경로 또는 대표 기능 카탈로그 ID
- 가이드는 OMS 밖의 공식 Channel.io 문서로 이동하는 외부 메뉴다.
- 내부 메뉴 18개와 외부 가이드 진입 1개를 기준으로 작성했다.
