# 리펀디 전체 기능 목록표

## 1. 사용법

이 문서는 리펀디에서 확인한 기능을 커머스라이프의 현재 범위와 무관하게 모두 보존한다. 전체 15개 영역, 163개 기능이며 기능 번호는 커머스라이프 MVP 선정표와 연결해 사용한다.

근거 표기:

- 화면: 2026-08-12 로그인 화면에서 확인
- 가이드: 리펀디 공식 이용안내에서 확인
- 자주 묻는 질문: 리펀디 공식 답변에서 확인
- 공지: 로그인 대시보드 공지에서 확인

### 직접전달 기능 설명

- 직접전달은 상품을 고객에게 직접 건네는 배송방법이 아니라, 구매대행 주문의 마켓 상태를 먼저 `배송중`으로 바꾸는 선발송 처리 방식이다.
- 네이버 스마트스토어와 11번가 주문은 발송대기에서 `가송장` 또는 `직접전달` 중 하나를 선택할 수 있다.
- 직접전달을 처리하면 마켓에서는 주문이 배송중으로 보이지만, 리펀디에서는 소싱상품 결제가 끝날 때까지 발송대기에 남는다.
- 직접전달 이후에도 상품 소싱, 결제, 배대지 접수와 실제 배송은 반드시 진행해야 하므로 구매 완료를 대신하지 않는다.
- 스마트스토어는 배송설정을 `직접전달`로 맞춰야 배송 지연에 따른 불이익 위험을 줄일 수 있다.
- 직접전달 주문의 국내 배송이 완료되면 구매확정 요청을 자동으로 보낼 수 있으며, 자동 처리를 위해서는 마켓의 추가 로그인이 필요하다.
