# 리펀디 벤치마킹 인덱스

## 1. 폴더 목적

이 폴더는 리펀디의 기능을 빠짐없이 축적하는 경쟁서비스 사실 원장이다. 커머스라이프의 현재 범위, 구현 난이도, 사업정책 때문에 리펀디 기능을 삭제하거나 누락하지 않는다.

리펀디 기능 사실과 커머스라이프 MVP 결정은 반드시 분리한다.

- 이 폴더: 리펀디가 무엇을 제공하는지, 어디에서 확인했는지 기록
- 01_서비스기획/04_리펀디_기능_MVP_선정_매트릭스.md: 어떤 기능을 어느 MVP 단계에서 채택할지 결정
- 커머스라이프 PRD·기능명세: 선택된 기능의 요구사항과 완료 조건 관리

## 3. 사실 기록 규칙

1. 확인한 기능은 커머스라이프에서 당장 만들지 않더라도 전체 기능 목록표에 유지한다.
2. 화면 확인, 가이드 확인, FAQ 확인, 공지 확인을 근거 유형으로 구분한다.
3. 로그인 화면에 개인정보·사업자번호·카드번호가 보여도 문서에는 저장하지 않는다.
4. 리펀디가 기능을 추가·변경·삭제하면 기존 기록을 지우지 않고 변경이력과 확인일을 갱신한다.
5. 추정은 사실처럼 쓰지 않는다. 화면에서 동작을 끝까지 확인하지 못한 항목은 확인 수준을 명시한다.
6. MVP 선정 상태는 이 폴더의 기능 존재 여부를 변경하지 않는다.

## 4. 조사 기준

- 로그인 화면: https://oms.refundy.co/
- 공식 가이드: https://docs.channel.io/oms_refundy/ko
- 실사용 화면 확인일: 2026-08-25
- 가이드 범위: 본문 가이드 55건, FAQ 7건
- 로그인 메뉴 범위: 대시보드부터 실험실까지 18개 경로
- 공지 범위: 대시보드 전체 공지 22건, 최신 공지 상세 3건

## 5. 갱신 절차

1. 사이드바 메뉴와 각 화면을 순서대로 확인한다.
2. 신규 버튼·조회 조건·상태·설정·자동처리·외부 연결을 전체 기능 목록표에 추가한다.
3. 공식 가이드의 카테고리와 문서 수를 대조한다.
4. 기능 ID를 유지하고 근거·확인일만 갱신한다.
5. 커머스라이프 MVP 후보가 달라지면 서비스기획의 선정 매트릭스만 수정한다.
6. 99_리펀디_벤치마킹_변경이력.md에 조사 결과를 기록한다.
