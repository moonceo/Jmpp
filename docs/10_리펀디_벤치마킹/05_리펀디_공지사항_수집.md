## 2. 화면 구성과 동작

### 대시보드 공지 영역

- 최신 공지 3건을 먼저 보여준다.
- 각 공지에는 제목, 중요 표시, 내용 미리보기, 상대 시각을 표시한다.
- 최신 공지는 신규 표시를 함께 보여준다.
- 공지를 선택하면 해당 공지의 상세 창을 연다.
- `더보기`를 선택하면 전체 공지 22건을 별도 창으로 보여준다.

### 전체 공지 창

- 상단에 전체 공지 건수를 표시한다.
- 공지는 최신순으로 정렬한다.
- 각 행에는 제목, 중요·신규 표시, 월·일, 한 줄 내용 미리보기를 표시한다.
- 공지를 선택하면 전체 목록 대신 선택한 공지의 상세 창을 보여준다.

### 공지 상세 창

- 제목, 중요 표시, 게시 후 경과 시간, 게시 기간, 본문을 표시한다.
- 게시 기간은 시작일과 종료일로 구성하며 현재 확인한 최신 3건은 모두 종료일이 정해지지 않은 상태다.
- 본문은 소제목, 문단, 목록, 주의사항, 이용안내 연결로 구성할 수 있다.
- 닫기를 선택하면 대시보드로 돌아간다.
