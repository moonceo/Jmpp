# 주문관리 개발 체크리스트

## 1순위

### 마켓연동

- [ ] 마켓 선택
  - [ ] 스마트스토어를 선택할 수 있다.
  - [ ] 쿠팡을 선택할 수 있다.
  - [ ] 11번가를 선택할 수 있다.
  - [ ] G마켓을 선택할 수 있다.
  - [ ] 옥션을 선택할 수 있다.
- [ ] 마켓 계정 추가
  - [ ] 마켓·스토어명·사업자번호를 입력한다.
  - [ ] 마켓별 연결정보를 입력한다.
  - [ ] 저장 후 계정 목록에 표시한다.
- [ ] 스마트스토어 연결정보
  - [ ] 연동용 판매자 ID를 입력한다.
  - [ ] 클라이언트 ID를 입력한다.
  - [ ] 클라이언트 시크릿을 입력한다.
- [ ] 쿠팡 연결정보
  - [ ] 업체코드를 입력한다.
  - [ ] Access Key·Secret Key를 입력한다.
  - [ ] 윙 로그인 ID를 입력한다.
- [ ] 11번가 연결정보
  - [ ] 판매자 ID를 입력한다.
  - [ ] 연결 키를 입력한다.
- [ ] G마켓 연결정보
  - [ ] Master ID를 입력한다.
  - [ ] Seller ID를 입력한다.
  - [ ] Secret Key를 입력한다.
- [ ] 옥션 연결정보
  - [ ] Master ID를 입력한다.
  - [ ] Seller ID를 입력한다.
  - [ ] Secret Key를 입력한다.
- [ ] 입력값 검증
  - [ ] 필수값 누락 시 저장을 차단한다.
  - [ ] 사업자번호 형식을 검증한다.
  - [ ] 같은 마켓 계정의 중복 등록을 차단한다.
- [ ] 계정 연결 확인
  - [ ] 저장된 연결정보로 인증을 확인한다.
  - [ ] 판매자·스토어 정보를 확인한다.
  - [ ] 사용할 수 있는 API 권한을 확인한다.
- [ ] 연결 성공
  - [ ] 연동상태를 `연결됨`으로 표시한다.
  - [ ] 확인일시를 저장한다.
  - [ ] 활성화 기능을 제공한다.
- [ ] 연결 실패
  - [ ] 잘못된 키를 오류로 표시한다.
  - [ ] 만료·재인증 필요를 구분한다.
  - [ ] 권한 부족·IP 미허용을 구분한다.
- [ ] 비밀정보 보호
  - [ ] 저장 후 비밀키 원문을 다시 표시하지 않는다.
  - [ ] 목록·브라우저 로그에 비밀키를 노출하지 않는다.
  - [ ] 새 비밀키 저장 시 기존 값을 폐기한다.
- [ ] 계정 활성화
  - [ ] 연결된 계정만 활성화할 수 있다.
  - [ ] 활성 계정을 주문수집 대상에 포함한다.
  - [ ] 허용된 주문 처리 기능을 활성화한다.
- [ ] 계정 일시정지
  - [ ] 활성 계정을 일시정지할 수 있다.
  - [ ] 일시정지 계정을 신규 수집 대상에서 제외한다.
  - [ ] 일시정지 계정의 외부 상태변경을 차단한다.
- [ ] 계정 설정 수정
  - [ ] 스토어명·사업자번호를 수정할 수 있다.
  - [ ] 마켓별 연결정보를 교체할 수 있다.
  - [ ] 수정 후 연결 확인 전까지 상태변경을 차단한다.
- [ ] 계정 삭제
  - [ ] 삭제 전 확인창을 표시한다.
  - [ ] 진행 중인 수집·처리 작업을 확인한다.
  - [ ] 삭제 후 신규 수집 대상에서 제외한다.
  - [ ] 기존 주문과 처리이력은 유지한다.
- [ ] 다중 계정 관리
  - [ ] 같은 마켓의 여러 스토어를 등록할 수 있다.
  - [ ] 스토어별 연결상태·활성상태를 구분한다.
  - [ ] 주문 목록에서 스토어명을 구분한다.
- [ ] 계정 상태 표시
  - [ ] 확인 대기·연결됨·오류를 구분한다.
  - [ ] 재인증 필요·연결 해제를 구분한다.
  - [ ] 활성·비활성 상태를 연결상태와 별도로 표시한다.
- [ ] 마켓별 기능 지원 표시
  - [ ] 주문수집 지원 여부를 표시한다.
  - [ ] 주문확인·송장·취소·클레임 지원 여부를 표시한다.
  - [ ] 미지원 기능은 실행할 수 없고 사유를 안내한다.
- [ ] 마켓별 수집 설정
  - [ ] 최초 수집기간을 설정할 수 있다.
  - [ ] 자동수집 사용 여부를 설정할 수 있다.
  - [ ] 마지막 수집결과를 확인할 수 있다.
- [ ] 마켓 계정 목록 상태
  - [ ] 최초 조회 중 로딩 상태를 표시한다.
  - [ ] 등록 계정이 없으면 빈 상태를 표시한다.
  - [ ] 조회 실패 시 오류와 다시 시도를 제공한다.

### 주문수집

- [ ] 마켓 주문 자동수집
  - [ ] 활성화된 마켓 계정만 수집한다.
  - [ ] 설정된 주기에 자동 실행된다.
  - [ ] 신규 주문이 목록에 반영된다.
- [ ] 주문 수동수집
  - [ ] 수동수집 버튼을 실행할 수 있다.
  - [ ] 중복 실행이 차단된다.
  - [ ] 완료 후 목록이 갱신된다.
- [ ] 신규·변경 주문 반영
  - [ ] 신규 주문을 생성한다.
  - [ ] 기존 주문의 주소·수량·상태 변경을 반영한다.
  - [ ] 오래된 정보가 최신 정보를 덮어쓰지 않는다.
- [ ] 중복 주문 방지
  - [ ] 같은 마켓 주문번호를 반복 수집해도 한 건만 존재한다.
  - [ ] 같은 상품주문번호를 반복 수집해도 한 건만 존재한다.
- [ ] 주문수집 결과 표시
  - [ ] 신규·갱신·오류 건수를 표시한다.
  - [ ] 완료·부분완료·실패 상태를 구분한다.
- [ ] 주문수집 실패 재시도
  - [ ] 실패 이유를 표시한다.
  - [ ] 실패한 작업만 다시 실행할 수 있다.
  - [ ] 재시도 후 중복 주문이 생성되지 않는다.

### 주문 목록

- [ ] 전체주문
  - [ ] 모든 일반 주문을 표시한다.
  - [ ] 처리보류 주문을 포함한다.
- [ ] 신규주문
  - [ ] 주문확인 전 주문만 표시한다.
  - [ ] 주문확인 완료 주문은 제거된다.
- [ ] 상품준비
  - [ ] 주문확인 완료·구매 미완료 주문만 표시한다.
  - [ ] 구매 완료 주문은 제거된다.
- [ ] 발송대기
  - [ ] 구매와 국내송장이 완료된 주문만 표시한다.
  - [ ] 발송 처리 완료 주문은 제거된다.
- [ ] 배송중
  - [ ] 마켓 발송 처리 완료 주문만 표시한다.
  - [ ] 배송완료 주문은 제거된다.
- [ ] 배송완료
  - [ ] 배송완료 주문만 표시한다.
  - [ ] 구매확정 여부를 함께 표시한다.
- [ ] 상태별 주문 건수
  - [ ] 탭별 건수가 실제 목록과 일치한다.
  - [ ] 처리 후 건수가 즉시 갱신된다.
- [ ] 기간 검색
  - [ ] 기본 조회기간을 적용한다.
  - [ ] 직접 시작일·종료일을 선택할 수 있다.
  - [ ] 잘못된 기간 입력을 차단한다.
- [ ] 주문 통합검색
  - [ ] 상품명으로 검색된다.
  - [ ] 주문번호로 검색된다.
  - [ ] 주문자·수령인으로 검색된다.
- [ ] 마켓 필터
  - [ ] 마켓별 주문만 표시한다.
  - [ ] 전체 선택 시 모든 마켓을 표시한다.
- [ ] 스토어 필터
  - [ ] 선택한 스토어 주문만 표시한다.
  - [ ] 마켓 선택에 맞는 스토어만 제공한다.
- [ ] 주문상태 필터
  - [ ] 현재 탭에 맞는 상태만 제공한다.
  - [ ] 선택한 상태의 주문만 표시한다.
- [ ] 페이지 이동
  - [ ] 다음·이전 페이지로 이동할 수 있다.
  - [ ] 페이지 이동 후 필터가 유지된다.
  - [ ] 중복·누락 없이 목록이 이어진다.
- [ ] 복수 품목 주문 표시
  - [ ] 한 주문의 여러 상품을 구분해 표시한다.
  - [ ] 품목별 수량·상태·액션을 유지한다.
  - [ ] 부분 처리 결과를 품목별로 표시한다.

  - [ ] 마켓·스토어·주문번호를 표시한다.

  - [ ] 상품주문번호·판매금액을 표시한다.
- [ ] 구매자 정보
  - [ ] 구매자명·연락처·아이디를 표시한다.
  - [ ] 권한에 따라 개인정보를 마스킹한다.
- [ ] 배송지 정보
  - [ ] 수령인·연락처·우편번호를 표시한다.
  - [ ] 주소·상세주소·배송메시지를 표시한다.
- [ ] 개인통관부호
  - [ ] 저장된 통관부호를 표시한다.
  - [ ] 형식 유효·본인일치·불일치를 구분한다.
- [ ] 소싱 정보
  - [ ] 소싱상품·옵션·수량을 표시한다.
  - [ ] 소싱상태·소싱 주문번호를 표시한다.
- [ ] 결제 정보
  - [ ] 결제상태·결제금액·결제일시를 표시한다.
  - [ ] 예상원가·실제원가·마진을 구분한다.
- [ ] 국내송장 정보
  - [ ] 택배사·송장번호를 표시한다.
  - [ ] 송장 수신·마켓 전송일시를 표시한다.
- [ ] 주문 처리이력
  - [ ] 상태 변경 전후를 표시한다.
  - [ ] 작업자·처리시각·처리결과를 표시한다.
  - [ ] 최신 이력부터 확인할 수 있다.
- [ ] 배송정보 수정
  - [ ] 수정 전 값을 불러온다.
  - [ ] 필수값·연락처·우편번호를 검증한다.
  - [ ] 성공 후 목록과 상세에 반영한다.
  - [ ] 실패 시 입력값과 기존 상태를 유지한다.

### 주문확인

- [ ] 개별 주문확인
  - [ ] 신규주문에서만 버튼을 표시한다.
  - [ ] 성공 시 상품준비로 이동한다.
  - [ ] 실패 시 신규주문에 유지한다.
- [ ] 일괄 주문확인
  - [ ] 선택한 신규주문만 처리한다.
  - [ ] 선택이 없으면 실행할 수 없다.
  - [ ] 처리 중 중복 실행을 차단한다.
- [ ] 주문별 성공·실패 결과
  - [ ] 성공 주문과 실패 주문을 구분한다.
  - [ ] 성공 주문만 상태를 변경한다.
  - [ ] 실패 사유를 주문별로 표시한다.
- [ ] 실패 주문 재처리
  - [ ] 실패 주문만 다시 선택할 수 있다.
  - [ ] 최신 마켓 상태를 확인한 뒤 처리한다.

### 상품 소싱

- [ ] 소싱상품 추천
  - [ ] 원주문 상품 기준 추천 목록을 표시한다.
  - [ ] 추천상품 이미지·가격·옵션을 표시한다.
- [ ] 키워드 상품검색
  - [ ] 키워드를 입력해 검색할 수 있다.
  - [ ] 검색 결과를 기존 후보와 구분한다.
- [ ] 상품 URL 검색
  - [ ] 지원하는 상품 URL 형식을 검증한다.
  - [ ] 해당 상품 한 건을 후보에 추가한다.
- [ ] 상품·옵션 선택
  - [ ] 상품과 정확한 SKU 옵션을 선택한다.
  - [ ] 품절 옵션을 선택할 수 없다.
- [ ] 구매수량 선택
  - [ ] 마켓 판매수량을 기본값으로 표시한다.
  - [ ] 최소수량·수량배수를 검증한다.
- [ ] 가격·재고 확인
  - [ ] 원화·위안화 가격을 표시한다.
  - [ ] 재고·확인시각을 표시한다.
  - [ ] 오래된 정보는 재조회한다.
- [ ] 상품 매칭 저장
  - [ ] 마켓 상품·옵션과 소싱 SKU를 저장한다.
  - [ ] 저장 성공 후 진행상태를 갱신한다.
  - [ ] 저장 실패 시 선택값을 유지한다.
- [ ] 기존 매칭 재사용
  - [ ] 동일 마켓 상품·옵션의 승인 매칭을 제안한다.
  - [ ] 주문이 달라도 동일 SKU를 재사용한다.
  - [ ] 과거 주문 매칭은 변경하지 않는다.
- [ ] 품절·가격변경 재검증
  - [ ] 구매 직전 재고를 다시 확인한다.
  - [ ] 가격 변경 시 사용자 확인 전 구매를 차단한다.
  - [ ] 품절 시 재매칭 상태로 이동한다.
- [ ] 매칭 변경
  - [ ] 기존 매칭을 새 상품·옵션으로 변경할 수 있다.
  - [ ] 변경자·변경일시·변경사유를 기록한다.
- [ ] 대체상품 선택
  - [ ] 기존 상품 사용 불가 시 대체상품을 선택한다.
  - [ ] 대체상품 가격·옵션·수량을 다시 검증한다.

### 구매대행 신청·결제

- [ ] 원주문·소싱상품 비교
  - [ ] 원주문과 소싱상품을 나란히 표시한다.
  - [ ] 상품명·옵션·수량 차이를 확인할 수 있다.
- [ ] 예상비용·마진 확인
  - [ ] 상품원가·이용료·환전·배송비를 표시한다.
  - [ ] 예상 총비용·순이익·마진율을 계산한다.
- [ ] 배송대행지 선택
  - [ ] 저장된 수령 프로필을 표시한다.
  - [ ] 한 개의 프로필을 선택할 수 있다.
  - [ ] 필수 수령·통관정보 누락을 차단한다.
- [ ] 구매대행 신청
