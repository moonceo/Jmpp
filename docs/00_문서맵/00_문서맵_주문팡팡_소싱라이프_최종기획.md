# 주문팡팡 + 소싱라이프 최종 기획 문서맵

본 문서는 주문팡팡 + 소싱라이프 연동 최종 기획 문서의 전체 구조와 문서별 역할을 정의한다.
기획 및 개발 기준은 아래 1~9번 문서를 기준으로 관리한다.

현재 기준은 주문팡팡 + 소싱라이프 최종 모델 기획 기준으로 관리한다.

## 문서 목적

- 플레이오토형 통합 주문관리 서비스를 주문팡팡의 기준 모델로 정의한다.
- 모든 판매처의 주문을 한 화면에서 모아보고 처리하는 구조를 정의한다.
- 네이버 스마트스토어와 쿠팡 API를 1차 기준으로 삼고, 이후 11번가, 지마켓, 옥션으로 확장 가능한 구조를 만든다.
- 주문 처리 중 소싱라이프를 외부 소싱/구매/국내송장 확보 서비스로 연동한다.
- 상태, 기능, 화면, API, 운영 기준을 일관된 기준으로 정의한다.

## 문서 관리 원칙

1. 기능을 추가할 때는 영향을 받는 1~9번 문서에 빠짐없이 반영한다.
2. 내부 주문 상태는 7번 문서를 기준으로 관리한다.
3. 마켓 API 상태는 내부 주문 상태로 매핑한다.
4. 네이버 스마트스토어와 쿠팡을 먼저 정의하고 11번가, 지마켓, 옥션은 같은 구조로 확장한다.
5. 소싱라이프는 주문팡팡 내부 기능이 아니라 외부 연동 서비스로 정의한다.
6. 유저플로우는 1~7번 기준 문서의 정책, 화면, 기능, API, 운영 기준을 시각화한 보조 기준으로 관리한다.
7. 와이어프레임은 1~8번 기준 문서를 화면 구조, 정보 배치, 대표 상태, 더미데이터로 구체화한 화면 설계 기준으로 관리한다.
