# 경쟁서비스 벤치마크 및 기능 패리티

## 1. 조사 목적

리펀디·샵마인과 범용 주문관리 서비스의 공개 기능을 비교해 커머스라이프의 출시 필수 기능과 차별화 범위를 정한다.

공개 페이지의 기능 주장은 실제 정확도·안정성·마켓별 지원범위를 보증하지 않는다. 본 문서는 제품 요구사항 후보를 만드는 자료이며, 경쟁사 마케팅 수치를 제품 완료 증거로 사용하지 않는다.

### 3-1. 2026-08-12 리펀디 실사용 재검증

로그인된 OMS의 18개 메뉴와 Channel.io 가이드 55건, FAQ 7건을 직접 확인했다. 이 절은 조사 범위만 요약하며 커머스라이프의 선택 판단은 섞지 않는다.

| 확인 영역 | 리펀디 기능 범위 | 근거 |
|---|---|---|

| 주문 운영 | 대시보드, 6개 그룹·31개 상태, 이슈 운영, 상태별 주문함, 확장 상세 | 화면·가이드 |
| 소싱·자동화 | AI 추천, 발주, 타오바오 검색, 가격협상, 성공 시 자동결제 | 화면·가이드·FAQ |
| 통관·알림 | 통관부호 알림톡·문자, 고객·판매자 알림, 대량 문자 | 화면·가이드 |

## 4. 출시 필수

### 4-1. 주문 운영

- 다중 마켓·다중 스토어
- 최초·증분 주문·클레임 수집
- 전체 주문과 작업단계별 조회

- 송장 발송과 결과 추적
- 취소·반품·교환의 세부 단계
- 문의·긴급 작업 연결
- Excel 내보내기

### 4-2. 안정성

- 계정 연결상태와 키 만료
- 중복 방지
- 부분 성공
- 재시도와 결과 대사
- 처리이력

샵마인이 저렴하고 빠른 운영 기준을 제공하더라도 커머스라이프가 실패 복구와 보안을 생략해서는 안 된다.

## 5. 커머스라이프 핵심 차별화

### 5-1. 옵션 단위 매칭 메모리

마켓 상품·옵션과 타오바오 SKU를 한번 승인하면 다음 주문에서 재사용한다. 단순 URL 즐겨찾기가 아니라 버전·수량 배수·가격·재고·대체 SKU를 포함한다.

### 5-2. 구매 직전 위험 점검

- SKU 존재·재고
- 가격변동
- 최소수량
- 중국 내 배송비
- 제한품목
- 통관정보
- 예상 원화비용

### 5-3. 주문 화면 안의 구매 실행

주문을 복사해 다른 화면에서 새로 입력하지 않고 소싱라이프 구매대행 신청과 결제로 연결한다.

### 5-4. 실제 해외물류 상태 분리

중국배송·통관·국내배송의 실제 소싱 진행 상태를 중심으로 보여주고, 마켓 배송중·배송완료는 원천 데이터로만 유지해 중복 표시를 줄인다.

### 5-5. 양방향 클레임 복구

마켓 취소와 소싱라이프 구매취소·환불을 별도 결과로 추적하고 한쪽만 성공한 작업을 숨기지 않는다.

## 6. 후순위

- AI 자동매칭
- 금지품목·지재권 자동 분류
- 역마진 자동 경고
- 문의·클레임 답변 초안
- 장부·세무·정산 고도화
- 외부 ERP·회계
- 조건부 무인 자동구매

P0의 수집·구매·송장·클레임 신뢰성이 확보되기 전에 무인 자동화를 출시하지 않는다.

## 7. MVP 선택 시 의존성 검토

| 경쟁 기능 | 커머스라이프가 결정할 사항 |
|---|---|
| 타오바오 직접 로그인·결제 | 직접 구현과 소싱라이프 계약 중 책임모델, 결제 승인·취소·보안 |
| 배대지·창고 업무 | 직접 운영, 제휴 배대지 연동, 통합 화면 중 운영모델 |
| 결제카드 | PG·토큰화, 결제한도, 실패·환불, 카드정보 비보관 원칙 |
| 상품등록·대량수정 | 마켓별 쓰기 API와 변경 실패·롤백 |
| 캐시백·쿠폰 | 적립·환급·취소 회수와 회계·세무 정책 |

이 표의 모든 기능은 리펀디 전체 카탈로그에 유지한다. 구현 순서만 MVP 선정 매트릭스에서 관리한다.

## 8. 비교 검증 지표

경쟁사와 기능 개수만 비교하지 않고 실제 사용자 작업을 비교한다.

| 지표 | 측정 |
|---|---|
| 첫 계정 연결시간 | 가입부터 첫 주문수집까지 |
| 주문 10건 처리시간 | 수집→매칭→구매신청→발송준비 |
| 반복 매칭 재사용률 | 같은 상품의 수동 재매칭 감소 |
| 오구매율 | SKU·수량·가격 오류 |
| 판매자센터 병행률 | 내부에서 끝내지 못한 작업 |
| 실패 복구시간 | 오류 감지부터 정상화 |
| 클레임 기한 준수 | 마켓 처리기한 내 완료 |
| 수동 복사 횟수 | URL·옵션·송장·주소 재입력 |

## 10. 제품 판정

리펀디와의 직접 경쟁 기준은 “소싱 추천 화면이 있는가”가 아니다. 다음 다섯 가지가 실제로 이어져야 한다.

1. 주문 누락 없는 수집
2. 정확한 옵션/SKU 매칭과 재사용
3. 중복 없는 소싱라이프 구매
4. 마켓 송장·클레임의 실제 반영
5. 실패를 운영자가 복구할 수 있는 상태·이력

샵마인 수준의 주문·알림 편의성과 범용 OMS 수준의 운영 안정성을 갖춘 뒤, 소싱라이프 구매 연결로 차별화한다.
