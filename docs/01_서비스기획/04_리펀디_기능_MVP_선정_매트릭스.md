# 리펀디 기능 기반 커머스라이프 MVP 선정표

## 1. 문서 역할

리펀디에서 확인한 15개 영역, 163개 기능은 [리펀디 전체 기능 목록표](../10_리펀디_벤치마킹/01_리펀디_전체_기능_카탈로그.md)에서 관리한다. 이 문서는 그 전체 목록을 바탕으로 커머스라이프의 MVP 단계를 결정하고, 현재 프로토타입에 만들어진 기능을 같은 번호 기준으로 관리한다.

중요 원칙:

- 벤치마크 기능은 MVP에 바로 선택하지 않아도 삭제하지 않는다.
- 미선정은 영구 제외가 아니라 현재 단계의 순서다.
- 경쟁사 구현 방식과 커머스라이프 구현 방식은 다를 수 있다.
- 단계가 바뀌어도 리펀디 기능 번호는 유지한다.

## 2. 선정 상태

| 상태 | 의미 |
|---|---|
| 구현됨 | 현재 프로토타입에서 사용자 흐름을 확인할 수 있음 |
| MVP-1 | 첫 실사용 출시 기준에 포함 |
| MVP-2 | MVP-1 안정화 직후 확장 |
| 후보 | 사업·사용자 검증 후 순서를 결정 |
| 의존성 검증 | 결제, 외부업체, 판매처 실제 처리, 개인정보 등 선행 검증 필요 |

어떤 상태도 리펀디 벤치마크 카탈로그에서 기능을 제거하지 않는다.

## 6. 정책·사업 검증 후보

아래 기능은 카탈로그에 유지하며 구현 전에 책임과 수익모델을 확정한다.

| 기능 | 필요한 결정 |
|---|---|
| AI 가격협상·협상 성공 자동결제 | 결제 한도, 사용자 승인, 실패·취소, 카드 책임 |
| 배대지 자동결제 | 제휴사 계약, 과금·환불·중복결제 방지 |
| 내부형 배대지 운영 | 직접 운영, 파트너 연동, 화면 통합 중 운영모델 |
| 캐시백·쿠폰 | 지원 소싱처, 적립·환급, 취소 회수, 회계·세무 |

이 표는 제외 목록이 아니다. 결정이 끝나면 MVP-1, MVP-2 또는 후속 릴리스로 이동한다.

## 7. 현재 프로토타입 기능 목록표

### 7.1 제공 단계 기준

이 목록은 2026-08-19 현재 프로토타입을 직접 사용했을 때 확인되는 화면과 처리 결과를 기준으로 작성했다. 화면에 문구나 버튼이 보이는 것과 실제 업무가 처리되는 것을 구분한다.

| 제공 단계 | 의미 |
|---|---|
| 실제 적용 | 입력하거나 처리한 결과가 서비스에 남고 다시 확인됨. 판매처와 관련된 기능은 실제 계정 확인이 추가로 필요함 |
| 일부 적용 | 실제 정보로 처리되는 부분과 예시로 보여주는 부분이 함께 있음 |
| 시연 가능 | 준비된 예시 정보로 업무 흐름을 체험하거나 현재 화면에서만 결과가 바뀜 |
| 화면 구성 | 선택항목이나 버튼은 있으나 조회 결과, 발송, 결제, 파일 만들기 등의 실제 결과는 없음 |

- `리펀디 기능 번호`는 현재 기능과 같거나 유사한 리펀디 기능을 표시한다.
- `일부`는 리펀디 기능 전체가 아니라 현재 프로토타입에서 제공하는 범위만 뜻한다.
- `자체`는 현재 프로토타입에는 있지만 리펀디 기능 목록에 직접 대응하는 항목이 없는 경우다.
- 실제 결제, 고객 메시지 발송, 배대지 주문서 제출, 판매처 클레임 처리는 아직 완료 기능으로 보지 않는다.

### 7.5 현재 판정

- 현재 프로토타입에서 사용자가 확인할 수 있는 기능은 11개 영역, 66개 기능 단위다.
- 처리 결과가 남는 기능은 로그인, 네이버 마켓 계정 관리, 주문 불러오기, 일부 주문 처리, 실제 주문과 소싱상품 연결, 국내송장 저장, 클레임 조회에 집중돼 있다.
- 대시보드, 주문현황, 소싱 추천·구매·결제, 알림, 문의 답변, 장부, 클레임 처리는 대부분 시연 가능 또는 화면 구성 단계다.
- 시연 가능과 화면 구성 단계의 항목은 출시 완료 기능이 아니라 사용자 흐름을 확인하기 위한 기능으로 관리한다.
